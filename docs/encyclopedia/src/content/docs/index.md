**Vector 2D Animation Engine** 是一个面向 Windows 的二维矢量动画创作项目。它围绕矢量绘制、元件复用和时间轴动画展开，尝试把图形编辑与场景组织放在同一套创作体系中，让素材能够从绘制阶段延续到动画制作阶段。

## 作者与贡献

作者、贡献者和项目维护信息将在后续补充。项目当前由仓库维护者持续开发，欢迎通过社区交流使用体验、问题反馈和改进建议。

## 项目来历

项目以原生桌面的二维矢量动画引擎原型起步。在创作方式上，它借鉴了 Adobe Animate 的矢量绘制、元件和时间轴工作流程，将可编辑的图形与按时间变化的内容联系起来。

这条思路的重点在于：一幅图形既可以是独立编辑的素材，也可以成为更大场景的一部分。素材进入场景后，仍然保留与源内容的联系；创作者可以围绕同一份素材继续修改、复用和制作动画。

随着项目发展，内容逐步延伸到嵌套元件、场景组合、资源管理，以及空间参考视图和相机等方向。矢量内容的编辑与组织仍然是这些能力的基础。

## 创作定位

Vector 2D 面向需要亲自绘制素材、反复调整造型，并将这些素材组织成二维动画的创作者。它关注从图形到元件、从元件到场景，再到时间变化的连续创作过程。

对于需要多次出现的角色部件、道具或图形元素，元件复用能够让创作者围绕同一份源素材工作；对于需要发生变化的内容，时间轴提供组织姿态与节奏的基础。绘制、复用与动画因此围绕同一个工程展开。

从技术定位上看，项目同时包含桌面编辑器与底层引擎：编辑器承载创作过程，引擎处理矢量几何、项目关系、动画数据和画面呈现。复杂图形与较大规模场景的组织和交互性能，是项目持续探索的方向。

## 核心理念

**让图形保留可编辑性。** 路径、填充、描边及其结构是创作内容的一部分，为后续调整造型和外观保留空间。

**让素材能够持续复用。** 元件与实例建立源内容和使用位置之间的联系，使同一份素材能够参与不同的组合，并在需要时继续修改。

**让动画建立在清楚的内容关系上。** 图层、帧与元件共同描述内容如何组织、何时出现，以及怎样发生变化。随着作品变得复杂，这些关系仍应能够被理解和编辑。

## 当前阶段

Vector 2D 仍处于持续开发和完善阶段，当前已经具备矢量绘制、元件与场景组织、时间轴编辑及工程保存等基础能力。具体行为可能随版本调整，百科与使用手册也会随之更新。

目前的能力边界同样需要明确：单个元件可以导出为 SVG 或元件包，整场景、整段动画的作品导出仍未提供。大规模内容的性能也是需要结合具体工程和设备持续验证的目标。

后续发展将继续围绕矢量编辑的完整性、动画行为的一致性、复杂场景的交互体验，以及工程数据的可靠性展开。
