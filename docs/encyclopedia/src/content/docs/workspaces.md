---
title: 工作区与界面
---

**工作区（Workspace）** 是 Vector 2D 用来绘制和制作动画的编辑环境。界面由主菜单、工具栏、舞台、属性面板和时间轴等部分组成，分别负责执行命令、选择工具、编辑画面和调整动画。

Vector 2D 提供“[基础绘制](#基础绘制)”和“[场景与动画](#场景与动画)”两个工作区。基础绘制用于制作角色、道具等素材；场景与动画用于将素材放入场景，安排动作和镜头。

两个工作区共用同一份工程。切换工作区后，舞台内容、可用工具和属性面板会根据当前编辑对象自动变化。

### 主菜单与工程名称

**主菜单** 位于窗口左上方，集中放置工程、编辑、显示和播放相关的命令。

#### 菜单组成

![“文件”菜单展开示例](/images/file-menu-example.png)

“文件”菜单展开示例

| 菜单 | 展开后的命令 |
| --- | --- |
| **文件** | 新建工程、打开工程；保存工程、工程另存为；重命名工程；画布与背景。 |
| **编辑** | 撤销、重做；剪切、复制、粘贴、删除；拆散、组、转换为元件；水平或垂直翻转、位图适应画布、上移或下移一层；设置。 |
| **视图** | 舞台适应窗口；显示或隐藏属性、时间轴；打开层级窗口。 |
| **插入** | 导入 Flash 工程、创建 Flash 视觉转换桥、导入 SVG、导入图片；切换到文本工具。 |
| **控制** | 播放或暂停、停止，用于控制当前时间轴的预览。 |
| **帮助** | 更新公告、鸣谢。 |

点击菜单名称即可展开命令。支持快捷键的命令会在右侧显示按键，例如 `Ctrl+N` 新建工程、`Ctrl+O` 打开工程、`Ctrl+S` 保存工程。

撤销和重做根据编辑历史执行。拆散、组合、翻转和调整层级等命令，需要先选中适用的内容。

SVG 和图片导入是否可用，取决于当前工作区和编辑范围。暂时不能执行的命令会显示为灰色。

#### 工程名称

![主菜单与工程名称](/images/main-menu-and-project-name.png)

主菜单与工程名称

工程名称位于主菜单右侧，用来确认当前打开的工程。

尚未命名的新工程显示为 `Untitled Project`。打开已有工程后，这里显示工程中保存的名称。

名称后的星号（`*`）表示工程存在尚未保存的修改。保存成功后，星号会消失。

点击工程名称即可在原位置编辑，也可以使用“文件 → 重命名工程”。

输入名称后按 `Enter` 确认，按 `Esc` 取消。空名称不会替换当前名称。

重命名只会修改工程名称，不会自动保存工程，因此确认后仍会显示星号。

### 工具栏

![左侧工具栏](/images/tool-palette.png)

左侧工具栏

**工具栏** 用于选择舞台工具，也提供对象绘制和素材库等常用开关。

工具栏会随工作区显示，无需单独开启。当前使用的工具会以强调色标出。

不适用于当前工作区、图层或编辑范围的工具，会被隐藏或暂时禁用。

#### 位置与排列

工具栏默认竖排在舞台左侧，主要工具从上到下排列，末端是对象绘制和素材库按钮。

通过“编辑 → 设置 → 操作偏好 → 工具栏位置”，可以将工具栏切换为顶部横排。

横排时，工具位于工作区标签下方、舞台上方，末端按钮排列在工具组之后。

#### 打开工具组

按钮右下角的小三角表示其中包含多个工具。

工具栏位于左侧时，将指针移到按钮上或点击按钮，会在右侧展开纵向列表。工具栏位于顶部时，点击或右键点击按钮，会在下方展开列表。

工具组按钮会显示该组最近使用的工具。再次点击即可启用它；从展开列表选择其他工具后，按钮图标也会更新。

**隐藏**：某个工具不适用于当前编辑范围时，会从展开列表中隐藏。组内所有工具都不适用时，隐藏整个工具组，并收起已展开的列表。

**禁用**：工具适用但当前不允许绘制时，仍显示按钮，但不能启用。活动图层或上级图层锁定，以及场景绘制处于参考视图状态，都会限制绘制工具。组内有显示项但全部被禁用时，组按钮也禁用。

**可用**：组内至少有一个工具显示且允许启用时，工具组按钮可以点击；展开项仍各自遵循显示和禁用规则。

组按钮显示该组最近使用的工具图标。其他工具是否可用，可以展开列表查看。

### 舞台

![引擎全景图，红色边框标出舞台区域](/images/stage-area.png)

引擎全景图中的舞台区域。红色边框内是舞台，左侧工具栏、顶部视图控制、右侧属性面板和底部时间轴属于舞台周围的界面。

**舞台（Stage）** 是界面中央的主要编辑区域，用来绘制图形、选择对象、调整变换和预览场景。

舞台上的内容会随当前工作区、编辑对象和播放头所在帧变化。选择图层、进入元件或移动播放头后，舞台会显示相应内容。

#### 显示内容

| 编辑范围 | 舞台显示的内容 |
| --- | --- |
| 基础绘制 | 当前元件或开放画布中的图形，可在这里制作和修改素材。 |
| 场景与动画 | 当前帧的手绘内容、元件实例及场景组合结果。 |
| 元件内部 | 正在编辑的元件内容。修改源元件后，引用它的实例会同步更新。 |
| 参考视图 | 从所选方向观察场景，用于检查位置和空间关系；可用工具随观察方向变化。 |
| 镜头编辑 | 当前镜头的构图与场景内容，用于检查画幅和镜头安排。 |

舞台中显示的内容不一定都能直接修改。能否编辑还取决于当前工具、编辑范围和图层锁定状态，详见[工具组可用项规则](#工具组可用项规则)。

#### 画布

![场景与动画中尚未设置画布时的引导界面](/images/scene-canvas-start-detail.png)

这是空场景中的“画布与背景”入口，可以先设置画面，也可以直接开始创作。

**画布** 是“场景与动画”中设置画面尺寸和背景的区域。舞台用于编辑和观察，画布及其外围区域都可以显示在舞台中。

空场景尚未设置画布时，舞台中央会出现“画布与背景”提示。

- **设置画布与背景**：打开设置窗口，选择画面尺寸和背景，点击“应用”后生效。
- **直接开始**：收起提示，继续在场景中创作；不会自动添加画布或背景。
- **文件 → 画布与背景**：随时重新打开当前场景的画布设置。
- **文档信息中的“画布与背景”**：未选择对象时，也可以从文档信息面板打开设置。

放入元件、绘制内容或创建镜头后，提示会自动消失。删除或撤销内容不会让提示再次出现；平移、缩放和切换工具也不会自动创建画布。

**画布尺寸**：确定画面边界与宽高比例，通过“文件 → 画布与背景”设置。

**画布背景**：可选择无背景、纯色或图片。无背景以棋盘格表示透明；背景位于场景内容下方。

**画布外区域**：便于放置和调整边界外的内容；开启画布外压暗后，仍可在这里编辑。

**工作区背景**：编辑器用于衬托画面的底色，由主题与外观设置控制。

![画布与背景设置弹窗](/images/scene-canvas-dialog.png)

画布与背景设置窗口：左侧提供尺寸预设和预览，右侧设置宽高与背景，底部可以取消或应用设置。

尺寸可以使用横屏、竖屏、方形等预设，也可以输入宽高，锁定比例或交换宽高。图片背景可以选择完整显示、铺满画布或原始大小，并调整位置和不透明度。

每个场景独立保存画布设置，基础绘制中的元件仍保持透明。改变画布尺寸不会自动缩放、移动或删除已有对象，也不会改变关键帧或镜头位置。工作区背景、选框、网格等编辑辅助显示不属于画布背景。

#### 缩放与平移

以下操作适用于二维舞台。使用前请先将指针移到舞台内；使用键盘命令时，应让舞台获得焦点，避免文字或数值输入框接收按键。

| 操作 | 作用 |
| --- | --- |
| 鼠标滚轮 | 放大或缩小当前视图。 |
| 鼠标中键拖动 | 平移视图，查看其它位置。 |
| 按住 `Space` 后左键拖动 | 临时平移，松开空格后恢复当前工具。 |
| `Ctrl` + 鼠标中键上下拖动 | 连续调整缩放。 |
| 舞台上方的放大、缩小按钮 | 调整当前工作区的视图倍率。 |
| `Ctrl` + `+` / `Ctrl` + `-` | 以视图中心放大或缩小。 |
| `Ctrl+0` | 将二维绘制视图恢复到 100%。 |
| `Home` 或“视图 → 舞台适应窗口” | 重新调整视图，使舞台适应可用空间。 |

缩放和平移不会改变对象的尺寸、位置或动画。顶部和底部显示的百分比是当前工作区的视图倍率；切换工作区后，读数会随当前视图变化。

三维参考视图的鼠标操作有所不同，例如中键拖动用于旋转视图，不能直接套用上表中的二维平移操作。

#### 网格、标尺与辅助线

![舞台上方的网格、吸附与视图控制区](/images/stage-view-controls.png)

舞台上方的控制区，对应界面总览图的 7 号分区。上排设置网格与标尺，中排设置吸附，下排右侧是面板开关和缩放按钮。

这些功能用于测量距离、定位和对齐，不会作为图形出现在导出的作品中。

| 控制项 | 作用 |
| --- | --- |
| 网格类型与不透明度 | 选择网格样式，调整网格在舞台上的显示强度。 |
| 标尺 | 在舞台底部与右侧显示刻度；可选择 px、mm、cm、in 或隐藏，刻度随缩放和平移更新。 |
| 吸附总开关 | 统一开启或关闭吸附；关闭后，各项吸附设置暂时不生效。 |
| 网格、对象吸附 | 让绘制点或移动中的内容吸附到可见网格、附近对象或线条端点。 |
| 紧贴、对齐 | 比较边缘、中心和间距，帮助移动内容时贴合或排齐。 |
| 角度与步长 | 设置绘制时使用的角度间隔和步长；是否生效取决于当前工具。 |
| 属性、时间轴按钮 | 显示或隐藏对应面板，为舞台调整可用空间。 |
| 放大、缩小按钮 | 改变当前视图倍率。 |

创建和调整辅助线：

- **水平辅助线**：从底部标尺向画布内拖动，在画布内松手放置。
- **垂直辅助线**：从右侧标尺向画布内拖动，在画布内松手放置。
- **调整辅助线**：按住 `Ctrl` 拖动已有辅助线；拖到可见标尺上松手可删除，按 `Esc` 可取消移动。

吸附与对齐提示会在操作时显示命中的边缘、中心或间距关系，帮助确认落点。须先开启吸附总开关及所需的分项。

辅助线保存在所属场景、元件或开放画布中，保存工程后仍会保留。标尺显示属于视图设置；其中的物理单位按固定的 96 px/in 换算，不代表屏幕上的实际物理长度。

#### 舞台右键菜单

![未选择对象时的舞台右键菜单](/images/stage-context-menu.png)

这是未选择对象时的右键菜单。没有适用选区的命令会显示为灰色，部分分组不会出现。

![选中对象后的舞台右键菜单](/images/stage-context-menu-selection.png)

这是选中绘制对象后的右键菜单。同一菜单会根据选区更新命令及其可用状态。

在舞台内右键即可打开上下文菜单。菜单会根据指针所在对象、当前选区、工作区和图层状态更新；没有适用目标的项目会隐藏或禁用。

| 菜单项或分组 | 用途与可用条件 |
| --- | --- |

| 删除、拆散 | 处理适用的嵌套实例或绘制对象；是否出现取决于右键目标和选区类型。 |
| 线条 | 将线条转换为填充，或合并、简化线段；有适用线条时才显示。 |

右键空白区域不会自动取消已有选区；要查看无选区状态，请先取消选择。右键对象时，菜单会将命中的对象作为上下文目标。图层锁定、对象类型不支持或选区不满足条件时，相应命令会变灰或隐藏。

### 属性面板

![文本工具的属性子页面](/images/properties-panel.png)

文本工具的属性子页面

**属性面板** 位于界面右侧，用于显示和修改当前工具、选中对象、图层、场景或文档的参数。

面板既可以通过右侧图标手动切换，也会在选择工具、对象或补间时显示相应设置。可通过舞台上方的属性按钮、视图菜单或 `F1` 显示和隐藏整个面板。

#### 页面分类

右侧图标分为“属性”“外观”“相机”和“场景”四类。“属性”展开后，还可以切换“对象”“工具”和“文档”三个子页。当前页面会以强调色标出，将指针放在图标上可以查看名称。

| 页面 | 主要用途 | 显示条件 |
| --- | --- | --- |
| 属性 → 对象 | 查看选区信息，调整位置、尺寸和外观；文字、图片、元件实例等会显示各自的设置。 | 需要有可查看的对象、正在编辑的文字或适用的补间。没有目标时，对象按钮不可用。 |
| 属性 → 工具 | 查看当前工具的选项，例如笔刷笔尖、形状设置或新建文字的默认格式。 | 内容随当前工具变化；工具不可用时，相应选项也会受到限制。 |
| 属性 → 文档 | 查看工程名称、保存位置、当前场景和图层信息，以及画布背景、播放设置和工程概况。 | 手动打开，不要求选中对象；显示当前工程和场景的信息。 |
| 外观 | 编辑填充、描边等绘制外观。 | 用于基础绘制、场景绘制或遮罩编辑等绘制环境；图片和导入 SVG 等选区可能没有可编辑的填充或描边。 |
| 相机 | 查看和调整镜头相关设置。 | 需要进入“场景与动画”。 |
| 场景 | 查看场景、播放和灯光等设置。 | 需要进入“场景与动画”；具体项目随场景和当前编辑范围变化。 |

“对象”页修改已有内容，“工具”页设置当前工具的行为或之后新建内容的默认值。例如，修改选中文字的字体应使用对象页；设置之后创建文字的字体则使用工具页。两者不会因为切换页面而互相覆盖。

外观页会区分选区和当前绘制外观。没有选区时，修改的是后续绘制使用的外观；有可编辑选区时，修改会作用于对应内容。

#### 自动切换与手动切换

**自动切换**

- **在工具栏选择或重新启用工具**：切换到工具页，显示该工具的设置；已有选区不等于正在编辑对象参数。
- **在舞台上选中新的对象或元件实例**：切换到对象页，并根据选区类型显示设置；多选时显示选区信息和可共同修改的项目。
- **对象页失去编辑目标，例如取消选择**：返回工具页，不会自动打开文档页。
- **选中时间轴中的补间**：普通对象补间显示在对象页，镜头补间显示在相机页。
- **打开镜头页面或添加场景灯光**：分别显示相机页或场景页。

**手动切换**

- **点击分类图标或属性子页图标**：手动切换页面，不会因此切换工作区或绘图工具，也不会清空选区。
- **从外观摘要等位置打开更多设置**：转到对应页面，例如从对象外观打开外观页。

**播放与帧更新**：面板中的数值和内容会更新，但不会仅因逐帧刷新而反复切换页面。

自动切换主要跟随主动操作。手动打开文档、外观或场景页面后，仍可继续查看；之后重新选择工具或改变对象选区时，面板会再次显示相应页面。

面板隐藏时，选择工具或对象不会自动把它展开。重新打开后会显示当前页面及其内容。

#### 不可用状态与滚动

- **在基础绘制中打开相机或场景页**：显示需要进入“场景与动画”的提示；只有点击提示中的切换按钮才会改变工作区。
- **当前编辑范围不支持绘制外观**：外观页显示提示，不会自动跳到基础绘制。
- **选区没有可编辑的填充或描边**：外观页显示说明，相关控件不可用；可返回对象页查看该类型的其他设置。
- **当前对象或图层不允许修改**：相关参数可能只供查看或被禁用；切换页面不会解除锁定或改变编辑权限。

面板宽度不足时，分类图标会改为顶部下拉列表；属性子页横向排列，功能不变。

较长的页面可以在面板内滚动，各设置分区也可以独立展开或收起。收起分区只隐藏设置，不会关闭对应功能或重置参数。

### 时间轴

![图层与时间轴](/images/timeline-panel.png)

图层与时间轴

**时间轴（Timeline）** 位于界面底部，用于组织图层，并决定内容在每一帧的状态。

左侧是图层区域，右侧是帧格。竖直播放头表示当前帧；移动播放头后，舞台和属性面板会同步显示该帧的内容。

图层区域用于新建、排序、锁定和隐藏图层，也可以建立文件夹、遮罩和父子关系。

帧区域显示 Cel、保持曝光、关键帧和补间。常用操作包括按 `F5` 插入帧、按 `F6` 插入关键帧，以及按 `F7` 插入空白关键帧。

基础绘制显示当前元件的时间轴，场景与动画显示场景的图层、地形、灯光和镜头轨道。可以通过舞台上方的按钮、视图菜单或 `F2` 显示和隐藏时间轴。

## 工作区

| 工作区 | 主要用途 | 舞台内容 |
| --- | --- | --- |
| [基础绘制](#基础绘制) | 绘制角色、道具等可重复使用的素材。 | 当前元件或开放画布。 |
| [场景与动画](#场景与动画) | 组织镜头，制作逐帧动画和补间动画。 | 场景中的手绘内容、元件实例及相机画面。 |

### 基础绘制

**基础绘制（Basic Drawing）** 用于制作和修改可重复使用的元件，也可以在开放画布上准备尚未整理成元件的素材。

这个工作区适合先绘制角色、道具、特效，以及其它可以多次放入场景的内容。

“当前”用于编辑当前元件，修改会更新所有引用。“开放”提供独立的项目画布，用于整理临时素材。

开放画布中的选中内容可以转换为新元件，原内容仍会保留。

### 场景与动画

**场景与动画（Scene & Animation）** 用于组织完整镜头。

场景可以同时包含手绘内容和素材库中的元件实例，并通过图层、关键帧、曝光和补间制作动画。

二维正面视图可以直接绘制逐帧内容，也可以放置元件实例。

修改源元件后，所有实例会同步更新。场景自己的手绘内容只属于当前场景。

相机和构图由时间轴中的“镜头”分组管理。

### 工作区切换

![工作区与编辑范围切换](/images/workspace-tabs.png)

工作区与编辑范围切换

点击舞台上方的标签即可切换工作区，也可以使用以下快捷键。

| 快捷键 | 切换结果 |
| --- | --- |
| `Ctrl+1` | 基础绘制。 |
| `Ctrl+2` | 场景与动画。 |
| `Ctrl+3` | 场景与动画，并打开时间轴中的“镜头”分组。 |

切换工作区只会改变编辑范围，例如从元件切换到场景，不会复制或移动素材。

## 界面设置

### 中英文切换

界面语言可在“编辑 → 设置 → 常规”中切换，当前支持 **English** 和 **简体中文**。

应用设置后，菜单、工具提示、属性页和主要对话框会更新为所选语言，并在下次启动时继续使用。

语言设置只影响编辑器界面，不会翻译工程名称、图层名称或文本对象中的内容。

### 主题与外观

编辑器提供 **Dark、White 和 Charcoal** 三种界面主题。当前截图使用 Charcoal（碳灰）主题。

主题可以进一步调整色调、饱和度、亮度和强调色，也可以单独设置工作区背景颜色。

主题只改变编辑器控件和工作区背景，不会修改图形或导出结果。工具栏位置、窗口边角和时间轴帧格尺寸也在设置中管理。

### 面板显示与隐藏

| 面板 | 显示与隐藏方式 | 快捷键 |
| --- | --- | --- |
| 属性面板 | 舞台上方的属性按钮，或视图菜单。 | `F1` |
| 时间轴 | 舞台上方的时间轴按钮，或视图菜单。 | `F2` |
| 层级窗口 | “视图 → 层级”。 | — |

隐藏面板后，释放出的空间会让给舞台；当前选择、图层和时间轴内容不会被删除。

层级窗口独立于主界面，可以单独移动。

窗口空间不足时，素材库、属性面板和时间轴会自动收紧。这只影响布局，不会改变工程数据。
