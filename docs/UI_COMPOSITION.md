# UI 组件组合

当前 UI 使用程序化 WinForms。AI 修改源码时，从 `native/UI/MainForm.UiComposition.cs` 的组合列表入手；列表使用从上到下的视觉顺序，不需要自行推算 WinForms 的反向 Dock 顺序。

## 检查器分类与触发边界

检查器分类由 `MainForm.InspectorRail.cs` 统一呈现。选择、工具、帧与工作区的普通刷新不得更改 `_inspectorCategory`；只有分类按钮、分类快捷键和明确的领域编辑命令可以导航。重复点击当前分类不关闭页面；不适用的上下文显示原因和显式工作区进入按钮，不借分类切换自动改变工作区。镜头时间轴上下文不能覆盖手动分类选择。检查器宽度小于 324 逻辑像素时以顶部分类选择框替换图标栏；该入口与图标栏使用相同导航规则，不依赖对象选择。笔尖导入与预设在窄栏换行，形状和铅笔字段按 48% / 52% 分列。

组合根固定分配宿主：属性页容纳对象／实例、文字、图像、空间材质和普通补间；工具设置页容纳笔尖、混色、铅笔和形状绘制参数；外观页容纳材质编辑器及编辑目标提示；场景页容纳场景、播放和灯光；镜头补间继续使用镜头页既有挂载入口。复用控件与事件，不复制线宽／颜色状态。工具和选择仅决定所属页内部适用模块，不能将整页自动替换为其他分类。

## 组合接口

`UiComposition` 只接收 WinForms 控件、可选高度及填充控件，不依赖项目、Stage、MainForm 或业务事件。

```csharp
var shape = new ShapeSettingsPanel();
var image = new ImageInspectorPanel();
var page = new ThemedScrollPanel();

shape.SetState(new(ShapeKind.Star, 5));
image.SetState(new("image-id", "sprite.png" + Environment.NewLine + "1920 × 1080"));

UiComposition.MountVertical(page.Content,
[
    new(shape, shape.PreferredHeight),
    new(image, image.PreferredHeight)
]);
page.PerformLayout();

shape.SettingsChanged += (_, e) => ApplyShapeSettings(e.State);
image.SettingsRequested += (_, e) => OpenImageSettings(e.AssetId);

// 重新排列既有组件：保留实例、状态和事件。
UiComposition.OrderVertical(page.Content, [image, shape]);
page.PerformLayout();

// 普通 Panel 也可作为宿主，最后一个参数占满剩余空间。
UiComposition.MountVertical(parent, [new(shape, shape.PreferredHeight)], fill: details);
parent.PerformLayout();
```

示例中的命令由宿主实现。控件类型在同一个程序集内可直接使用，不需要另建框架或容器。

- `MountVertical` 增加或移动指定组件，保留未列出的兄弟控件，不负责删除或释放控件。
- `OrderVertical` 只排列当前宿主内的组件，跳过暂时属于其他宿主的组件。
- 隐藏的组件不占 Dock 空间；显示、启用状态由宿主控制。
- 组件的 TabIndex 随视觉顺序更新，键盘导航顺序与排列保持一致；组件内部仍管理自身焦点。
- 高度省略时保留控件现有高度或 AutoSize 行为，不强制所有面板采用统一尺寸。
- 重复组件、已释放控件、负高度或父子循环在修改布局前被拒绝。
- 接口暂停布局并以 `ResumeLayout(false)` 结束，允许外层批量组合；外层结束后调用 `PerformLayout` 或 `ThemedScrollPanel.ResumeContentLayout(true)`。
- 一个 WinForms 控件只能属于一个父容器。需要同时显示两份时分别创建控件，通过宿主同步状态。
- 所有创建、布局、状态设置与事件处理在 UI 线程进行；父容器负责释放子控件。组件移动时，`ThemedScrollPanel` 会解除旧容器的滚轮订阅，并接入新容器。

## 组件边界

| 组件 | 状态输入 | 用户意图 / 输出 | 依赖方式 |
| --- | --- | --- | --- |
| `ShapeSettingsPanel` | `SetState(ShapeSettingsState)` | `SettingsChanged`，含形状和顶点数量 | 无 DrawSettings 实例订阅或修改 |
| `ImageInspectorPanel` | `SetState(ImageInspectorState?)` | `SettingsRequested`，含资产 ID | 宿主查询资产、格式化摘要和打开编辑命令 |
| `SelectionSummaryPanel` | 四个文本属性 | 只读展示 | 宿主计算选择、图层和统计信息 |
| `LayerBlendModePanel` | `SetLayer` / `ClearLayer` | `BlendModeChanged` | 宿主同步当前图层并执行混合模式编辑，控件负责标题、图层名称与选择框的展示 |
| `TextSettingsPanel` | `SetSettings` | `SettingsChanged` | 既有独立状态接口 |
| `BrushTipPanel` / `MixingBrushSettingsPanel` | 各自的 `Set*` | 各自的设置事件 | 既有独立状态接口 |
| `SpatialMaterialPanel` / `SceneLightingPanel` | `SetMaterials` / `SetLights` | 类型化编辑、选择事件及交互开始/完成/取消 | 宿主保留撤销与模型更新规则 |
| `SceneEditorPanel` / `PlaybackSettingsPanel` | 既有绑定 / 属性接口 | 各自的场景命令 / 播放设置事件 | 同一检查器中的平级组件，可分别重排 |

宿主分工：`MainForm.UiComposition.cs` 负责位置与排列，`MainForm.WorkbenchCommands.cs` 连接事件，检查器和领域 partial 负责计算状态与执行原有编辑命令。叶组件不查找 MainForm、不引用兄弟组件，也不通过父容器查询业务状态。

## 检查器模块标题与分隔线

检查器顶部的“图层”标题由 `native/UI/LayerBlendModePanel.cs` 管理。`MainForm.UiComposition.cs` 负责挂载与排列面板，标题通过 `InspectorModuleStyle.CreateTitle` 复用字体、颜色和对齐规则，内部定位由叶组件维护；标题样式不改变图层模型或混合模式编辑流程。

- 标题使用 `Theme.UiFont(8.5f)` 的常规字重，靠左上对齐。面板左侧内边距为 4、顶部内边距为 0，标题不额外添加内边距；这些数值沿用 WinForms 的缩放机制。
- 标题颜色从当前 `Theme.Panel` 与 `Theme.Text` 按 50% 混合，并通过 `Theme.ReadableUiColor` 保持可读性，与时间轴左侧图标采用一致的柔和配色。绘制时重新获取主题颜色，高对比度模式使用 `SystemColors.ControlText`。
- 标题以单行主题文字绘制，窄栏使用省略号，禁用时使用可读的主题禁用色，不采用系统 Label 的浮雕阴影。选择摘要和形状参数标签复用 `InspectorModuleStyle.CreateTextLabel`，保持同样的禁用绘制规则与既有对齐方式。
- 当前图层名称在标题旁左对齐，使用 9pt 常规字重和 `Theme.Text`，标题列按本地化文字自适应宽度，后留 10 的间距，再显示 8 的圆形图层色标与名称；长名称省略，悬停和可访问描述提供完整名称。色标颜色由宿主在 `SetLayer` 中传入，绘图上下文使用 `GetLayerColor`，场景上下文使用 `SceneLayerDefinition.ColorArgb`，与时间轴一致；清空状态移除色标和提示。混合模式继续独占下一行，与标题之间保留较宽松间距，底部留白为 16。调整标题时，应保留 `SetLayer` / `ClearLayer` 的状态刷新保护和 `BlendModeChanged` 的事件边界。

“着色”模块由 `MaterialEditorPanel` 管理，其标题也使用 `InspectorModuleStyle.CreateTitle`，与“图层”保持相同的 8.5 常规字号、柔和主题色和左上对齐。标题左侧内边距为 4，顶部和底部各保留 10 的留白，填色／描边行高为 50；字段通过行边距补偿保留原有水平位置。

模块边界使用 `InspectorModuleStyle.DrawBottomDivider` / `DrawDivider`：`LayerBlendModePanel.OnPaint` 绘制底部边界，组合根连接检查器宿主绘制事件，补齐外侧内容留白，使分隔线两端贴齐检查器边缘。模块线与着色内部分组线共用 `DividerColor`，即 `Theme.Panel` 与 `Theme.Border` 按 55% 混合；模块线宽为内部分组线的 1.5 倍（96 DPI 下分别为 1.5 与 1），随 DPI 缩放，高对比度模式使用系统文字色。边界绘制不增加焦点、命中区域或业务绑定。后续模块可复用这个绘制入口；组合根负责模块顺序，叶组件负责自身标题及边界。

通宽模块线用于识别可独立组合的面板边界，着色内部随内容缩进的较细分组线继续表示模块内分组，两者保持不同的视觉层级。本次建立展示约定，不引入运行时拖拽或模块配置协议。

## 图片与形状检查器

条件模块与常驻模块使用同一字段规范。`InspectorModuleStyle.CreateFieldLabel` 提供 8.5pt 次级标签和无浮雕的禁用文字；`StyleField` 统一完整字段的 32 逻辑像素最小高度、上下 4 的间距及数值 11pt 字号，下拉列表仍保留原菜单字号和行高。文本、工具、实例、灯光及空间材质字段通过各自布局预留足够行高，不能只扩大子控件而不更新宿主高度。常规属性采用 48% / 52% 标签／输入列；笔尖复合形状编辑器给两个输入保留较宽的整体列，滑条与空间 XYZ 联合编辑器保留紧凑排列。

空间材质的标题、覆盖开关和预设分行，投射／接收阴影分别占一行，避免窄栏截断操作名称；灯光名称和 Codex / MCP 单行字段使用 `ModernTextInput`，令牌通过内部原生编辑器的密码模式遮蔽。上述变化只负责展示，不改变绑定、事件、连续编辑边界或领域数据。

下拉框收起态在离屏缓冲绘制文字时显式传入当前字段背景色，防止浅色主题下透明文字绘制产生黑色重影；不改变弹出菜单和选择行为。

和谐色展开时在同一次布局事务中更新内容可见性、行高与面板高度，避免展开标志已生效但末行缓存仍为零高度。滤镜面板总高度覆盖四组 32 像素字段及底部两个颜色操作，不能沿用较矮字段时期的总高度。

图片检查器使用固定行的单列布局：标题、8 行图片摘要、8 逻辑像素间隔和 32 逻辑像素高的主题设置按钮。摘要每行单独省略，长文件名或路径不折行挤占其他信息；完整文本保存在悬停提示及可访问描述中。形状边数／顶点数输入框采用 40 行步长、32 控件高度和 11pt 数值文字，继续按 48% / 52% 分列；控件事件与宿主命令边界不变。

## 场景与播放检查器

`SceneEditorPanel` 和 `PlaybackSettingsPanel` 沿用与着色模块一致的 `InspectorModuleStyle.CreateTitle`：小字号、柔和主题色、左上对齐。两个面板采用左 4、右 8、上 10、下 16 的内边距，字段额外缩进 4。场景参数保留 96 的标签列，镜头投影下拉框随参数列伸展；播放数值参数使用下述半栏输入规范，不再套用固定 96 的标签列。

场景模块首选高度为 340，基础信息行高为 40，列表操作标题行高为 36；场景与实例列表保留上下间距，关闭整数项高度约束以填满可用区域。播放模块首选高度为 204，四个参数行高为 36，以 TableLayoutPanel 替代绝对坐标，统一标签与编辑器对齐。循环开关只显示开关本体，说明由左侧字段标签提供。

布局由两个叶组件各自维护，组合根读取首选高度。已有场景选择、实例双击、添加命令、投影切换、播放参数事件、帧范围约束和 `_updating` 刷新保护保持原有边界。

## 镜头与导演检查器

`ShotDirectorPanel` 的相机列表标题与所选相机属性标题复用 `InspectorModuleStyle.CreateTitle`，采用 8.5pt 常规字重、柔和主题色和左上对齐。标题左侧缩进为 4，属性字段左右边距为 8，单行属性按 48% / 52% 分配标签与输入列，采用下述标准输入框契约。

单参数控件高度为 32、行步长为 40，相邻外框净距为 8，与播放面板一致；数值字号为 11pt，文字及下拉菜单字号保持原有约定。位置／旋转使用与单行输入框同列同宽的暗色向量组，内部 XYZ 纵向排列，每行 32、上下内边距各 4，组后留白也为 8；宽高比与向量组之间、正交尺寸与重置按钮之间不再叠加额外空行。数值左侧采用主题强调色底的 X/Y/Z 轴标徽章，轴向细色条提供辅助识别，行间使用轻分隔线；点击轴标聚焦对应数值，高对比度使用系统颜色。组内复用原有 ModernNumericUpDown，GroupedAppearance 仅隐藏空闲时的独立外框，保留焦点、高对比度及编辑事件。窄布局中相机列表与属性区之间留 12。顶层相机标题不添加顶部内边距，与图层模块标题对齐；标题、工具栏高度分别为 24 与 34，尺寸沿用 `ScaleMetric` 适配 DPI。宽布局仍并排展示列表与属性，窄布局仍上下堆叠，属性区滚动和共享曲线编辑器保持原有归属。

顶部相机／帧数／时长摘要与属性区帧／关键帧／补间统计不常驻显示，分别通过相机模块标题和当前相机标题的悬停提示提供。未选中时不显示操作指导行，属性布局不为隐藏提示预留高度；提示资源随面板释放。

相机名称与描述复用 ModernTextInput，统一主题字段背景、分界线色描边、焦点状态与圆角偏好；布局高度取组件 PreferredFieldHeight 与行高的较大值，避免底边裁切。工具栏采用紧凑宽度和统一间距，重置按钮不再撑满属性区。相机列表移除原生边框及交替深色行，使用柔和选中底色、内缩颜色标记与 48 逻辑像素行高；次级行只显示本地化投影类型，属性标题取消额外顶部留白。

这些展示调整不改变相机激活、增删重排、定位、投影与构图参数、连续编辑事件或撤销边界。

## 检查器工作区切换动画

`MainForm.ShowWorkspace` 在基础绘制、场景与动画、镜头与导演之间切换时，使用 `InspectorTransitionOverlay` 为右侧检查器提供 180ms 的过渡。真实控件沿原有流程绑定、排列并恢复布局，覆盖层只保存前后快照，以缓出曲线淡出旧内容、淡入新内容；新内容从下方 6 个逻辑像素移到原位。画布与时间轴不参与该动画，过渡期间覆盖层拦截检查器鼠标输入，不改变真实控件状态或事件绑定。

首次展示和同工作区刷新不播放动画。连续切换从当前过渡画面重新开始，不排队；宿主大小或可见性变化、系统禁用动画或高对比度、快照捕获失败时取消过渡并直接展示真实目标控件。快照超过 800 万像素时跳过捕获。覆盖层由检查器宿主拥有，释放时解除订阅并销毁计时器与位图；新类型注册到 UI 热重载模块。自绘控件快照的视觉完整性仍需实际界面验收。

## 工具栏图标开关

时间轴的自动关键帧、运动轨、洋葱皮与画布右上角 `DrawSnappingStrip` 的六个吸附开关，共用 `SvgToggleButton` 的 `IconOnly = true`、`ShowCheckedBackground = true` 绘制路径。选中时图标下方显示圆角胶囊底色，颜色按宿主背景和主题文字色混合；未选中时使用宿主背景，悬停和按下沿用控件的渐变反馈。该路径不使用另一种按钮样式的底部强调条。

圆角、底色、主题对比度与焦点反馈由 `SvgToggleButton` 管理，宿主仅设置尺寸和图标大小：吸附栏保留 28 × 28 的按钮、20 的图标，时间轴沿用现有尺寸。高对比度模式使用系统选中色和矩形底色。吸附栏保持 `DrawSettings` 的状态读回、`_updating` 防反馈、点击/空格切换、说明提示和窄窗口布局；统一选中外观不改变吸附行为。

工作区按钮等分段选择按钮通过 Theme.StyleSegmentedButton 统一底色：未选中时将面板色向主题文字色混合 6.5%，悬停 10%，按下 4.5%，让深浅主题都保留轻微但清晰的按钮轮廓。选中状态继续使用主题强调底色，尺寸与布局保持稳定。

## 弹出菜单视觉约定

主菜单、二级菜单和上下文菜单复用 `AnimatedContextMenuStrip`。菜单保留 30 的操作行高、7 的外侧留白、随个性化设置切换的直角／4 逻辑像素微圆角外框与悬停底色，圆角随 DPI 缩放；窗口区域与圆角外框一致。悬停背景复用 `Theme.MenuSelectionSurface`（面板底色与强调色按 28% 混合）；正文与快捷键分别以 `Theme.Text` 和 `Theme.Muted` 为首选色，通过 `ReadableText` 保持可读对比度，外框使用 `Theme.ControlOutline`，子菜单箭头通过 `ReadableUiColor` 提高辨识度。菜单每次展开刷新主题和窗口区域，避免角样式切换后残留旧轮廓；分隔线采用淡化的主题边框色。

所有命令子菜单在 `StyleItem` 中统一为 `AnimatedContextMenuStrip`，迁移原菜单项实例以保留事件、Tag 和勾选状态；动态新增的嵌套项使用同一入口。宽度依据正文、快捷键、勾选／图标与箭头共同测量，逻辑宽度范围为 224–480；尺寸与留白随 DPI 缩放。二级菜单直接展开，不使用一级菜单的开场位移。调色浮层等嵌入编辑器保持其专用布局。

渲染器在菜单项局部坐标中绘制高亮与分隔线。高对比度模式恢复矩形区域和系统文字／选中色，系统关闭动画时跳过开启动画。原有点击、子菜单、勾选、禁用、快捷键和键盘导航继续由 ToolStrip 管理。

下拉选择框通过 `Theme.StyleComboBox` 和 `DrawComboBoxItem` 统一选项行：30 逻辑像素行高、跟随直角／微圆角方案的内缩选中底色、12 的文字留白，与命令菜单使用一致的主题配色。列表最多显示八行，展开时根据当前项目数更新高度，更多选项使用原生滚动和键盘选择。关闭状态高度仍由 `ComboBoxSurfaceAdapter` 独立维护；文字和箭头按 ClientSize 居中，不能用包含非客户区的外部 Height 计算；原生下拉窗口外框仍由系统管理。

时间轴工具栏与页签栏下沿的横向分隔线也使用 Theme.ControlOutline，厚度按 1.5 逻辑像素随 DPI 缩放并向上取整（100% 缩放为 2 像素），在内容绘制结束后向栏内填充实心横条，防止抗锯齿衰减和背景覆盖，避免页签栏通过对比度增强产生亮色长线。

## 控件描边

`Theme.ControlOutline` 统一交互控件外框与模块分隔线的颜色，普通主题按面板色与边框色混合 55%，高对比度使用系统窗口文字色。图标按钮、普通按钮、开关按钮、工作区色块、颜色目标按钮、数值输入、下拉选择框和命令菜单外框均使用该颜色，悬停、选中和焦点不再把外框提升成亮白或强调色。选中底色、图标和独立的键盘焦点提示继续保留；直角／微圆角仍由个性化设置控制。
滑动条 `ModernSlider` 使用 CSS 风格的三层表面：轨道使用 `PanelStrong` 与 `Border` 的低对比混合色，进度使用 `AccentSurface` 与 `Accent` 的主题色混合，滑块使用 `PanelStrong`／`PanelHover` 的紧凑圆形表面，外框和刻度使用 `Theme.ControlOutline`。悬停只提升进度和滑块表面，拖动保留按下动画；禁用状态降低填充和刻度对比度。暗黑模式不再把整条轨道提升为白色，高对比度仍使用系统颜色。

状态统计统一放在底栏：渲染 FPS、UPS／动画 FPS、绘制数、原子数、缩放及当前帧只显示一份。上方参数行保留工具操作，移除统计文字。辅助状态使用 Theme.SecondaryText 的柔和灰色，工作区颜色说明、网格说明和热重载正常状态降为同级，失败和恢复仍保留错误／警告色。

文本框和列表框通过 Theme.NativeFrames 的 NativeFrameAdapter 绘制非客户区边框，使用 ControlOutline，保留原生输入、选中、滚动和键盘行为。文本框左右内边距为 7 逻辑像素，随 DPI 调整；不套额外容器，不改变绑定或布局。NativeFrameAdapter 独占非客户区计算和边框绘制，不在原生计算后叠加边距；根据当前字体高度将原生文字和光标居中，外框复用 Theme.PaintUiSurface，跟随直角／微圆角偏好；列表保持矩形结构。完整检查器输入框采用下述标准高度，紧凑高度只用于明确的辅助控件。和谐色选择器不再限制为 156 逻辑像素，按统一输入列伸缩；所在行根据选择框实际高度加上下留白更新，响应 SizeChanged 与 DPI，避免固定行高裁切底边。

## 检查器输入框与留白契约

本节是检查器后续新增、改版和条件面板修正的布局基线，不要求一次性重排所有尚未修改的面板。常驻面板和仅在特定工具、选择或工作区中出现的面板适用同一规范；不能只检查默认可见状态。所有像素值均为 96 DPI 下的逻辑像素，实际尺寸随 WinForms DPI 缩放，不固定物理像素。

### 尺寸与对齐

- 以已经确认的描边“宽度”数值框为尺寸基准，而非扩大整栏或直接复制参考图的绝对尺寸。完整属性行采用左标签、右输入框，内容列按 48% / 52% 分配，输入框约占半栏并随可用宽度伸缩。
- 混合模式收起框、描边宽度、和谐色收起框使用同一左右边界和 `Theme.ControlHeight`（32）高度。播放 FPS、开始和结束也沿用半栏宽度与标准高度。着色面板 HEX 是色样、HEX 标签、可伸缩文本框和复制操作构成的复合行，不再限制半栏宽；文本框仍保持标准高度。高度独立于字号，不能靠增大字体撑高控件。
- 颜色通道滑条旁的辅助小数值框、工具栏数值和分段按钮保留各自的紧凑布局；不把它们强行扩成半栏。该例外不适用于完整属性输入框。
- 对齐以共同宿主中的最终 Bounds 为准，不以各自面板内的百分比相同代替。必须计入滚动页 ContentPadding、内层 Margin/Padding、列取整及 DPI；基础绘制页目前有右侧 2 的 ContentPadding，图层面板在自身布局中补偿该差异。
- 标签与输入框的垂直中心一致；固定高度参数行不能被 Dock Fill 的剩余空间拉高。面板首选高度及最小高度覆盖实际控件高度、行边距、标题与底部留白，避免下沿裁切。
- 连续参数输入行采用播放面板的间距节奏：32 高输入框、40 行步长，即外框间净距 8。相机向量组与相邻参数也使用 8 的外部间距；组内轴行保持连续，不逐行叠加该间距。模块标题、分隔线及颜色编辑区按各自分区留白约定，不把分区间距重复加在每个参数之间。

### 字号与展开菜单

- 数字是数字的字号，汉字及其他文字是文字的字号：标准数值输入及单位采用 11pt 常规字重；文字选择项、HEX 等保持各自文字字号。混合模式收起框文字与左侧标签字号一致，不套用数值的 11pt。
- 仅调整收起框外观时，使用 `Theme.StyleComboBoxSelection` 独立设置收起框高度和文字绘制，不修改 ComboBox.Font、ItemHeight、DropDownWidth、选项、选中事件或菜单绘制来间接实现尺寸。
- 已有展开菜单的字体、行高、宽度、滚动、键盘及选择行为保持不变。和谐色原有菜单字体也保留；收起框与展开菜单可使用不同字号。
- “颜色”“高级设置”等折叠标题悬停、按下和展开时只强调文字与箭头，不增加整行背景高亮；保留键盘焦点提示。

### 颜色区间距

- 颜色编辑默认展开，以颜色折叠标题、填充／描边、材质类型、大色域、HEX 复合行、不透明度、颜色通道、最近使用及和谐色形成阅读顺序；专用描边和端点设置继续按目标显示。
- 默认使用 HSV 色域，HSV／HSL 的主分量使用下方横向色相条；RGB／Lab 继续使用右侧主分量条，保持各自的计算与轴含义。色域容器高度为 232、顶部留 8、底部留 12；横向色相行高 36，竖向主分量列宽 24。不挤占和谐色空间，也不把 RGB 色面伪装成 HSV。
- HEX 复合行显示当前色样、完整编码及复制操作。完全不透明时显示 #RRGGBB，带透明度时显示 #RRGGBBAA；原有两种输入格式仍可提交，6 位输入仍表示不透明。点当前色样打开已有色板，不另外增加一套取色弹窗。
- 颜色面板以原生 WinForms 控件落地：填色使用实色色样，纯色描边使用空心轮廓色样；材质与颜色模型的分段按钮以底色和短下划线标识选中。HEX 标签嵌入 ModernTextInput 的前缀区，复制使用带可访问名称及工具提示的紧凑图标按钮。水平色相与不透明度滑条使用细轨道、圆形手柄，仍沿用原有命中、键盘和连续编辑事件；这些外观选项不改变其他面板的默认控件样式。
- 通道标签保持当前上置布局。数值框与和谐色选择框沿用现有标准尺寸、菜单及主题契约；最近使用和和谐色色块跟随父区背景，避免额外深色条带。微圆角、直角及高对比度仍由既有偏好和系统状态控制。
- 不透明度使用独立的两行布局：第一行标签与 100 逻辑像素宽的百分比输入，第二行完整滑条。显示 0–100%（一位小数），内部 Alpha 和滑条仍使用 0–255；界面换算不改动素材与工程的透明度存储。
- 「颜色通道」默认折叠，展开后先显示 RGB／HSV／HSL／Lab 模型按钮，再以三列展示各通道标签和数值。模型范围、Lab 小数精度、连续编辑事件保持不变；隐藏滑条只作为原有通道状态的内部桥接，不参与布局与焦点。
- 最近使用色直接复用现有 RecentPalette，无历史时不显示空模块；按现有完成／离散编辑边界记录，拖动中不增加历史。直接显示最近 8 色，色块以 24 为最小尺寸自适应栏宽、间距为 6 并响应 DPI；窄栏允许换行，按实际行数计算高度。点色样保留当前 Alpha，全部颜色与渐变预设仍从原色板入口访问。
- 和谐色保持独立折叠，默认收起；展开后的规则行按 48%／52% 分配，行高跟随实际选择框和 DPI。折叠不重置规则、颜色、模型或渐变色标，关闭再打开颜色编辑器保留两个子区的展开状态。面板高度按实际可见区累计，不预留隐藏内容的空白。

### 截图验收

- 必须先完成构建再用新程序集截图；截图正常宽度与最窄支持宽度，展开颜色编辑器，并触发相关特殊工具／选择面板。
- 使用与真实检查器相同的挂载层级、ContentPadding 和首选高度。不得为截图把面板强制撑高、截掉底部，或用等宽孤立面板截图代替实际宿主对齐检查。
- 同时检查外框左右边界、宽高、标签中心、字号、色块位置、分隔留白和底部完整性。尺寸比较转换到共同宿主坐标；展示图片还需人工查看，不能以 Bounds 或构建通过替代视觉验收。
- 模拟 Scale 不能表述为真实高 DPI 验证，未检查的真实 DPI、交互或展开菜单应明确说明。纯外观位置调整不自动运行产品回归，按根目录 AGENTS.md 的确认规则执行。

颜色输入使用独立组件 `ModernTextInput`：外层 `UserControl` 通过 `Theme.PaintUiSurface` 绘制主题表面和单层描边，内层无边框原生 `TextBox` 负责文本、选区、光标、粘贴和输入法。编辑器按实际字体高度垂直居中，横向留白为 8 逻辑像素。组件通过 PreferredFieldHeight 返回字体与 DPI 对应的安全高度；HEX 宿主行按该高度和上下留白分配空间。外框向内留一个设备像素，避免直角描边在非整数 DPI 时被底边裁切。公开 Text、MaxLength、CharacterCasing、ReadOnly、SelectAll，并转发键盘事件，保留原有解析、提交和取消处理；错误文字色由宿主控制。焦点与悬停改变表面色，不改变尺寸。外框随直角／微圆角偏好，主题颜色在绘制时读取；禁止将内层编辑器接入 NativeFrameAdapter。着色面板、专业颜色对话框与工作区颜色浮层的 HEX 字段统一采用该组件，新类型登记到 Shell 热重载模块。普通列表／文本框继续使用各自 Theme 入口。

## 素材库面板

`LibraryVaultPanel` 复用 `InspectorModuleStyle.CreateTitle` 的小号弱化标题、`Theme.StyleSegmentedButton` 分类按钮，以及 `ModernTextInput` 搜索框。搜索框通过 PlaceholderText 代理保留本地化提示；UiLocalization 将 ModernTextInput 视为编辑字段，不翻译用户输入，由内部原生编辑器处理提示与输入法。

标签筛选使用 DropDownList 与共享 `Theme.StyleComboBox`，避免可编辑原生输入区和白色箭头块。标签管理保留 SvgIconButton，采用 32 逻辑像素的图标按钮、无障碍名称和悬停提示，窄面板不再截断按钮文案。筛选区按输入组件 PreferredFieldHeight、下拉框实际高度与 DPI 分配两行，外层使用 AutoSize 行，保留搜索后 8、筛选后 10 逻辑像素留白，不以固定总高度压缩输入控件。分类间距为 4，列表入口采用 ControlOutline 分隔线。所有素材操作、稳定 ID、筛选延迟、标签赋值与拖放事件沿用原有绑定。

素材库图片分类的导入按钮使用 `SvgIconKind.ImportImage`，保留用户提供的 1024 viewBox 路径，通过共享 SvgIcons／SvgIconBitmapCache 缩放与缓存，颜色由按钮主题状态传入。SVG 链接和元件分类继续使用各自的添加／新建文件夹图标。

素材库的 Asset* 图标共享 24 单位画布、1.65 单位圆头／圆连接线宽，与导入 SVG 的 70.4/1024 路径厚度协调；工具栏和列表使用同一图标系列，实际像素尺寸由宿主和 DPI 决定。标签管理与顶部操作复用 StyleToolbarButton。该系列只替换素材库调用，不改变其他面板的通用图标；链接失效仍使用警告图标。

时间轴显示操作使用 SoloLayerVisible／AllLayersVisible，分别组合单层／叠层与右下角眼睛；叠层沿用用户提供 SVG 的菱形比例。工具栏文件夹、新增、父子关系与自动关键帧使用共享线性图标，保留原有命中区域、悬停提示和显示操作语义；不替换其他模块的原有图标。

时间轴文件夹使用 TimelineFolder，直接保留用户提供的 SVG 路径，并沿用共享图标主题颜色和 DPI 缩放。眼睛与图层轮廓留出间隙，避免线条叠在一起。

时间轴左侧操作图标绘制槽统一为 20 逻辑像素，标题图标为 22；独显／全部命中宽度为 28，组间留白收紧为 12。绘制尺寸与命中区域独立，图标缩小后保留完整点击高度。

时间轴线性操作图标的线宽与洋葱皮一致，采用图标画布尺寸的 1/12（24 单位画布中为 2）；文件夹 SVG 通过同色描边补齐等效轮廓厚度，标题图标同步加厚。图标尺寸和命中区域保持独立。

时间轴工具栏左侧操作和父子关系采用与洋葱皮一致的无描边圆角底色：选中时按明暗主题混合 16%／22% 文字色，悬停 8%，按下再提升 4%。独显／全部从实际图层可见状态计算选中，新增／文件夹使用瞬时交互反馈，父子关系使用实际开关状态。输入字段保留其编辑表面与焦点行为。

独显与全显反馈互斥：单层或所有层可见且只有当前可见层时，使用最近一次独显／全显操作区分；切换时间轴上下文时重置操作偏好。父子关系按钮维护显式悬停状态，移出、离开控件与重新绑定时清理并重绘，不将整个时间轴的焦点误画到该按钮。

界面自绘控件统一移除虚线焦点框，键盘焦点改为短实线提示；时间轴图标保持线性轮廓，不添加内部半透明填色，按钮仅在悬停与选中时显示胶囊底色，键盘操作保持可用。

素材库抽屉顶边由 LibraryVaultPanel 自身绘制 ControlOutline 分界线，线宽按 DPI 取整并完全落在客户区内，避免父容器边缘被内容覆盖；与工作区上方面板交接时保持柔和边界。

时间轴高度手柄和图层栏列宽手柄统一采用三点提示，分别横向／纵向排列，直径 2、间距 5 逻辑像素，使用 ControlOutline，交互时强调颜色。移除手柄额外长线和刻度，保留布局分界线和原有拖动命中区域。

时间轴图层区使用中性背景，选中和悬停表面内缩 2 逻辑像素并遵循主题圆角偏好。当前行用短图层色标标记，普通可编辑图层名称采用主文字色，隐藏／锁定行弱化；类型图标与名称留出 18 逻辑像素距离。保持既有行高、层级缩进、控制列、选择和拖动命中区域，帧格颜色不变。

素材库右上角新建／导入与打开操作共享相同按钮槽和线宽；打开图标使用圆角开放框与短箭头，轮廓范围统一为 3–21 图标单位，避免硬折角和箭头突出造成视觉不协调。

素材库新建文件夹按钮与时间轴文件夹按钮共用 TimelineFolder 图标，保留新建操作和悬停提示。

素材库搜索复用 ModernTextInput 的 SearchAppearance 外观：34 逻辑像素安全高度，左侧线性搜索图标与 32 的文字起点，微圆角模式半径 8，直角与高对比度沿用主题表面。搜索图标不改变搜索事件及输入法行为，普通 HEX 输入外观不受影响。

DrawingScopeButton 为元件入口的展示型双态按钮，不修改文档作用域；240ms cubic-out 滑块运动，当前状态停留 2200ms 后以 280ms 淡入元件名称。使用文字自适应宽度、DPI 缩放、主题颜色、高对比度、键盘点击和动画禁用偏好；计时器随组件释放，类型登记 Shell 热重载。

DrawingScopeButton 宽度仅按本地化开放／当前状态文字的最大测量宽度，加 36 逻辑像素的滑块与间距计算；元件名称不参与宽度计算，延迟显示时超长名称采用省略号，切换保持宽度稳定。文字测量与绘制均采用 NoPadding，避免多余留白。使用6px圆角轨道和4px圆角白色滑块，滑块内复用软件 Application.ico，图标随控件释放；不接入普通按钮的主题重绘适配器，避免控件自绘被覆盖。

## 扩展和验证

新增组件优先提供无参数构造、显式状态输入、类型化事件和尺寸属性。状态刷新应使用 `_updating` 防止触发编辑，连续手势沿用开始/完成/取消协议。复用 Theme、UiLocalization 和既有基础控件。

新类型同步登记 `native/App/HotReloadModules.cs` 的所属模块。当前 UI 树的结构变更仍使用现有进程重启与会话恢复策略。

组合回归位于 `Benchmark.AppIntegration.cs`，由 `RunUiRefreshStabilityRegression` 接入现有 `Render` 套件，覆盖视觉顺序、Fill、隐藏组件、重复挂载、跨容器与动态子组件滚轮解绑、独立状态/事件以及主题/语言截图。场景与播放的平级关系由现有工作区回归检查。使用仓库验证脚本的 `-Suite Build,Render -Plan` 先核对计划，再串行执行实际套件。

当前解耦主要覆盖检查器组合及以上组件。Timeline、Vault、部分 DrawSettings 控件仍使用既有模型绑定；它们可以通过组合接口放置，但更改其业务行为仍需要遵循原有宿主命令、撤销和数据契约。源码组合能力不包含运行时布局编辑器或 JSON 布局协议。

右侧检查器统一禁止可见滚动条：基础绘制、场景与动画及镜头属性通过 ThemedScrollPanel.ShowScrollBar=false 隐藏轨道并释放轨道占位，保留滚轮与键盘滚动。镜头属性复用该容器，取消系统 AutoScroll 滚动条。其他弹窗保持原有滚动条设置。

图层组齿轮直接调用 EditTimelineTabGroupOrder，复用 1000×640 逻辑像素的 TimelineTabGroupOrderDialog 和 ModernDialogForm 主题容器，不再经过设置菜单；确认时沿用 PerformTabGroupEdit 的原有编辑边界，右键组菜单仍提供颜色、重命名及删除。

图层组管理弹窗包含重命名、删除、排序、颜色和恢复默认颜色。配置在弹窗中暂存，确认后通过既有图层组编辑边界统一应用，取消不应用；内置组禁止重命名和删除。名称输入弹窗复用 ModernTextInput，关闭附加焦点下划线并保留主题边框。

同类管理弹窗优先复用 ModernDialogForm.ManagementDialogSize（1000×640 逻辑像素）；名称输入弹窗复用 NameDialogSize（440×224），保持简短输入窗口紧凑。图层组管理采用说明、组标签、操作栏、所选组图层列表、状态行的顺序布局；操作紧邻标签，剩余空间用于图层内容。

图层组管理采用紧凑组标签区，所选组名称与管理操作共用一行：标题靠左、操作靠右。下方图层列表使用带内边距的 36 逻辑像素行高和柔和行底色，保持 1000×640 窗口尺寸。

图层组标签超出窗口时采用细窄的主题横向滚动条，无系统箭头和白色轨道，支持滑块拖动、滚轮浏览与标签拖动时的边缘滚动。

图层组标签区使用 AutoSize 行高，通过 GroupScrollHost.GetPreferredSize 汇总实际标签内容高度、DPI 最小高度与滚动条预留空间，避免固定行高导致标签底边裁切。

按钮和菜单命令不再添加表示后续弹窗的固定省略号；仅在文本实际超长时显示截断省略号，加载状态、搜索提示及更多入口保留各自语义。

主菜单的设置与鸣谢入口使用纯文字。鸣谢入口打开主题对话框，显示鸣谢名单：聪明尼。


颜色与渐变预设弹窗按按钮右侧对齐向左展开，并限制在屏幕工作区内；下方空间不足时向上展开。内容高度覆盖全部固定行与内边距，标题复用模块标题样式并接入本地化，边框使用主题分界线色。

设置窗口采用统一的内边距与分区间距：主题色和高亮色并排调节，语言和个性化选项与左侧名称对齐，简洁选中高亮使用主题开关。颜色数值的单位只显示一次；常规与 Codex / MCP 页面切换保持窗口尺寸稳定。

时间轴顶部的前、后、帧高和帧宽标签使用浅色次级文字，保证深色主题下的可读性。

顶部网格与吸附工具使用统一高度和间距，吸附图标扩大可见绘制尺寸，辅助数值使用次级文字。配色色板弹窗统一分区标题、内边距和色块间距，默认色块与渐变预览使用柔和的主题边框，悬浮和选中仍保留清晰反馈。
