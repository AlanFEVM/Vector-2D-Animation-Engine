# Vector 2D Animation Engine 0.1.11

[文档索引](README.md) · [当前用户指南](USER_GUIDE.md)

发布日期：2026-08-03

0.1.11 新增实时光学/颜料混色、混色连通区域编辑，并完善素材面板与项目标签工作流。

## 重点更新

### 混色笔刷

- 新增 `Mixing Brush`。笔刷会采样活动图层中的已有填色，可选择线性光 `Optical` 光学混色或 Kubelka-Munk `Pigment` 颜料混色。
- 可调节混色力度、粘性、载色量、影响因子、笔刷大小和边缘柔度。离开采样颜色后，携带色会按影响因子逐渐恢复到当前 `Fill` 颜色。
- 光学模式支持同色反复叠加覆盖；颜料模式会持续计算吸收状态和过渡色，修复红色不纯以及跨颜色涂抹时的异常色偏。
- 笔迹按固定距离生成区域顶点，并只保存最终实时 ARGB 色值、点位、笔刷大小和三角形索引，不保存生成渐变或混色历史。
- 混色区域使用预乘线性光顶点色插值和透明外围顶点形成连续柔边，光学与颜料模式不再出现生硬边缘和分层色带。
- 折返、自交和反复涂抹会重新采样并计算受影响区域；同一图层顶部的连续混色结果会合并，重叠位置只保留最后一次叠加后的烘焙结果。
- 增量边函数栅格化、活动图层采样候选缓存、颜色转换表及透明三角形跳过机制降低了实时预览与重复涂抹开销。

### 擦除、撤销与局部选择

- 启用 `Fill` 擦除时，`Eraser` 可以裁切混色笔迹；擦除中段会保留前后两个有序区域片段。
- 每次混色绘制只生成一条撤销记录，松手后可立即使用 `Ctrl+Z` 恢复绘制前的区域结果。
- 选择与框选按真实上色覆盖命中，而不是只按对象外框。擦除形成的透明间隙不会造成误选。
- 合并对象中的单个连通混色岛可独立点击或框选；移动、自由变形、删除、复制与粘贴不会连带选择或修改其他岛。
- 首次编辑会事务化物化所选区域，并保持原有图层、Cel、关键帧和绘制顺序；撤销可恢复拆分前的合并对象。
- 旧工程中的轨迹式 Mixing Brush 对象继续兼容读取和渲染。

### 素材面板与标签

- Vault 素材面板采用更紧凑、稳定的列表布局，提供真实几何悬停预览、文字搜索、独立标签筛选和更平滑的局部行重绘。
- 右键素材可展开 `Set Tags`，直接从已有项目标签中勾选或取消；每次选择后子菜单保持打开，便于连续设置多个标签。
- 已分配标签以彩色小圆点显示在素材名称右侧，悬停可查看完整标签列表，不再占用素材名称的主要显示空间。
- 新建标签默认命名为 `New tag` 并使用随机颜色；重名时自动追加序号。
- 标签管理器内直接提供 R、G、B 滑杆和数值框。标签定义、颜色及素材分配会随工程保存、打开和编辑器重启恢复。
- 修复预览与素材右键菜单的交互冲突、`Set Tags` 错误禁用、标签操作导致当前元件跳转，以及素材列表渲染闪烁。

## 安装与更新

正式发布物只有一个文件：

```text
VectorAnimationEngine-0.1.11-win-x64.exe
```

1. 关闭正在运行的软件。
2. 将 `VectorAnimationEngine-0.1.11-win-x64.exe` 放入现有可写运行目录；可以保留旧版 EXE 用于回测。
3. 保留已有 `.Runtime`、`.V2DEngine`、`logs`、工程和用户数据。
4. 启动 0.1.11 EXE。兼容的 `.Runtime` 会直接复用，`.V2DEngine` 会从当前 EXE 的内嵌负载原子重建。

仓库根目录的 `VectorAnimationEngine.exe` 是源码开发启动器，不属于正式发布包，请勿用正式 EXE 覆盖。

## 兼容性与已知说明

- 支持 Windows x64；首次自动安装 .NET 8 Core 与 Windows Desktop x64 运行环境需要网络连接和可写目录。
- 工程格式继续兼容旧数据；缺少标签或混色区域字段时使用默认值，旧版轨迹式混色笔刷对象仍可读取。
- 混色颜色已经烘焙到区域顶点；后续修改全局混色参数不会追溯改变已提交笔迹。
- 当前正式 EXE 尚未进行代码签名。
