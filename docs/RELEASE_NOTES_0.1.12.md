# Vector 2D Animation Engine 0.1.12

[文档索引](README.md) · [当前用户指南](USER_GUIDE.md)

发布日期：2026-08-04

0.1.12 新增面向实际制作的传统补间、形状补间和补间曲线工作流，正式将可复用绘制资产统一命名为“元件”，完善铅笔贝塞尔编辑，并修复元件 Auto Key、预览及长混色笔触性能问题。

## 重点更新

### 传统补间与形状补间

- 在时间轴帧右键菜单中新增 `Create Classic Tween`、`Create Shape Tween` 和 `Remove Tween`。可选择完整起止区间，也可在两个有内容关键帧之间的任意帧直接创建。
- 传统补间支持单个兼容本地矢量对象，或位于元件图层中的单个嵌套元件实例。位置、尺寸、缩放、最短方向旋转、倾斜、Alpha、色调、描边、填色和渐变状态会按适用类型插值。
- 形状补间分别匹配封闭填色与开放的 Line、Pencil、笔刷描边。矩形、圆形、Polygon、Path、不同顶点数和不同对象数会编译为稳定的跨类型边计划。
- 复合 Path 支持孔洞与岛屿的增加、消失、移动和合并；未配对对象或轮廓会从稳定的退化几何展开或收缩，并同步淡入淡出。
- 填色和描边颜色随几何一起变化。支持纯色到渐变、渐变到纯色、不同数量的渐变色标，以及在保持颜色连续的前提下确定性切换渐变类型。
- 修改补间端点的几何、材质或实例状态，以及插入、删除或移动关键帧后，会重新计算受影响的中间帧。

### 补间曲线与编辑反馈

- 选中补间色带后，右侧检查器显示 `Tween Curve`。曲线横轴为时间、纵轴为补间进度，固定端点保持 `0%` 与 `100%`。
- 双击曲线或使用 `+` 新增锚点；拖动或使用方向键调整，`Shift+方向键` 进行较大步进；选中内部锚点后可使用 `Delete`、`Backspace` 或 `-` 删除。
- 曲线锚点保持时间递增和进度不倒退，防止补间倒放或产生不稳定区间。
- 拖动、新增和删除带有弹性动画反馈，但动画不会进入工程数据。每次曲线手势只生成一条撤销记录。
- 删除补间会保留已经物化的中间 Cel，便于继续逐帧编辑；`Ctrl+Z` 可恢复补间关系和曲线。

### 铅笔与绘制工作流

- Pencil 新增类似 Adobe Animate 的 `Smoothing 0-100%`。数值越高，越会在保留首尾点和误差边界的前提下，用更少的三次贝塞尔段拟合指针轨迹。
- Pencil 绘制后的开放描边支持贝塞尔锚点和控制柄编辑、锚点增删、交点切分、擦除和填色边界计算。
- 选择框穿过 Line 或 Pencil 时会沿框边切分开放曲线，并只选择框内部分，可继续移动、变形、删除、复制和粘贴。
- Fill 工具创建封闭区域填色时，会把活动图层当前 Cel 中已有填色边缘与描边共同作为边界；其他图层不会参与边界计算。
- Line 拖动预览现在使用实际的 `Stroke` 颜色和线宽，不再误用 Fill 颜色；同时修复近期工具与渲染调整后绘制预览消失的问题。

### 实例 Auto Key 与性能

- 元件实例的位置、旋转、缩放、倾斜、翻转、外观和播放设置现在正确遵循 `Auto Key`。
- 开启 `Auto Key` 时，会先在播放头物化当前关键帧；关闭时修改保持曝光的来源关键帧，不会在播放头插入关键帧或隐藏实例状态点。
- 当前帧本身已有关键帧时会继续编辑该关键帧；若实际编辑的是传统补间端点，中间状态会按当前补间曲线重新计算。
- 长时间连续绘制 Mixing Brush 时，预览重建频率会根据活动工作网格规模自适应调整，避免单笔绘制越久性能越低，同时保持最终区域顶点色不变。

## 安装与更新

正式发布物只有一个文件：

```text
VectorAnimationEngine-0.1.12-win-x64.exe
```

1. 关闭正在运行的软件。
2. 将 `VectorAnimationEngine-0.1.12-win-x64.exe` 放入现有可写运行目录；可以保留旧版 EXE 用于回测。
3. 保留已有 `.Runtime`、`.V2DEngine`、`logs`、工程和用户数据。
4. 启动 0.1.12 EXE。兼容的 `.Runtime` 会直接复用，`.V2DEngine` 会从当前 EXE 的内嵌负载原子重建。

仓库根目录的 `VectorAnimationEngine.exe` 是源码开发启动器，不属于正式发布包，请勿用正式 EXE 覆盖。

## 兼容性与已知说明

- 支持 Windows x64；首次自动安装 .NET 8 Core 与 Windows Desktop x64 运行环境需要网络连接和可写目录。
- 工程格式继续兼容旧数据；补间、铅笔贝塞尔和混色区域缺失扩展字段时使用兼容默认值。
- 形状补间目前使用确定性的自动轮廓匹配，尚未提供 Adobe Animate 的 Shape Hints 和 Angular/Distributive 手动混合模式。复杂自动结果不符合预期时，可增加中间关键形状约束变化。
- Scene 实例支持关键帧状态，但传统补间和形状补间目前用于元件的绘制图层；嵌套实例只支持传统补间。
- 当前正式 EXE 尚未进行代码签名。
