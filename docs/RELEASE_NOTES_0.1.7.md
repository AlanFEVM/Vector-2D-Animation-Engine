# Vector 2D Animation Engine 0.1.7

[文档索引](README.md) · [当前用户指南](USER_GUIDE.md)

发布日期：2026-07-29

0.1.7 修复共享填色锚点跨多个描边交点时的编辑范围，并让正式 EXE 在复用有效运行环境的同时稳定重建内嵌程序主体。

## 重点更新

### 多交点填色边界编辑

- 拖动真实填色锚点时会先实体化所有与它相接的可见边界区间，使锚点两侧都参与同一次编辑。
- 当同一切割描边与填色边界形成两个交点时，拖动两者之间的锚点会同步调整内部两段，不再改变任一交点外侧的原始边界。
- 指针移动期间会根据当前三次贝塞尔曲线刷新虚拟交点参数，使两个交点锚点始终贴合切割描边。
- 直线三次贝塞尔拆分改为只对最终交点锚点取整并保持严格直线，避免交点附近产生极短残余交叉或看似失效的锚点。

### 正式 EXE 热更新

- 正式 EXE 每次启动都会从自身内嵌负载原子重建 `.V2DEngine`；旧目录只在新主体完整解压并通过文件检查后替换。
- 完整兼容的 `.Runtime` 会直接复用，不下载也不替换；缺失或不完整时仍进入 Microsoft .NET 8 Core 与 Windows Desktop x64 安装流程。
- 启动器自检新增重复主体部署、过期文件清除和运行环境复用检查，同时保留内嵌元数据、SHA-512、下载地址及压缩路径安全验证。
- 主体部署或校验失败时会回滚原 `.V2DEngine`，并继续把详细原因写入 `logs\bootstrap.log`。

### 验证与性能

- 新增与双交点截图场景一致的回归：连续四次移动底部共享锚点，确认两侧内部边界同步变化、两个交点保持在切割线上，并逐次比较交点外侧受保护三次贝塞尔的全部控制点。
- 填色边缘覆盖层只在相邻虚拟交点确实漂移时重新求交；相同量化位置继续跳过重复几何修改。
- 正式发布流程会构建源启动器、生成一次性单 EXE，并执行嵌入负载、运行环境复用和重复部署自检。
- 工程文件格式没有变化。

## 安装与热更新测试

正式发布物只有一个文件：

```text
VectorAnimationEngine-0.1.7-win-x64.exe
```

为了对比测试，不需要覆盖或删除现有 `0.1.6` EXE：

1. 关闭正在运行的软件。
2. 将 `VectorAnimationEngine-0.1.7-win-x64.exe` 与现有 `0.1.6` EXE 放在同一个可写目录。
3. 保留已有 `.Runtime`、`.V2DEngine`、`logs`、工程和用户数据。
4. 启动 `0.1.7` EXE；有效 `.Runtime` 会直接复用，`.V2DEngine` 会从 `0.1.7` EXE 的内嵌负载原子重建。
5. 需要回测旧版时先关闭软件，再启动保留的 `0.1.6` EXE。

仓库根目录的 `VectorAnimationEngine.exe` 是源码开发启动器，不属于正式发布包，请勿用正式 EXE 覆盖。

## 兼容性与已知说明

- 支持 Windows x64；首次自动安装 .NET 8 Core 与 Windows Desktop x64 运行环境需要网络连接和可写目录。
- 已有兼容 `.Runtime`、日志、工程和用户数据会继续保留。
- 复杂 SVG 栅格化拆散仍受有限精度约束，高倍缩放时可能出现轻微边缘或颜色分级差异。
- 当前正式 EXE 尚未进行代码签名。
