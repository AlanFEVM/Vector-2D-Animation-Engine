# Vector 2D Animation Engine 0.1.6

[文档索引](README.md) · [当前用户指南](USER_GUIDE.md)

发布日期：2026-07-28

0.1.6 重点改善填色边界与描边交汇处的连续编辑稳定性，并减少拖拽期间重复的几何与覆盖层计算。

## 重点更新

### 局部填色边界编辑

- 局部 `Fill part` 在拓扑物化、拖动、提交、取消、撤销以及锚点增删过程中会继续关联原有填色区域。
- 填色边界开放部分会显示完整锚点和三次贝塞尔控制点；被同层封闭描边完整贴合的部分继续隐藏，半封闭情况下只显示开放路径。
- 按住 `Ctrl` 左键点击曲线可在点击位置插入锚点并直接继续拖动；按住 `Ctrl` 右键可删除真实锚点。
- 拖动与相邻直边相接的端点时会保持贝塞尔控制点共线，原本已经弯曲的边段继续保留控制几何。

### 共享交点与连接线

- 填色边界、独立 Line、带描边 Path 和闭合自由线使用同一套共享交点规则，不区分填色侧或线段侧优先级。
- 从填色侧或描边侧拖动共享端点，所有相关端点都会同步到同一个量化坐标。
- 独立 Line 穿过填色边界时按需要拆分为精确三次贝塞尔子曲线；Path 自带描边和闭合自由线的交点保留在原对象内部。
- 按住 `Ctrl` 从 Line 端点拖动可创建连接分支；按住 `Ctrl+Alt` 从 Line 中部拖动可建立精确分支锚点，拖动时可按住 `Shift` 临时启用角度吸附。

### 拓扑与连续编辑稳定性

- 同一条贴合 Line 在一次拖拽中只承担一种联动角色：整段匹配时同步完整曲线，仅端点相接时只同步共享端点。
- 连续编辑会重新捕获当前拓扑，不会再次拆分已经存在的共享端点，避免失效控制点、重复线段和幽灵线段。
- 填色重叠归一化优先重建原始三次贝塞尔子曲线，仅简化无法匹配的连接边；孔洞、尖角和真实交点不会变成密集渲染采样锚点。
- 实心轮廓重叠会在提交时归一化为实心区域，不再意外镂空；同色填色合并与边界调整共用一个撤销步骤。

### 性能与交互反馈

- 连续指针事件落在同一个量化曲线位置时，会跳过重复的路径修改、共享交点更新、覆盖层重建和舞台失效。
- 填色边缘覆盖层直接读取三次曲线控制点，不再为每个路径段执行自适应采样或每帧建立查询字典。
- 覆盖层数组只向舞台移交一次；相同覆盖层不会重复使 Direct2D 几何缓存失效或重新计算选择高亮状态。
- 离线双语“更新公告”查看器现已收录 0.1.6 公告并保留历史条目，会继续跟随当前界面语言和色彩主题。

## 安装与更新

正式发布物只有一个文件：

```text
VectorAnimationEngine-0.1.6-win-x64.exe
```

1. 关闭正在运行的软件。
2. 在正式程序目录中用新版 EXE 替换旧版正式 EXE。
3. 启动新版 EXE；内嵌程序会在负载变化时原子刷新 `.V2DEngine`。
4. 已有兼容 `.Runtime`、日志、工程和用户数据会继续保留。

仓库根目录的 `VectorAnimationEngine.exe` 是源码开发启动器，不属于正式发布包，请勿用正式 EXE 覆盖。

## 兼容性与已知说明

- 支持 Windows x64；首次自动安装 .NET 8 Core 与 Windows Desktop x64 运行环境需要网络连接和可写目录。
- 工程文件格式没有变化。
- 独立 Line 的内部交点可能通过精确曲线拆分形成两个 Line 对象，这是共享拓扑的正常结果。
- 复杂 SVG 栅格化拆散仍受有限精度约束，高倍缩放时可能出现轻微边缘或颜色分级差异。
- 当前正式 EXE 尚未进行代码签名。
