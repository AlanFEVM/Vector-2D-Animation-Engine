01 · 从第一张画开始

用矢量绘图制作可复用元件，再在场景中组织、摆放和制作动画。

先画素材

在「基础绘制」中编辑元件，熟悉形状、填色和描边。

再做动画

用关键帧保存不同姿态，用保持曝光控制每个姿态出现多久。

最后组装场景

从素材库放入元件实例，同一素材可以重复使用。

  1. 从左上角主菜单新建工程，切换到基础绘制，确认当前元件和未锁定的活动图层。
  2. 选择矩形工具，在舞台空白处拖出一个矩形。工具图标带小角标时，可展开同组工具选择圆形、多边形等。
  3. 打开右侧外观，先选「填色」，再修改颜色；选择「描边」可单独设置边线颜色和宽度。
  4. 用选择或自由变换工具调整图形。按 Ctrl+S 保存工程。
  5. 继续阅读下方动画示例，给同一组图形创建第二个姿态。

02 · 认识工作区与画布

顶部「基础绘制」用于编辑元件；「场景与动画」用于场景布局、实例动画和镜头。右侧竖排图标切换文档、对象、外观、素材及镜头等检查器。底部状态栏可帮助确认当前元件／场景、帧号与缩放比例。

区域你可以在这里做什么
顶部切换工作区、设置 FPS、网格、吸附和标尺。
左侧工具栏选择、变换、绘制形状、线段、钢笔、笔刷、文本与着色。
中央舞台绘制与拖动对象；使用空白区域导航视图。
右侧检查器查看所选对象的位置、尺寸、外观及实例参数。
底部时间轴管理图层、关键帧、曝光、播放、洋葱皮与运动轨。

设置作品尺寸

打开右侧「文档」，点击「设置画布与背景」。选择预设或输入宽、高，再设置透明、颜色或图片背景，点击「应用」。没有设置画布时也可在开放画布上创作；工作区底色与作品背景是不同设置。

看清单位画布尺寸使用 px。部分对象检查器使用 vu：1 px = 25 vu；1 pt = 0.5 px。不要直接把 vu 数值当作像素。

03 · 绘图、节点与曲线

几何工具适合快速搭建轮廓，钢笔适合精确路径，铅笔和笔刷适合自由绘制。先在工具组中确认当前工具，再看顶部／右侧出现的对应参数。

工具基本操作
矩形／椭圆／多边形在舞台拖出外接范围；用工具参数调整形状。
线段从起点拖到终点；选中后可调整端点和曲率。
钢笔逐点建立路径，在需要转弯的位置建立锚点并调整曲线。
铅笔／笔刷按住鼠标连续绘制；压力笔刷按设备压力改变笔触。
混色笔刷用于颜料式绘画，先调整笔刷大小、强度及混色参数。
文本创建文字对象，再在文字相关检查器中修改内容与样式。

编辑端点与曲率

选中可编辑的线段后，先观察端点和控制柄，再拖动对应点。靠近端点时，端点命中优先于曲率调整。拖动端点期间按住 C，可吸附连接到其他端点。

编辑填色的边界与编辑已经独立的描边，作用范围不同。如果需要填色轮廓一起改变，请选中实际拥有该填色的边界；独立的外部线段不会因为与填色重合就始终共同变形。松开鼠标后，受影响的几何会重新整理拓扑；自交区域需检查填色和交点处分割结果。

文本、未拆散 SVG 等对象不提供内部通用节点编辑。需要编辑 SVG 轮廓时先使用右键菜单的「Break Apart／拆散」，复杂滤镜和效果的转换可能与原图有差异。

04 · 填色、描边与渐变

  1. 先选中对象，打开右侧「外观」。
  2. 明确选择填色还是描边，再输入 Hex 色值或使用颜色选择器。
  3. 描边可独立设置颜色和宽度；想只保留轮廓时，关闭填色。
  4. 切换纯色、线性、径向或形状渐变，编辑渐变色标及方向。
  5. 多选后可批量修改外观；用 Ctrl+Alt+C 复制外观，再选中目标按 Ctrl+Alt+V 应用。

图层颜色和工程高亮色用来识别编辑状态，不会替代对象实际材质。轮廓显示（Outline）也只是编辑预览。

05 · 选择、复制与精确布局

任务操作
多选Shift 追加；Alt 框选减选；Shift+Alt 框选求交集。
清空／反选Alt+A 取消全选；Ctrl+Shift+I 反选当前帧可选对象。
移动／轴锁定拖动所选对象；Shift+拖动限制水平或垂直方向。
微移方向键移动 1 px；Shift+方向键移动 10 px。
拖出副本按住 Alt 拖动已选对象的主体；兼容 Ctrl+Alt+拖动。
重复排列Ctrl+D 就地复制；移动副本后继续 Ctrl+D 可重复上次位移。
原位粘贴Ctrl+Shift+V 保留复制时的原坐标。
穿透选择Ctrl+Alt+点击，选择指针下方被遮挡的对象。
精确变换对象检查器输入数值；Ctrl+Shift+G／R／S 进入二维移动／旋转／缩放数值变换。

对齐和等间距分布

选中多个对象，在舞台右键菜单打开「对齐与分布」。基准可选「选择范围」「主选对象」或「画布」。主选对象作为基准时保持原位；分布需要至少三个对象，调整的是对象之间的空隙。混合本地图形与嵌套实例的布局命令暂不可用。

水平／垂直翻转、描边转填色和合并线段可从右键菜单访问；没有默认键的命令可在快捷键设置中绑定。

06 · 标尺、辅助线与智能吸附

  1. 点击顶部标尺，选择单位。横标尺位于舞台底部，竖标尺位于舞台右侧；选择「隐藏」关闭显示。
  2. 从底部标尺按住鼠标拖入舞台，创建水平辅助线；从右侧标尺拖入，创建垂直辅助线。
  3. 按住 Ctrl 拖动已有辅助线重新定位；拖回标尺区域后松开即可删除。
  4. 拖动中按 Esc 取消。辅助线采用工程偏好的高亮色系，不属于作品内容。

辅助线分别随场景、元件或开放画布保存；切换编辑上下文时请确认当前所属位置。辅助线不导出为作品内容。标尺显示和单位属于视图设置，不能作为打印物理尺寸校准：英寸换算采用固定 96 px/in。

让吸附帮助布局

先打开顶部「吸附」总开关，再根据需要开启「紧贴」或「对齐」。「紧贴」偏向可见边缘；「对齐」比较边缘、中心和等距关系。右键相关按钮可设置辅助线、画布和等距目标，以及 4／8／12／16 逻辑像素容差。拖动时出现的高亮参考线表示当前命中关系。

同时开启吸附和紧贴时，绘制线段或拖动端点会轻吸附到水平、15°、30°、45°、60°、垂直及镜像方向；远离这些方向后恢复自由调整。对象、辅助线目标和 C 键连接优先于轻角度偏好。

07 · 用图层组织画面

在底部图层列表中选择活动图层，再开始绘制。上方图层覆盖下方图层；不同角色、背景和装饰分层后，选择与制作动画更容易。

功能用途与注意点
显示／锁定眼睛控制可见性，锁定避免误选与编辑；无法绘制时先检查图层及所属文件夹是否锁定。
文件夹把相关图层放在一起管理；文件夹的状态会影响子层。
轮廓显示只看编辑轮廓，适合检查叠放关系，不会删除填色。
遮罩先建立遮罩与被遮罩层关系；遮罩先裁切，混合模式再参与合成。
混合模式在图层检查器中设置；效果依赖上下层内容，复杂模式可能影响实时播放速度。
父子关系用于二维编辑跟随；不要把它理解为任意运行时骨骼或完整三维层级。

在舞台上，H 隐藏选中，Alt+H 显示全部，Shift+H 孤立选中。对象级锁定可使用舞台上下文中的 Ctrl+2，隐藏可用 Ctrl+3。快捷键的实际作用取决于焦点和选择状态。

08 · 制作第一段关键帧动画

帧 Frame

时间上的一个位置，软件从第 0 帧开始计数。

关键帧与 Cel

关键帧建立一个内容状态，Cel 保存对应绘制内容。

保持曝光

没有新关键帧时，继续显示前一个关键帧的内容。

  1. 在基础绘制的第 0 帧画好图形。本例使用矩形、圆形和三角形。
  2. 选中时间轴当前层，按 F5 延长曝光。本例延长到第 29 帧，共 30 帧；F5 不会自动向后移动播放头。
  3. 点击第 15 帧，按 F6 复制出新的关键帧。
  4. 回到舞台，把图形向上移动。这次修改属于第 15 帧的 Cel，不会改变第 0 帧的姿态。
  5. 按 Enter 播放／停止；拖动播放头检查两个姿态。30 FPS 下，30 帧约为一秒。
为什么前面的画面也变了？如果 Auto Key 关闭，直接编辑保持帧会改到其来源 Cel。需要从当前帧开始变化时，先按 F6 复制关键帧，或按 F7 建立空白关键帧。开启 Auto Key 可在受影响的轨道上自动建立当前帧状态。

关键帧常用操作

快捷键作用
F5／Shift+F5插入／删除帧。
F6／F7复制关键帧／插入空白关键帧。
,／.前一帧／后一帧。
Up／Down（时间轴焦点）上一／下一关键帧。
Enter播放／停止。

09 · 补间、洋葱皮与运动轨

让两个姿态之间连续变化

准备两个有内容的关键帧，确保区间内没有其他关键帧。在两者之间的时间轴帧格上右键，选择「Create Classic Tween／创建传统补间」或「Create Shape Tween／创建形状补间」。

类型适用内容
传统补间（蓝色色带）基础绘制：单个兼容的本地矢量对象，或同一嵌套元件实例。场景：普通内容层中恰好一个场景实例。适合位置、旋转、缩放与外观变化。
形状补间（绿色色带）基础绘制的原始矢量内容，可让不同轮廓与对象数量过渡。场景层、嵌套实例、文本、未拆散 SVG 和混色笔刷区域不支持。

点击补间色带，在右侧「Tween Curve」调整缓动。端点关键帧控制最终姿态；修改端点后中间帧会重新计算。对复杂轮廓，增加中间关键形状通常更容易控制；当前没有 Adobe Shape Hints（a-z）。在补间区间内部另建或修改关键帧会取消原补间关系。

用洋葱皮比较姿态

点击时间轴工具栏的双层菱形图标，设置前／后范围。暖色表示前帧，冷色表示后帧；残影不可选择，播放时暂时隐藏。下图中，下方暖色残影是上一个姿态，上方实色图形是当前姿态。

运动轨需要实例

运动轨显示实例在一段时间内的位置与锚点。先放入并选中元件实例，再开启折线形运动轨按钮。只有直接绘制的内容而没有实例时，按钮灰显是正常状态。运动轨与洋葱皮可以同时开启。

10 · 素材库、元件与实例

  1. 在基础绘制中完成一个元件，并为其命名。使用素材库按钮打开 Vault。
  2. 切换到「场景与动画」，从素材库将元件拖到舞台，生成一个实例。
  3. 重复拖入同一元件，得到共享源内容的多个实例；分别调整位置、缩放和播放方式。
  4. 需要修改所有引用的内容时，进入源元件编辑；只想改变一次放置的位置或大小时，编辑场景实例。
源元件与实例元件是可复用的内容定义，实例是它在画面中的一次放置。修改源元件会影响所有引用。Alt+D 用于关联复制；需要独立改画时使用独立副本，并确认源关系。

使用目录、标签和搜索整理素材；同类素材可借助素材标签筛选。导入 SVG 或图片后，可在对应素材页中管理和放置。图片作为整体位图使用，不能像原生矢量一样直接编辑节点。

11 · 场景布局、实例动画与镜头

场景可以组合多个元件，也支持在二维前视的可绘制上下文中直接绘制。先看清当前在编辑场景、实例还是源元件，再操作右侧检查器。

给场景实例制作动画

  1. 把需要独立运动的实例放到单独的场景图层。
  2. 在起始帧设置实例位置，延长场景曝光，再在终止帧建立关键帧。
  3. 调整终止帧的位置、旋转或缩放。
  4. 该层恰好只有一个实例时，可用时间轴右键菜单创建传统补间；需要形状变化时，进入源元件制作形状补间。

使用镜头取景

在时间轴切换到「镜头」分组，使用镜头相关检查器管理和选择相机。镜头轨道与场景内容共用一条连续时间轴；「全部」可同时查看相机与内容轨道。相机关键帧可使用传统补间，调整位置与取景参数。

默认使用二维场景。三维参考视图、空间相机和灯光属于实验性功能，需要先在设置中开启实验性 3D；没有启用时找不到相关入口属于正常状态。本手册截图采用二维工作流。

12 · 保存、导入与导出

保存工程

从主菜单「工程文件」选择保存，或按 Ctrl+S。首次保存选择格式和位置。标题中的星号表示仍有未保存修改。

格式如何保管
.v2d 单文件工程一个文件包含工程内容，适合备份和传递。
.v2dProject 文件夹工程索引与 .Vault、.TimeLine 等目录共同组成工程；移动或备份整个工程目录，不要只复制索引。

「另存为」用于另建副本或转换工程保存格式。保存前确认目标目录；不要把两个文件夹工程混放到同一个受管理目录，也不要手动改写工程内部素材文件。

导入素材或已有作品

主菜单「导入」提供 SVG、图片及 Flash／Animate 工程等入口。部分素材导入要求可绘制上下文，入口灰显时先返回基础绘制。Flash 导入是单向转换，支持范围取决于原文件内容；不能直接表达的内容可使用视觉转换桥，按对话框指引在 Adobe 软件中运行脚本。

区分可编辑交换与视觉导出

需要选择
导出单个元件的静态外观导出 SVG；适合在其他矢量软件中使用。
传递可再次导入的元件导出 .V2DSymbol；包含所选元件及嵌套引用。导入会新增元件，不覆盖现有元件。
传递完整工程与时间轴保存 .v2d，或复制完整文件夹工程。
当前没有整场景或整段动画的作品导出命令。不要把保存工程、单元件 SVG 导出理解为视频、GIF 或整段动画导出。

13 · 设置与快捷键方案

点击左上角主菜单，打开「设置」。可调整语言、主题、高亮色、操作偏好和快捷键方案。高亮色也用于辅助线与吸附参考线。

进入快捷键设置，选择现有方案或创建自定义方案，再为命令修改绑定。不同方案的工具键可能不同；以下速查面向当前常用默认绑定。工具提示与菜单中显示的绑定以当前方案为准。

先检查焦点输入框中的方向键用于编辑数值，时间轴中的 Up／Down 用于跳关键帧。Ctrl+2／Ctrl+3 在有舞台选择时用于对象锁定／隐藏，在其他上下文可能切换工作区；Ctrl+Shift+S 在舞台数值变换上下文用于缩放，其他上下文用于另存为。需要文件操作时从主菜单选择最明确。

15 · 遇到问题时

现象先检查
无法绘制确认工作区和活动元件；检查活动层、父文件夹是否锁定或隐藏；停止播放，退出模态编辑。
选不到黄色端点切换到对应选择／节点工具，确认选中的是可编辑线段；放大视图，检查是否选中了上方覆盖对象。未拆散 SVG 没有原生端点。
拖线后填色没有跟随确认操作的是填色的实际边界，还是独立描边；独立外部线不会自动成为填色边界。
找不到标尺／不能拉辅助线点击顶部标尺选单位；从底部或右侧刻度带按住并拖入舞台。重移已有线需按 Ctrl。
吸附不起作用先启用吸附总开关，再启用紧贴或对齐；右键检查目标类型与容差。
改当前帧却影响了前面当前是保持帧且 Auto Key 关闭。撤销，再按 F6 或开启 Auto Key 后修改。
运动轨按钮灰显当前内容没有元件实例；先从素材库放入并选中实例。
补间命令失败检查起止帧是否有内容，区间内是否有额外关键帧，以及对象数量、类型是否符合该补间要求。
同一素材的其他位置也变了你编辑了共享源元件。需要独立内容时先复制为独立元件。
颜色改错部位先确认外观面板正在编辑填色还是描边，图层高亮色不等于材质颜色。
画面不在窗口内Home 适应二维内容，Shift+2 查看选中；确认图层可见性和当前帧。
打开／导入报错保留错误窗口的完整报告；确认工程文件夹完整、格式受支持，再提供报告和复现步骤。

当前边界

复杂形状自动补间可能需要中间关键形状；通用节点编辑没有覆盖所有类型；复杂 SVG 拆散不能保证滤镜效果逐像素一致。实验性 3D 不在默认二维流程中。大规模非普通混合和滤镜可能降低交互帧率。

本手册依据 2026-10-30 当前工作树及实际操作整理。截图来自软件中新建的演示工程；窗口布局会随尺寸、主题与语言变化。本文是当前功能使用说明，不代表某个历史安装包均包含这些功能。

17 · 笔刷、压力与颜料

左侧笔刷工具组包含普通铅笔、Pressure Brush 和 Mixing Brush。普通铅笔生成开放描边；Pressure Brush 将设备压力映射到大小或不透明度；Mixing Brush 生成可混合颜料区域。

  1. 选工具后在顶部确认大小、平滑、压力映射和混色参数。
  2. 先在小范围试画，观察右侧外观与舞台预览；需要无压力设备时关闭压力映射。
  3. 擦除时使用对应擦除模式；不要把擦除误认为删除原始矢量节点。
  4. 保存后再次打开，确认颜料区域和普通矢量对象都在当前 Cel 中。
动画限制Mixing Brush 区域不参加形状补间。要做平滑姿态变化，可把关键画面作为独立曝光，或将可编辑矢量轮廓用于形状补间。

18 · 相机、视差与导演工作流

场景与动画工作区共用一条连续时间轴。时间轴的「镜头」分组只显示相机轨道；「全部」会同时显示相机与场景内容。

2D 相机

适合平移、缩放、旋转和取景框动画。

透视相机

实验性 3D 开启后可使用 XYZ、焦距和视锥。

正交相机

保持平行投影，适合无透视缩放的场景。

相机关键帧保存投影模式、位置、旋转、焦距或正交尺寸。选中两个相机关键帧后创建传统补间；中间帧按曲线重算。拖动镜头框时不再显示多余的浮动操作提示，悬停提示仍可查看说明。

2D 相机视差按图层或实例的深度关系产生相对位移；调整相机或舞台尺寸后，辅助框和投影会刷新。三维参考视图需要在设置中打开实验性 3D，若开关关闭则不会出现三维入口。

19 · SVG、图片与文本的完整流程

  1. 在可绘制上下文打开主菜单的「导入 SVG」或「导入图片」。场景遮罩编辑面也可作为导入上下文。
  2. SVG 导入后先作为完整矢量资产保存；要编辑内部节点，在对象菜单选择 Break Apart，并检查拆散结果。
  3. 图片会复制到 Vault 的托管资产中；源文件之后移动不会阻止工程打开。
  4. 文本对象在文本检查器中修改内容和样式；文本不是通用路径节点，不能直接参加全部形状补间。
  5. 选中单个元件后，可导出静态 SVG；需要可逆工程数据时导出 .V2DSymbol。

SVG 导出保留单个元件的视觉外观；.V2DSymbol 保留嵌套引用和库元数据，但不会带上引用它的场景、播放设置或整条时间轴。

20 · Codex／MCP 与自动化

设置中的 Codex／MCP 面板控制服务是否启用、是否允许编辑写入以及端口。启用服务不等于自动授予编辑权限；写入操作仍应经过参数校验、UI 线程调度和文档撤销边界。

用途推荐做法
读取状态先获取当前工程、场景、帧、选择和工作区，再决定操作。
修改文档使用现有工程／图层／时间轴工具，保持一次操作可撤销；不要直接编辑存储 JSON。
导入动画包使用动画包导入入口，失败时读取完整诊断报告，避免留下半导入元件。
服务安全只在本机可信环境开启；完成自动化后关闭编辑写权限或服务。
本次手册制作使用了现有 MCP 状态读取和工程操作接口；没有遇到必须新增工具才能完成的用户功能，因此没有虚构或添加未验证的 MCP 命令。

21 · 版本、发布与用户安装

普通用户只需使用正式发布的单 EXE 或开发启动器提供的应用入口，不需要接触源码、.NET SDK、GPU 回归和内部基准。

  • 更新公告和版本信息从主菜单查看。
  • 开发启动器用于源码调试和模块热加载；正式包使用外部运行时与内嵌引擎资源。
  • 替换正式 EXE 前备份工程；工程文件与运行时目录不要混在工程目录内。
  • 遇到启动、重启或热加载问题，先保存工程，再记录启动方式、版本、完整错误报告和复现步骤。
