# Vector 2D Animation Engine 操作教程

本文档记录当前软件的可用操作。后续每次新增功能或改变交互方式，都需要同步更新本文档，并随代码一起提交 git commit。

## 启动软件

在项目根目录双击：

```text
VectorAnimationEngine.exe
```

当前根目录 EXE 是轻量入口程序。它优先启动 `runtime\\win-x64` 中依赖框架的 ReadyToRun 预编译桌面应用；该路径不需要系统安装 .NET SDK，也避免了启动时 JIT 编译与源码构建的开销，但需要 .NET 8 Desktop Runtime。

当预编译运行时缺失，或其时间戳落后于 `native/` 源码、项目配置或 `global.json` 时，启动器会自动回退到源码工程。源码路径需要系统 `PATH` 中与 `global.json` 兼容的稳定 .NET 8 SDK；仅安装更高主版本 SDK 并不满足该约束。若 Debug 输出仍是最新的，会跳过初次编译直接启动。使用预编译运行时不需要 SDK；根目录入口本身仍需要 .NET Desktop Runtime 8。

软件默认打开空项目，不会自动生成压测场景。

正式分离包的根目录包含 `VectorAnimationEngine.exe`、`.Runtime` 和 `.V2DEngine`。`.Runtime` 是固定的私有 .NET 8 桌面运行环境，`.V2DEngine` 是可更新的软件代码与依赖；该包不要求系统预装 .NET。常规版本发布只提供补丁 ZIP 和对应的 SHA-256 文件，不重复分发运行环境。收到补丁后先关闭软件，再把旧 `.V2DEngine` 整个备份或移走，然后解压补丁中的新 `.V2DEngine` 到软件根目录。不要把新旧目录逐文件混合，因为新版本可能删除不再使用的依赖。除非补丁说明运行环境或包结构已经升级，否则保留根目录启动器和 `.Runtime` 不变。

## 单位体系

当前引擎把矢量单位作为最小绘制原子：

- `1 px = 25 vu`，其中 `vu` 表示 vector unit。
- `1 pt` 线宽固定显示为 `0.5 px`。
- 因此 `1 pt = 12.5 vu`，材质面板中的 `Width pt` 会转换为内部矢量单位保存和计算。
- 对象坐标、尺寸、吸附网格、命中测试、框选和移动编辑都以矢量单位为基础。
- 状态栏中的 `Zoom 100%` 表示 `25 vu` 显示为 `1 px`。
- 软件打开项目或生成压测场景后的默认用户可视范围宽度为 `4000 vu`。

后续矢量布尔、路径编辑、吸附、对齐、材质和导出逻辑都需要遵守这个单位体系。

## 开发自动重启

双击根目录 `VectorAnimationEngine.exe` 会优先启动 ReadyToRun 预编译运行时。预编译运行时的状态栏显示 `Module Reload Off`，适合日常快速启动。开发时可使用以下命令强制进入非交互模式的 `dotnet watch` Metadata Hot Reload：

```powershell
.\VectorAnimationEngine.exe --dev
```

开发模式下，修改 `native/` 下的 C# 代码并保存后，同一轮保存产生的多个类型更新会先合并为一个串行热更批次。渲染和引擎方法更新会在当前窗口内应用；Shell、时间轴、检查器和 Vault 的更新会自动重建工作台窗口，以重新执行控件构造和布局代码。两种路径都会保留当前项目、活动工作区、帧位置、选择上下文、舞台视图和窗口状态。模块刷新失败时会依次尝试完整工作台重建和保留项目的编辑器进程重启。

底部状态栏显示 `Module Reload On` 时表示当前处于开发模块热重载模式；应用、完成、恢复或失败状态会带有本次热更代际编号。无法由 .NET 在运行时应用且未产生元数据回调的结构性编辑不会自动杀掉软件；保存后点击右上角重启图标，启动器会重新启动编辑器进程并应用修改后的代码，同时恢复当前项目、活动工作区、帧位置、舞台视图和窗口状态。需要在不监听文件变化的情况下单次启动时，可以使用：

```powershell
.\VectorAnimationEngine.exe --no-hot-reload
```

通过根目录开发启动器运行时，右上角窗口控制区的重启图标会保存一次性项目快照并请求启动器重启 `dotnet watch` 子进程。启动器会向下一次 native 启动传递一个短期一次性令牌；只有令牌匹配且未过期时，新编辑器实例才会恢复当前 `Project`、活动工作区、帧位置、舞台视图和窗口状态。普通启动、错误令牌或过期令牌都会清理待恢复快照而不加载旧工程。这也会加载无法由 Metadata Hot Reload 直接应用的修改。使用 `--no-hot-reload` 或直接运行 native 时，图标会降级为窗口内重启，仍会保留当前项目内容。

## 日志和崩溃定位

通过根目录 `VectorAnimationEngine.exe` 启动时，软件会在项目根目录写入运行日志：

```text
logs/
```

常见文件：

- `launcher.log`：根目录 EXE 的启动记录，以及隐藏 `dotnet watch` 进程的编译输出和异常重试记录。日志达到 `8 MB` 后会轮换为 `launcher.previous.log`；watch 进程非零异常退出时最多自动重启三次。
- `native-yyyyMMdd-HHmmss-pidN.log`：桌面应用本体的运行日志。

如果直接运行 `native/` 工程或 native 输出目录下的 EXE，且没有设置 `V2D_LOG_DIR` 环境变量，native 日志会写入该 EXE 基目录下的 `logs/`。日志会记录启动环境、热重载窗口重建、压测场景生成、Direct2D 渲染失败回退、UI 线程未处理异常和进程级未处理异常。通过根目录启动器运行时，软件崩溃后优先查看项目根目录 `logs/` 中最新的 `native-*.log`。

## 主界面区域

- 顶部栏：自定义窗口标题区、播放、帧滑块、运行压测场景、适配舞台，以及右上角重启、最小化、最大化/还原、关闭按钮。
- 悬浮工具栏：覆盖在舞台左上侧，用于选择、平移、基础形状、线条、铅笔、笔刷组、填充，以及打开 Vault 抽屉的 `V` 按钮。
- 中央舞台：绘制、选择、移动和编辑对象。
- 右侧检查器：根据当前工作区显示绘制对象设置、材质、场景管理、层级或动画设置。
- 底部图层时间轴：左侧管理绘制图层、嵌套对象实例或场景图层，右侧查看帧尺、拖动播放头、查看保持曝光、实心关键帧和空白关键帧。
- 最底部状态栏：显示当前渲染帧率、更新频率、动画 FPS 设置和舞台缩放比例。

右侧检查器使用紧凑自适应表格布局，并在内容超过可视区域时提供细窄的主题滚动条；可用鼠标滚轮、拖动滑块、点击轨道翻页，或用方向键、Page Up/Page Down、Home/End 滚动。内容刷新后会保留当前位置，避免编辑时跳回顶部。场景列表、层级树和 Vault 列表的原生滚动条也会采用深色主题，避免出现明亮的系统滚动条。主工作台的顶部栏、悬浮工具栏、舞台、图层时间轴和右侧检查器之间使用细边界区分，便于长时间编辑时快速扫描。

主窗口使用自定义无边框外观，不再显示 Windows 默认标题栏和系统边框。按住顶部栏左侧标题区域或空白处可以拖动窗口；双击标题区域可以最大化或还原；窗口四边和四角仍可拖拽改变大小。

顶部标题栏的属性和时间轴图标分别控制右侧属性面板与底部时间轴面板。点击按钮或按 `F1` / `F2` 可带动画收起、展开对应面板；重新展开时间轴时会恢复用户上次拖动调整后的高度。高亮按钮表示面板当前处于打开状态。

所有数字输入框在鼠标悬浮到数值区域时会显示水平拖拽光标。按住左键左右拖动可连续减小或增大数值；开始拖拽后鼠标会隐藏并持续回到按下位置，因此可以越过屏幕边缘无限拖动，松开、取消或失去捕获时会在按下位置恢复。按下的数字位决定拖拽步长，例如点击 `23.976` 中的 `2`、`3`、`9`、`7` 或 `6` 时，每步分别调整 `10`、`1`、`0.1`、`0.01` 或 `0.001`；按在小数点、符号或文本外时回退到该输入框的默认步长。拖动期间不会选择数字文本；单击后会聚焦并全选当前数值，可直接用键盘输入替换，按 `Enter` 或点击输入框以外的画布、标签、面板等区域后提交并自动失焦。鼠标悬停在数字框的数值或步进按钮上时，向上滚动会增大数值，向下滚动会减小数值；上下方向键和右侧步进按钮也可逐级调整数值。FPS 输入采用按位滚轮：指针位于十位、个位、十分位、百分位或千分位数字上时，每格分别调整 `10`、`1`、`0.1`、`0.01` 或 `0.001`。

## 工作区

顶部工作区标签用于切换不同编辑模式：

- `Basic Drawing`：绘制对象模式。这里所有工具都围绕当前绘制对象服务，右侧包含对象检查、绘制设置和材质设置。任何新绘制的几何都会写入当前绘制对象。
- `Scene Edit`：场景编辑模式。这里用于管理多场景、多绘制对象、场景实例、场景类型和镜头信息。场景是项目级组合上下文，保存的是绘制对象实例，而不是独立绘制几何。
- `Animation`：播放 FPS、循环、起止帧设置。

底部图层时间轴在所有工作区中保持可见，方便像早期 Flash 一样在绘制时直接切换图层和播放头。

时间轴会跟随编辑上下文切换：绘制对象上下文只显示稳定图层轨道，每个绘制图层可同时容纳本地 Cel 几何和多个嵌套绘制对象实例，不再为实例自动生成额外轨道；图层的可见性和曝光统一控制其中的几何与实例。场景上下文中的每条轨道绑定稳定场景图层 ID，一个场景图层同样可容纳多个绘制对象实例。新增、删除或调整图层后，仍然存在的图层会保留原轨道 ID、时长和关键帧数据。

进入 `Animation` 工作区时会保留进入前的绘制对象或场景上下文。场景时间轴仍会实时重建组合预览，绘制类工具保持禁用，避免修改只用于预览的临时合成结果。

在 `Basic Drawing` 工作区下方只显示当前正在编辑的绘制对象和 `+ Object` 按钮。这里的绘制对象类似 Flash 元件，用于表示可复用的绘制对象编辑上下文。完整的多绘制对象切换和管理在 `Scene Edit` 中完成：

- `Drawing Object 001`：新建项目默认创建的空绘制对象，初始只有一个图层和第 1 帧；后续可通过时间轴新增图层或帧。
- `+ Object`：新增绘制对象页签。

当前绘制对象页签表示本窗口正在编辑的对象。按住绘制对象页签可拖到 Vault 保存引用，也可拖到场景中创建场景实例。Vault 中的其他绘制对象引用可以拖入当前绘制对象的当前绘制图层，形成嵌套实例；同一图层可放置多个实例，对象不能包含自身，也不能形成 A→B→A 等直接或间接循环。悬浮工具栏在 `Basic Drawing` 中负责选择矩形、线条、填充等具体绘制工具；切到 `Scene Edit` 时绘制类工具会禁用，避免场景装配时误绘制。

`Scene Edit` 工作区提供：

- Scenes：多场景列表，`+ Scene` 可新增场景概念。
- Drawing Objects：多绘制对象列表，`+ Object` 可新增绘制对象，并可切换当前绘制对象。
- Scene Instances：当前场景中的绘制对象实例列表，`+ Instance` 会把当前选中的绘制对象作为实例加入当前场景。
- 在场景舞台或 Scene Instances 列表中双击实例，会进入其来源绘制对象的 `Basic Drawing` 编辑器；返回 `Scene Edit` 后组合预览会使用更新后的定义重新构建。
- 在 2D 场景舞台中使用 Select 点击实例，会显示包围该绘制对象及其嵌套内容的绿色发光选择框；选框中的十字圆点标记该绘制对象的共享原始锚点，拖拽选框内对象可移动实例。切换到 `任意变形` 后，同一选择框会显示八向缩放、旋转和移动手柄，可直接调整该场景实例的 X/Y、缩放和 Z 轴旋转。
- 从绘制对象页签、Project Vault 或 Stored Vault 拖拽绘制对象到 2D 场景，或拖到另一个绘制对象以创建嵌套实例时，舞台会显示跟随鼠标的半透明实际几何预览；预览包含递归嵌套内容，离开舞台或放下后自动清除。
- 项目素材库使用树形文件夹整理绘制对象。点击素材库标题栏的文件夹按钮可在当前层级新建文件夹；选中文件夹后新建会创建子文件夹。文件夹右键支持重命名和复制，复制会同时复制完整子文件夹结构及其中的绘制对象，并重映射副本之间的嵌套引用。可拖拽绘制对象或文件夹改变归属和嵌套层级，拖到素材树空白处会移回根目录；文件夹不能移动到自身或其后代中。
- Scene type：可选择 `2D scene with depth` 或 `3D scene`。
- Camera：可选择 `Orthographic` 或 `Perspective` 投影模式。2D 场景保留纵深配置，3D 场景使用独立镜头配置。
- 选择 `3D scene` 后，舞台会显示带 X/Y/Z 轴的 3D 参考网格，并使用 Blender 风格视图导航：鼠标中键拖拽旋转视图，`Shift+中键拖拽` 平移视图，`Ctrl+中键上下拖拽` 推近/拉远视图，滚轮推近/拉远，`Ctrl+滚轮` 调整视图缩放系数，`Numpad 1/3/7` 切换前/右/顶视图，`Ctrl+Numpad 1/3/7` 切换反向视图，`Numpad 5` 切换透视/正交，`Home` 重置 3D 参考视图。
- 2D 世界网格默认不透明度为 `10%`，可通过顶部 `Grid` 滑块调整。点击滑块左侧的网格图标可以在直角坐标网格、极坐标网格和黄金比例螺旋线网格之间切换。直角坐标网格以十进制层级显示，最小逻辑网格为 `10 vu`，每 10 条细线形成一级粗线；缩放时细线会连续淡入或淡出，并与对应粗线平滑合并，红色 X 轴、绿色 Y 轴和中心圆点共同标记世界原点。极坐标网格使用同一世界原点绘制自适应圆环和固定角度径向线，缩放时圆环间距跟随当前十进制网格层级变化，平移远离原点时仅计算与视口相交的圆环。黄金比例螺旋线网格提供黄金矩形、黄金分割线和每四分之一圈按黄金比例扩张的构图螺旋，螺线起点与直角坐标网格的世界原点保持一致；它会根据当前可视范围向内、向外持续延伸，平移或缩小到远景时也不会收缩成固定大小。黄金矩形会按当前自适应网格吸附步长扩展到覆盖视口，绘制吸附仍使用该缩放级别对应的直角坐标格点。
- Hierarchy：场景、图层和对象层级树。
- `Scene Edit` 不接受矩形、线条、笔刷、材质、删除或粘贴等原始几何编辑；绘制必须先进入某个绘制对象。拖入场景的绘制对象引用会成为项目级实例，而不是临时舞台几何。
- `Scene Edit` 的舞台与 `Basic Drawing` 的绘制对象舞台保持分离，但会根据当前帧递归生成组合预览：只有可见且时间轴处于实心曝光的场景图层会参与预览，图层中所有可见实例会按实例顺序组合，父子实例的 X/Y 位置、X/Y 缩放和 Z 轴旋转会逐层合成。组合结果保留来源映射，用于双击进入正确的绘制对象编辑器。
- 绘制对象编辑器会把嵌套实例显示为组合底图。本地图形命中优先；没有命中本地图形时，可用选择工具选中并拖动整个嵌套实例，也可用自由变换工具移动、旋转、缩放和倾斜。在空白处拖出选框时，如果没有框中本地几何，会选择完整落入选框的一个或多个嵌套实例；整组实例可一起移动、变形或删除。在不同时间轴帧修改实例时，会在宿主图层创建关键帧，并为该帧独立保存可见性、三轴位置/旋转/缩放、倾斜和播放设置；状态保持到下一个关键帧，更早的关键帧不会被后续旋转或变形覆盖。选中绘制对象实例时，右侧会显示实例播放设置：可设置独立播放 FPS，并选择“仅播放一次”“循环”或“停留帧”；实例 FPS 会相对于宿主时间轴 FPS 换算内部帧，多层嵌套会逐层换算。`Anchor X/Y` 修改的是来源绘制对象的共享原始锚点，而不是当前实例的关键帧属性；修改后项目中所有直接实例、嵌套实例及其状态关键帧都会同步更新锚点位置，并自动补偿各自的缩放、旋转和倾斜，使现有画面保持不跳动。同源实例多选时仍可共同编辑该共享锚点；混合选择不同来源时锚点输入会禁用。“原始大小”按钮只会把当前关键帧的 X/Y 缩放恢复为 100%，并保留该帧的其他状态；多选时，主动修改的播放设置和恢复大小命令会应用到全部已选实例。为宿主图层启用残影后，嵌套实例也会按前后帧状态显示红色/蓝色残影。选中嵌套实例后按 `Delete`，或在实例上右键选择“删除”，会从当前绘制对象中移除该实例，但不会删除它引用的源绘制对象。右键选择“拆散”会把一个或多个所选实例在当前帧的递归组合结果冻结为宿主图层当前 Cel 中的普通填色和线条；第 0 帧且没有未来可见状态时会移除实例引用，否则会从当前帧起隐藏原实例，从而保留更早帧和后续显式可见关键帧。来源绘制对象资产不会被删除。双击实例内部图形仍会进入对应的源绘制对象编辑器。

## 绘制工具

悬浮工具栏使用 SVG 矢量图标按钮，位于舞台指标栏下方的左上侧，鼠标悬浮会显示工具名称。当前支持：

- Select / Free Transform Tool Group：选择和任意变形共享父工具按钮，主按钮显示最近使用的子工具。
- Shape Tool：组合形状工具，主按钮显示当前形状，点击后使用当前形状绘制。
- Line Tool Group：独立的线条父工具盒，包含 Line、Pen、Simple Pen 和 Pencil，主按钮显示最近使用的子工具。
- Line：绘制带端点和贝塞尔控制点的线条。
- Pen：采用传统 Adobe Illustrator 钢笔交互。按 `P` 启用；单击创建转角锚点和直线段，按下并拖拽创建成对方向手柄和三次贝塞尔曲线段，随后可连续添加锚点；每段曲线分别保存起点侧与终点侧两个控制点，可独立拖动，修改其中一个不会覆盖另一个。单击首锚点闭合路径，双击或按 `Esc` 结束开放路径。没有正在绘制的路径时，单击任意已有线段会一次选中与它端点连续的整条路径，并同时显示路径中所有可调锚点与两侧曲线控制点；这些手柄可直接拖动，共享锚点会同步带动相连线段。拖拽新锚点时按住 `Alt` 会锁定入手柄并独立调整出手柄，以创建折角；按住 `Ctrl` 仍可临时编辑尚未选中的线段端点或曲线控制点。按住 `Shift` 会约束线段和方向手柄角度。舞台会显示入/出方向手柄、锚点吸附标记和 X/Y 对齐辅助线。
- Simple Pen：保留原有的简易逐段钢笔。第一次单击确定起点，后续单击确定终点并可在按住鼠标时直接拖动单个二次贝塞尔控制点。双击会先提交当前有效线段再结束路径；拖拽期间即使鼠标捕获意外丢失，也会提交已经形成的有效线段并保留续画锚点。按住 `Ctrl` 悬停在线段内部会显示菱形加号，单击即可在曲线上插入锚点；锚点插入仅在没有正在续画的 Simple Pen 路径时生效，不会抢占当前线段提交。靠近已有端点时会优先吸附到该锚点。启用 `Snap Objects` 后会持续吸附锚点，启用 `Align` 后会按已有锚点的 X/Y 位置对齐；舞台上的青色辅助线、十字吸附标记会显示最终落点。
- Pencil：自由绘制开放描边，使用材质面板的 `Stroke` 颜色。
- Brush Tool Group：包含普通 Brush 和 Pressure Brush，主按钮显示最近使用的子工具。
- Brush：自由绘制软边笔迹，并在松开鼠标后生成多层闭合 Path 填色轮廓，使用材质面板的 `Fill` 颜色或渐变。线性渐变通常按笔迹的累计长度连续分布，即使笔迹急转或接近闭合也不会被起笔到收笔的直线轴压缩；当笔迹发生真正的内部自交时，会自动切换到沿笔迹主方向的空间渐变，使交叉点两条分支保持一致颜色，避免突兀切色。所有软笔刷层共用相同映射并保留各层透明度。径向渐变以起笔为中心、收笔方向确定半径；形状径向渐变以整次笔迹的包围中心为渐变中心，所有软边层共享最外层轮廓，并通过轮廓距离场让回绕、凹陷和自交分支连续过渡到边缘色。使用完全相同色标与透明度的形状渐变笔刷相交时，不再按后画填色覆盖旧填色，而是实时预览联合后的轮廓，并在提交时重新计算整块形状的渐变中心、边缘与距离场；不同渐变信息仍保持正常覆盖规则。中心落在孔洞或轮廓外时会自动吸附到邻近的内部稳定区域。实色笔刷会立即与当前图层、当前 Cel 中相交或相距不足 `10 vu` 的同 ARGB 填色合并，落笔后不会自动选中填色。
- Pressure Brush：根据鼠标移动速度和按下持续时间连续改变笔尖大小，生成带有流体粗细变化的闭合 Path 填色轮廓，支持与 Brush 相同的沿笔迹长度 Fill 渐变、即时同色填色合并与不自动选择规则。
- Fill / Ink Bottle Tool Group：填充和墨水瓶共享父工具按钮，主按钮显示最近使用的子工具。
- Fill Tool：填充已有对象颜色；点击线条会将当前 `Fill` 颜色应用到该线条并转换为纯色，按住 `Shift` 点击会同时修改所有端点连通的线条。
- Ink Bottle Tool：点击填色对象或其边缘，把当前 `Stroke` 颜色和 `Width pt` 应用为完整边界描边。
- Eyedropper Tool：点击填色、线条或描边可吸取对应的 Fill 或 Stroke 颜色；点击带渐变的填色或线条会吸取渐变类型和全部色标。
- Gradient Tool：点击填色对象或线条创建当前选择的线性或径向渐变；线性模式拖动两端圆形手柄调整方向和范围，径向模式拖动中心与半径端点调整扩散范围。形状径向模式仅用于填色，拖动中心手柄可改变渐变中心，轮廓距离场会将整个不规则填色的边缘稳定映射到 100% 色标位置，并在凹陷、回环和自交处保持连续。内部色标会显示为菱形手柄，可以直接拖动改变色标位置；普通径向模式还会显示半径圆。线条在应用渐变后仍可调整宽度；直接修改描边颜色会切回纯色描边。
- Eraser Tool：沿笔尖轨迹局部擦除绘制元素；可分别启用擦除线条和擦除填色。

Shape Tool 当前包含 Rectangle、Ellipse、Triangle、Polygon 和 Star。拖拽任一形状时，按住 `Shift` 会临时保持等比；按住 `Ctrl` 会以初始落点为中心向外绘制，两个修饰键可以同时使用。选择 Polygon 时，`Draw Settings` 会显示 `Sides`，可调 `3-64` 条边；选择 Star 时会显示 `Points`，可调 `3-32` 个尖角。参数会随对象保存，并在预览、复制、变形、撤销与场景合成中保留。Select / Free Transform Tool Group 包含 Select 和 Free Transform；Line Tool Group 包含 Line、Pen、Simple Pen 和 Pencil；Brush Tool Group 包含 Brush 和 Pressure Brush；Fill / Ink Bottle Tool Group 包含 Fill 和 Ink Bottle。父工具按钮右下角都有分组标记；鼠标悬浮时会在按钮右侧弹出各自的子工具，且彼此独立记忆最近使用的子工具。按 `Tab` 会在当前父工具的子工具中循环向后切换，按 `Shift+Tab` 循环向前切换；在非父工具状态按 `Tab` 会切换形状组。

在 `Basic Drawing` 中打开左上角主菜单并选择 `Import SVG...`，或者从资源管理器把单个 `.svg` 文件拖到舞台上，可以将 SVG 导入当前普通绘制图层和当前 Cel。通过菜单导入时对象位于视口中心；拖入时对象中心位于鼠标落点。导入结果始终只占一个对象：可以整块选择、移动、缩放、旋转、复制粘贴、调整同层顺序、删除、撤销，并随工程保存和重新打开。导入前会先完整校验文件；格式错误、DTD、外部实体或超出限制的文件不会修改当前场景。锁定图层、文件夹图层、遮罩图层和 `Scene Edit` 不允许导入。

导入后的整块 SVG 不直接开放内部节点、描边、填色或渐变编辑；Fill、Ink Bottle、Gradient、Eraser、材质面板和拓扑分段会先跳过它。需要继续编辑时，选中一个或多个整块 SVG，在舞台右键选择“拆散”，可把支持的 Path、矩形、圆、椭圆、直线、折线和多边形转换成普通复合 Path 填色与 Freeform 线条。曲线会按稳定精度展开为折线；渐变当前取中间代表色。拆到单一图层后，填色统一位于线条下方，复杂 SVG 的跨元素填色/描边交错顺序以及非圆角连接可能产生近似。文本、图片、外部资源、虚线、图案、裁剪、遮罩、滤镜和标记等不能可靠转换的内容会在删除源 SVG 前整次拒绝，因此不会留下半成品。拆散前，整块 SVG 仍不支持倾斜手柄和水平/垂直翻转。

鼠标悬浮在工具按钮上时，会显示带淡入和滑动动画的工具名称提示。

在舞台上按住 `Space` 会临时启用手形平移模式，按住鼠标左键拖拽即可移动画布；松开鼠标后仍保持临时手形光标，松开 `Space` 后恢复原工具。该操作不会切换当前工具，也不会修改选择或绘制内容。点击工具按钮后无需再次点击画布，只要鼠标已经回到舞台即可直接使用；文本、数字和下拉输入框正在编辑时，空格仍由当前输入框正常处理。2D 绘制对象、2D 场景编辑和 3D 参考视图均支持该操作。

## 工程保存与资产库

标题栏左侧的主菜单提供 `New Project`、`Open Project`、`Save Project` 和 `Save Project As`。快捷键分别为 `Ctrl+N`、`Ctrl+O`、`Ctrl+S` 和 `Ctrl+Shift+S`。首次保存或另存为时选择或新建一个专用文件夹；目标中已有未受当前工程管理的 `.Vault`、`.TimeLine`，或同名清单属于其他工程时，保存会拒绝覆盖并保留原数据。后续保存会直接更新同一资产库。工程有未保存修改时，标题会显示 `*`；新建、打开或关闭前可选择保存、放弃或取消。加载失败不会替换当前正在编辑的工程。

工程使用目录型大型资产库，而不是单个压缩包。一个工程文件夹只能包含一个 `.v2dProject` 清单，并使用以下结构：

```text
Project Folder/
  Project Name.v2dProject
  .Vault/
    <drawing-object-id>.svg
  .TimeLine/
    Drawings/
      <drawing-object-id>.json
    Scenes/
      <scene-id>.json
```

`.v2dProject` 记录格式版本、生成软件版本、工程 ID、名称、项目播放 FPS、循环与起止帧、素材文件索引、文件夹层级和 SHA-256；`.Vault` 按稳定 Drawing Object ID 保存 SVG。每个 SVG 同时包含普通 SVG 预览图元和 V2D 可逆元数据，因此路径、笔刷、渐变、复合轮廓、线端样式及编辑语义都可原样恢复；`.TimeLine` 保存绘制对象与场景的图层、轨道 ID、实心/空白关键帧、Cel 归属、嵌套实例和实例动画。打开工程时会先校验版本、路径、文件数量与累计大小、校验和、引用与时间轴一致性，全部成功后才替换当前工程。保存会先在临时目录写出并完整回读校验，再通过持久事务日志整体替换 `.Vault`、`.TimeLine` 和清单；若进程被强制结束或机器断电，下次保存或打开会先根据日志恢复上一份完整工程，或确认新版本已完整安装后清理备份。该过程自动移除已删除素材的陈旧文件，同时保留工程根目录中的其他用户文件。

标题栏左侧的主菜单也可打开 `Settings`。`Language` 提供 `English` 和 `简体中文`，保存后会立即切换工作台、菜单、工具提示、对话框、动态状态和启动错误文字，并保存到当前用户设置。默认语言为 `English`。

应用内设置、命名、输入、信息、警告、错误和二次确认弹窗使用统一的二级界面样式：自定义标题栏、明确的内容/命令分区、主次及危险按钮层级，并在打开和关闭时播放短促的淡入位移动画。`Enter` 执行默认操作，`Esc` 或标题栏关闭按钮取消；系统文件和颜色选择器继续使用 Windows 原生界面。

`Tool shortcuts` 提供两套方案并会保存到当前用户设置；默认使用 `Traditional Flash`。传统方案为：`V` 选择、`Q` 任意变形、`H` 手形、`R` 矩形、`O` 椭圆、`N` 线条、`P` 钢笔、`Y` 铅笔、`B` 笔刷、`K` 填充、`S` 墨水瓶、`I` 吸管、`G` 渐变、`E` 橡皮擦。

`Number Keys` 方案按左侧工具栏从上到下排列：`1` 当前选择组、`2` 当前形状组、`3` 当前线条组、`4` 当前笔刷组、`5` 当前填色组、`6` 渐变、`7` 橡皮擦、`8` 吸管、`9` 素材库。数字键会启用父工具最近使用的子工具。两套方案都保留 `Tab` 或 `Shift+Tab` 在当前父工具内前后循环切换；使用铅笔、普通笔刷、压感笔刷或橡皮擦时，按 `[` / `]` 可以减小或增大当前工具宽度；按 `Esc` 会取消当前尚未落笔完成的自由笔迹或渐变手柄拖动。

使用普通 Brush 或 Pressure Brush 时，按住 `Shift` 会在鼠标周围显示最近使用的颜色色块；将鼠标移到某个色块上即可切换后续笔刷的 `Fill` 颜色，松开 `Shift` 会关闭色块。该操作不会改写当前选中的对象。

使用 `任意变形` 时，边框上的八个方形手柄用于缩放，四个角外侧的圆形手柄用于旋转，四条边外侧的菱形手柄用于倾斜：上/下边沿手柄水平倾斜，左/右边沿手柄垂直倾斜。边框中心的十字圆点是旋转焦点：可直接拖动到任意位置，之后从任意角旋转都会围绕该焦点进行；拖动对象时焦点会随对象一起移动。基础形状发生倾斜时会转换为等价 Path，以保留真实的斜切轮廓。

Brush、Pressure Brush 和 Eraser 共享 `Brush Tip` 面板：可在 `Soft Round`、`Traditional Brush` 和导入笔尖之间切换。Traditional Brush 是实心硬边笔触，`Shape` 可选 `Round` 或 `Square`，右侧宽度百分比会把笔尖横向拉宽或压窄；非正圆笔尖可用 `Direction` 按度数旋转。该轮廓同时用于普通笔刷、压感笔刷、画布预览和橡皮擦范围。Soft Round 继续提供可调硬度的软边笔触。面板中的 `Size` 以 pt 调节，两个笔刷子工具共享笔刷大小，Eraser 单独记忆大小；写入场景时会转换为 vu，因此缩放舞台只会改变笔尖在屏幕上的显示直径，不会改变笔迹或擦除范围在世界坐标中的尺寸。Pressure Brush 的慢速移动和持续按住会增加笔尖直径，快速移动会减小直径。`Pressure Smooth` 仅作用于压感笔刷，默认 `70%`；它同时平滑笔划位置与压力宽度，预览与提交的填色共用同一结果。连续模式下，保持正圆的内建笔尖以一次性变半径轮廓提交，减少长笔划的计算时间；方形、变宽和旋转后的传统笔尖、导入笔尖和离散印记模式会按笔尖轮廓连续盖印。可通过 `Import 128x128` 导入严格为 `128x128` 的 PNG、BMP、JPG、GIF 图像。带透明通道的图片按 alpha 生成遮罩；普通 RGB 图片按亮度生成遮罩，随后经过 RGB 高斯柔化并生成多层软边笔迹。画布中鼠标周围会显示当前笔尖的实际轮廓；Eraser 使用同一笔尖轨迹进行擦除。

## 绘制预览

选择任意绘制工具后，在舞台按住鼠标左键并拖拽，会显示半透明绘制预览：

- 形状工具显示填充和描边预览。
- 线条工具显示线段预览和端点。
- 铅笔和笔刷会随鼠标连续显示自由笔迹预览；传统笔刷的方形、宽度和方向会直接显示在预览中，压感笔刷也会实时显示流体的粗细变化；松开鼠标后才会写入场景。
- 松开鼠标后，铅笔预览会转换为开放描边，普通笔刷和压感笔刷预览会转换为无描边的闭合 Path 填色轮廓。
- 形状和线条拖拽距离太短时不会创建对象；铅笔、普通笔刷或压感笔刷单击会创建一个圆点。

## 绘制设置

在 `Basic Drawing` 工作区可以调整绘制设置：

- 默认所有吸附、紧贴、对齐和角度吸附开关都关闭。
- Snapping 图标组：位于 `Basic Drawing` 顶部第二行右侧，集中放置吸附相关 SVG 图标开关。
- Snap：总吸附开关。
- Grid：网格吸附。舞台会根据当前缩放比例自动使用对应的可见十进制网格层级；放大时可吸附到更细的格点，缩小时自动切换到更粗的格点。
- Objects：对象吸附；用于绘制线条或拖动线条端点时吸附到附近线条端点。
- Tight Fit：紧贴占位。
- Align：对齐占位。
- Angle Snap：持续启用直线和钢笔线段的角度步进吸附。使用直线工具时也可以按住 `Shift` 临时启用同一角度步进，无需打开 Snap 或 Angle Snap。
- Grid vu：位于顶部吸附条中，设置没有舞台缩放上下文时使用的兼容网格大小，单位为矢量单位；舞台交互优先使用当前可见网格的自适应步长。
- Angle snap degrees：位于顶部吸附条中，设置角度吸附步进，单位为度。
- Aspect Ratio：位于右侧 Inspector 的 Draw Settings 中，用于固定比例绘制。
- Shape：位于右侧 Inspector 的 Draw Settings 中，用于设置当前绘制形状。
- Smoothing：控制铅笔和笔刷的自由路径平滑程度。平滑和简化误差按屏幕像素换算，因此不同缩放比例下的手感保持接近。

当前吸附功能主要作用于形状、线条创建和编辑时的点位计算。开启网格吸附后，形状、渐变手柄、钢笔锚点与控制点、线段端点都会吸附到当前缩放层级实际显示的格点。铅笔和笔刷保持连续手绘输入，不使用网格吸附；使用直线工具拖拽时按住 `Shift`，预览和最终线段会按 `Angle snap degrees` 吸附到最近角度。开启 `Snap` 和 `Objects` 可持续启用线条端点吸附，也可以在绘制线条或拖动端点时按住 `Ctrl` 临时启用。当对象吸附与网格吸附同时开启且指针命中对象端点时，对象端点拥有更高优先级，不会再被网格量化拉开；对象端点也优先于角度吸附。高级紧贴和对齐仍是后续扩展占位。

## 选择和编辑对象

切换到 Select 工具后：

- 点击对象可以选中。
- 按住 `Shift` 点击对象或线段可以追加多选；按住 `Shift` 框选会把框内对象并入当前选择，空框不会清空已有选择。
- 拖动框选区域时，选框使用独立于画布场景重绘的轻量覆盖层同步跟随指针；鼠标按下后会先显示选框，再把拓扑恢复、线段合并和完整选区计算延迟到松开鼠标时执行，因此复杂渐变、蒙版、网格或大量对象不会阻塞选框首次出现和后续更新，选区命中规则不变。
- 双击线条或填色边界，会选中当前帧、同一图层中通过端点、T 形接点或交点相连的全部线段。
- 在空白区域按住左键并拖拽，可以使用框选选择多个对象。
- 框选会选择完整位于矩形内的对象或现有拓扑分段；穿过选框边界的 Line 和 Fill 会暂时分成独立部分，并选中框内部分。Pencil 笔迹仍保持非破坏性选择；若未编辑这些临时部分便取消选择，软件会还原框选前的原始对象。
- 框选得到的拓扑分段可以直接移动、删除、复制或修改材质；执行这些操作时才会按当前交点关系实体化。
- 如果鼠标按下位置存在已选中的填色，按住左键拖拽会优先移动该填色；只有没有命中已选填色时，才进入普通选择或框选流程。
- 如果从未选中的填色区域内部直接拖拽，软件会把这次拖拽识别为框选；填色已经被选中后，再次从该填色上拖拽才会移动它。
- 拖拽已选对象主体可以移动。
- 框选多个对象后，拖拽其中任意已选对象可以整体移动这一组选中对象。
- 选中线条或填色后会显示带呼吸动画的高亮轮廓；填色使用较细的冷色青绿边界，线段和填色边界描边使用更强的暖色金黄/橙色路径高亮，因此在复杂画面中可以直接区分当前选中的是填色还是线段。动画沿真实线条路径或填色边界变化，不会改写对象本身的颜色与透明度。
- 多选时会显示多对象高亮轮廓，主选中对象继续显示可编辑手柄。
- 选中填色形状后，会显示边界角点手柄。
- `Ctrl+X` 会将当前选中的本地矢量对象或嵌套绘制对象实例剪切到内部剪贴板；之后可用 `Ctrl+V` 粘贴。实例剪贴板会保留源对象引用、宿主图层和全部状态关键帧。舞台右键菜单提供水平翻转、垂直翻转、上移一层和下移一层；这些命令同时支持本地矢量对象和嵌套绘制对象实例。层级调整只在对象所属的当前图层与当前关键帧内移动一步，不会跨越图层；嵌套实例翻转会写入当前关键帧的独立实例状态。上移一层和下移一层也可分别使用 `Ctrl+↑` 与 `Ctrl+↓`。
- 拖动边界角点可以调整对象边界尺寸。
- 点击填色形状的描边边界时，会选中边界线段；被选中的边界段会单独高亮。
- 矩形、三角形、多边形和星形等基础形状的直线边界被选中后，会立即显示起点、终点和中点曲率手柄。拖动任一手柄时才会将该边实体化为独立 Line，随后可继续像普通贝塞尔线条一样编辑。
- 拖动被选中的线条段或边界段时，该虚拟拓扑部分会先实体化为独立对象，然后跟随鼠标移动；被穿过线切出的矩形填色区域也会在小范围框选时实体化。框选同时切出填色和部分外边界时，两者会作为一个整体平移，边界联动不会再次回写并拉伸已经移动的填色。
- 从填色边缘实体化的线段会继续关联原填色轮廓。移动整条线、端点、贝塞尔控制点，或使用任意变形的移动、缩放、旋转、倾斜时，填色边缘会同步扩张或收缩，避免在线条与填色之间留下缝隙；未共享端点的独立线条不会影响填色。
- 选中线条后会立即显示起点、终点和贝塞尔控制点；点击到线条的拓扑分段时也会显示该线条的全部控制点，并可直接拖动。
- 铅笔的一次按下到抬起会保存为一个开放描边对象；点击笔迹可整体选择、移动、删除、复制、粘贴和撤销，不显示矩形缩放手柄。
- 笔刷的一次按下到抬起会生成闭合 Path 填色；它按填色对象参与选择、移动、删除、复制、粘贴和撤销，并可能在落笔时与同色填色自动合并。
- 拖动线条起点或终点可以调整线段端点；如果多个线段端点已经连接在同一位置，这些连接端点会一起移动以保持连接。拖拽期间会缓存可见区域中的吸附候选，线段预览保持高频刷新，关联填色轮廓按独立节奏更新并在松开时精确提交。相同颜色和粗细的锐角线在端点交汇时会按进入方向排序并逐对斜接；三条及以上线从同一侧汇聚时，由最外侧方向形成连续尖角，中间线补齐内部连接，避免退化成圆头、平头或中心缝隙。
- 开启 `Snap` 和 `Objects` 后，拖动线条端点靠近其他线条端点时会自动吸附；按住 `Ctrl` 可在不开启这些开关时临时吸附。Line Tool 绘制新线条的起点和终点同样支持此操作。
- 拖动贝塞尔控制点可以把线条调整为曲线。
- 按 Delete：删除当前选中的一个或多个绘制对象。
- `Ctrl+Z`：撤销最近一次场景编辑，包括绘制、删除、移动、端点/控制点调整、填充、材质修改、粘贴和拓扑 part 实体化。
- `Ctrl+C`：复制当前选中的一个或多个对象。
- `Ctrl+V`：粘贴复制的对象，并在舞台上偏移一小段距离后选中新对象。

选择命中支持填色、自由线条和填色对象的边界描边。线条按贝塞尔曲线距离判断，填色对象按对象边界判断。

当焦点位于文本输入框或数值输入控件中时，`Ctrl+Z`、`Ctrl+C`、`Ctrl+V` 会优先保留给该输入控件使用。

## 绘制元素和拓扑规则

当前引擎开始把绘制对象内部拆成绘制元素：

- 填色是绘制元素。
- 线条是绘制元素。
- 填色对象的边界描边也是绘制元素；例如默认矩形的四条边可以分别选中。
- 渲染顺序先遵守图层：时间轴最上方的 `Layer 0000` 位于最前；同一图层内先绘制全部填色，再绘制 Line、Pencil 和填色对象的边界描边，因此线条会显示在同层填色之上，但不会穿透更高图层的填色。
- 舞台中的实色、线性渐变、径向渐变和形状径向渐变统一使用屏幕像素级几何抗锯齿。Direct2D GPU 渲染与 GDI 回退都会保留边缘的亚像素覆盖，并用不足一个屏幕像素的同材质覆盖抑制浅色填色在深色舞台上产生的暗边；处理只作用于轮廓，不会模糊填色内部。
- 同一个图层、同一个关键帧中，同一个 `1 vu` 绘制单位区域只允许一个填色单位有效。后提交或移动后的不同颜色或不同渐变填色会从已有填色中裁掉相交区域，因此重叠区只保留最新填色的材质；原对象的描边会保留为独立边界线。不同图层和不同关键帧内容彼此不受影响；相同材质的相交填色仍会尝试合并为一个复合 Path。
- 线条和填色边界相交或相切时，线条会按交点切分为多个可命中的线段部分，填色边界描边也会被反向切分。
- 线条和线条相交时，也会按交点建立拆分关系；新绘制线条的端点停在线段或贝塞尔曲线内部时，即使没有穿过，也会把接触位置实体化为共享的 T 形切分端点。选择时会根据鼠标所在的线段部分显示 `Stroke part N`。
- 线条拓扑统一按二次贝塞尔曲线处理，曲线和曲线、直线和曲线、直线和直线使用同一套拆分逻辑；直线是控制点位于中点的特殊曲线。
- 线条拆分点会量化到矢量单位，且不会继续切出小于 `1 vu` 的线段部分。
- 填色如果被线条明确穿过边界，则选择时会根据切分侧显示不同的 `Fill part N`。
- 如果线条没有完整穿过填色边界，填色仍然按一个整体选择。
- 典型矩形切分：一条线从矩形外部穿过矩形并从另一侧穿出时，矩形填色会形成两个可命中的 `Fill part`，矩形边界描边会从默认四边变为六段，穿过矩形的新线条会被矩形边界反向切成三段。
- 框选穿过选框边界的 `Line` 会直接实体化为独立线条对象，框内段会被选中高亮；`Fill` 和 Pencil 笔迹仍按现有拓扑分段或完整对象选择。
- Path 填色支持复合轮廓：一个填色对象可以包含外边界和一个或多个内孔边界，因此允许完整的环形、甜甜圈形状等闭合区域填色存在。
- 复合填色使用 even-odd 规则渲染和命中测试：点击环形实体部分会选中填色，点击内孔空白区域不会选中该填色；复制、粘贴和撤销会保留内孔。
- 同一图层中 ARGB 颜色完全相同的填色对象在绘制、移动、缩放、粘贴、填充或材质改色后会尝试自动合并；两个填色区域相交，或其边界距离小于 `10 vu` 时，会基于真实填色轮廓生成合并区域。Brush 生成的闭合填色也遵循此规则。合并结果如果形成内孔，会保存为复合 Path 填色，不再把内孔填实。
- 同一图层、同一关键帧内容中的直线段会在绘制、移动、端点编辑、粘贴、删除、填充或材质修改等场景变更后检测合并。只有方向一致且共线、描边 ARGB 与粗细完全相同，并且至少一对端点距离严格小于 `5 vu` 时才会合并；错位平行线、贝塞尔曲线、不同图层或不同帧内容不会误合并。合并结果保持为一条直线，并作为同一次操作参与撤销。连续拖动颜色或宽度时，会在拖动完成后按最终材质检测，避免经过中间值时提前合并。
- 在 Basic Drawing 舞台右键会打开带主题、高对比文字和开场缩放回弹动画的菜单。命中已选 Line 时，`Convert Lines to Fill` 会把所有已选 Line 的完整可见描边轮廓转换为无描边的 Path 填色；命中未选 Line 或右键空白处时，只转换该 Line 或当前选中的 Line。填色颜色取原 Stroke，保留图层、关键帧和绘制顺序，并可通过 Undo 撤销。
- 同一菜单中的 `Break Apart / 拆散` 适用于所选整块 SVG 或嵌套绘制对象实例。SVG 会转换成普通填色和线条；实例会按当前帧、当前播放设置和完整父子变换递归展开到各自宿主图层新物化的当前 Cel，并从当前帧起隐藏原实例。多个目标作为一次操作提交，任一目标包含不支持内容时全部保持原状；`Ctrl+Z` 会恢复原 SVG 或实例。带文件夹/遮罩图层的嵌套来源暂不拆散，以免把分层效果错误压平。
- 同一菜单中的 `Merge and Simplify Lines` 在命中 Line 时处理该线及其连通线链；右键空白处则处理当前选择中的线段。框选产生的部分线段会自动补齐同一原线的物化兄弟段，再执行简化。该命令只影响命中/选择范围内满足相同方向、端点、颜色和粗细条件的直线，并可通过 Undo 撤销。钢笔存在未完成路径时，右键仍用于取消该路径。

当前拓扑解算使用基础形状边界和自适应采样的贝塞尔曲线，覆盖现有矩形、椭圆、三角形、多边形、星形、Path 填色和线条。矩形填色被单条穿过线切分后的移动和框选矩形拆分已经可用；复合 Path 已能表达洞和多轮廓填色，后续复杂路径、多条切线、多重交叠和完整面片重建会继续扩展。

Pencil 生成的开放笔迹当前作为完整 `Stroke` 对象参与命中、框选和移动，不会像 Line Tool 的贝塞尔线条一样在交点处自动切段，也暂不作为填色区域的拓扑切割线。Brush 生成的是闭合 Path 填色，不是 `Stroke`；它按填色规则参与命中、框选、移动和同 ARGB 自动合并。

## 填充颜色和材质

在 `Basic Drawing` 右侧检查器的 Materials 区域可以调整。Fill 或 Stroke 会始终保持一个高亮的当前编辑目标；选择 Fill 时会隐藏仅属于描边的 `Width pt`，选择 Stroke 时再显示。点击 `Color` 或任意颜色目标可展开色环和 RGB/HSV/HSL 通道；Hex 输入框始终显示。Paint 行末的色板图标在纯色与渐变模式下都会显示，并可打开紧凑的颜色与渐变预设选择器：

- Fill / Stroke：点击目标按钮决定当前正在编辑填色还是描边颜色；未选中对象时两者会分别保留自己的实色与渐变配置，两个缩略图始终显示各自的当前状态，切换目标不会串改或遮蔽另一方的颜色、色标。新绘制对象会保存自己的描边颜色。
- Paint：切换 `Solid`、`Linear`、`Radial` 或 `Shape`。`Shape` 是仅用于 Fill 的形状径向渐变，中心色会沿每条射线平滑过渡到不规则轮廓上的边缘色；编辑 Stroke 时该选项禁用。`Solid` 会收起色标、位置与增删控制；切换到渐变时自动展开这些控制并选择第一个色标，颜色平面、通道和调色板会直接编辑该色标；切回 `Solid` 后则恢复编辑当前 Fill 或 Stroke。渐变条使用与 Adobe 类似的颜色停靠点：点击停靠点选择颜色，点击渐变条的空白位置添加色标，拖动内部色标改变位置，或使用 `+`/`-` 添加和删除；端点位置固定为 0% 和 100%。新绘制的 Line 会直接使用当前线性或普通径向渐变；渐变端点、中心和内部色标可通过 Gradient Tool 在舞台中拖动。
- 色板图标：将内置色、Recent、Custom 与渐变预设放入同一个紧凑弹出面板。提供 `Sunset`、`Ocean`、`Aurora`、`Ink` 四个线性渐变，以及 `Spotlight`、`Bloom` 两个径向渐变；点击预设会同时写入全部色标并切换到预设对应类型，点击颜色或预设后面板自动收起。Gradients 标题右侧的 `+` 会保存当前线性、径向或形状径向渐变，`-` 删除当前选中的已保存渐变；已保存的预设会写入 `data/material-palettes.json`，重启后仍可使用。Materials 顶部的 Fill 缩略图会按当前渐变类型显示预览和色标数量。
- Color Harmony Wheel：展开 Color 后显示 Adobe 风格色环。色环内外侧具有扩展的鼠标热区，指针变为手形时即可按下拖动；鼠标方向的环面会显示带高光的小幅凸起，帮助确认当前交互方向。拖拽期间以高频指针采样更新颜色和环面反馈，即使进入内圆区域、越过外缘或移出控件，也会继续按指针方向调整当前 Fill、Stroke 或渐变色标的主色相。RGB/HSV/HSL 与 Alpha 控制条也会在指针位置上下产生平滑的局部突起，并在拖出控制条后继续高频更新数值和形变反馈。环内节点会显示当前规则的所有颜色。可选择 `Complementary`、`Analogous`、`Triadic`、`Split complementary` 或 `Tetradic`，并直接点击右侧生成的色块应用该颜色。各通道数值输入可精确调整颜色和 Alpha，并会与常驻 Hex 输入框同步。
- RGB：以红、绿、蓝通道编辑颜色。
- HSV：以色相、饱和度、明度编辑颜色。
- HSL：以色相、饱和度、亮度编辑颜色。
- Hex：常驻显示，可输入 `#RRGGBB`、`#RRGGBBAA` 或三位简写颜色值。
- Colors / Recent / Custom：色板图标内提供内置常用色、最近应用的颜色和本次运行期间的自定义色；点击色块会应用到当前 Fill、Stroke 或渐变色标。Recent 左侧显示纯色，右侧显示最近使用过的线性、径向和形状径向渐变缩略图。使用 `+` 保存当前颜色，使用 `-`、Delete 或右键删除自定义色块。
- Width pt：描边宽度，单位为点。`1 pt` 固定等于 `0.5 px`，并按 `1 px = 25 vu` 转换为内部矢量单位。

Pencil 使用 `Stroke` 颜色并生成开放描边；Brush 使用 `Fill` 颜色并生成无描边的闭合填色轮廓。Pencil、Brush 和 Eraser 分别记忆自己的 `Width pt`；Brush 与 Eraser 的大小也可在 `Brush Tip` 面板直接调整。Brush 的 `Width pt` 控制后续笔刷填色的笔迹宽度，不会给生成的 Path 添加边界描边。

使用 Fill Tool 点击已有对象，可以把当前材质颜色应用到该对象；点击线条会改为当前 Fill 颜色，按住 `Shift` 会对所有端点连通的线条一起应用。使用 Eyedropper Tool 或按 `I` 可从填色、线条和描边吸取对应颜色与渐变。

如果已选中对象，在材质面板调整参数会直接影响当前对象。

`Basic Drawing` 工作区右侧检查器中的 `Fill`、`Stroke` 和 `Width pt` 会同步到当前材质。透明度可通过 RGB/HSV/HSL 的 Alpha 通道或常驻 Hex 输入框设置。调整 `Width pt` 后，后续绘制的形状会使用新的描边粗细；如果当前已有对象被选中，也会立即更新该对象描边。

## 图层和 Vault

图层功能已经合并到底部图层时间轴中：

- 左侧图层栏：管理当前场景图层。
- 右侧时间轴轨道：显示每个图层的保持曝光、实心关键帧、空白关键帧和播放头。

Vault 位于窗口左侧边缘的抽屉中，点击悬浮工具栏上的 `V` 按钮可以打开或关闭。Vault 只显示当前项目中的绘制对象素材。

Vault 以固定宽度覆盖层滑入，不会在打开动画中缩放舞台或触发 GPU 渲染目标重建；项目绘制对象没有变化时会复用已经生成的列表行，因此重复打开大型素材库时不会再次全量创建列表。

### 图层时间轴

底部图层时间轴左侧显示当前场景图层：

- 点击图层可设置为当前活动图层。
- `Ctrl` 点击图层可追加或取消多选，`Shift` 点击可按当前可见的时间轴顺序选择连续图层，`Ctrl+A` 可全选当前可见图层。多选图层会在左侧图层栏中高亮显示。
- 点击任一已选图层的眼睛或锁定图标，会将显示/隐藏或锁定/解锁统一应用到所有选中图层；图层名称栏右键的 `Show Selected Layers`、`Hide Selected Layers`、`Lock/Unlock Selected Layers` 和 `Layer Color for Selected...` 同样支持批量操作。重命名、新建和移动仍只作用于单个图层。
- 拖拽图层名称可以调整图层顺序；对象归属和对应时间轴轨道会一起保持。
- 点击图层左侧眼睛图标可切换该图层可见性。
- 双击图层行也可以切换该图层可见性。
- `Solo` 只显示当前活动图层。
- `All` 显示全部图层。
- 每个图层名称前的色条表示图层颜色；在图层名称栏右键选择 `Layer Color...` 可以修改。该颜色用于时间轴识别，不会改写图形本身的填色或描边。
- 在图层名称栏右键选择 `Rename Layer...`，或在时间轴获得焦点时按 `Shift+F2`，即可重命名当前图层；绘制图层和场景图层均支持重命名。`F2` 用于全局显示或隐藏时间轴面板。
- 每行眼睛图标右侧是锁定图标。点击它或在图层菜单选择 `Lock Layer` 可锁定当前绘制图层；锁定文件夹会同时锁定子层，已锁定图层的内容不会被选择或编辑。
- 在绘制对象时间轴的图层名称栏右键，可选择 `New Folder Layer` 或 `New Mask Layer`。`+` 按钮仍用于新增普通绘制图层。
- Folder Layer 会把当前绘制图层收纳为子层；子层在时间轴中缩进显示，文件夹的可见性会统一控制所有子层。
- Folder Layer 名称前有展开箭头；点击箭头或选中文件夹后按 `Left` / `Right` 可以折叠或展开子层。折叠只影响时间轴显示和可操作行，不会改变子层的绘制、可见性、锁定状态或帧内容。
- Mask Layer 会创建在当前绘制图层上方，并自动关联该内容层。时间轴会将关联内容层缩进显示在遮罩层下方；遮罩层名称前的展开箭头可折叠或展开该内容层，也支持选中遮罩后按 `Left` / `Right`。折叠只影响时间轴中的显示和可操作行。遮罩层当前 Cel 中的封闭填色形状会裁切关联内容层；遮罩层未锁定时，遮罩图形会正常显示并可继续编辑，锁定后才会隐藏遮罩图形本身，仅保留裁切结果。遮罩为空、隐藏或当前帧没有内容时，关联内容层不会显示。
- 拖拽图层名称时，拖到 Folder Layer 行的中央可把图层放入该文件夹；拖到任意行的上边缘或下边缘会放在该层之前或之后，并继承其父文件夹。把图层拖到根层的边缘即可移出文件夹。拖动遮罩层到普通绘制图层中央，或反向拖动普通绘制图层到遮罩层中央，会建立遮罩-内容关系并自动将遮罩放在内容层上方。时间轴始终将遮罩和唯一关联内容层作为连续组显示与移动：拖到内容层上方会落在整个组之前，拖到遮罩层下方会落在整个组之后，普通图层不会插入两者之间。移动文件夹会同时移动其子层；移动已关联的遮罩或内容层时，两者会保持在同一层级关系中。文件夹不能拖入自身或其子层。
- 时间轴标题栏中的 `Onion` 开关可为当前绘制图层启用洋葱皮，`Prev` 与 `Next` 可分别设置前帧、后帧范围（0-8 帧）。将范围调整为非零会自动启用当前图层的洋葱皮。舞台会在当前帧所有绘制对象和本地几何的下方显示相邻 Cel 的半透明预览，前帧为暖色、后帧为冷色，因此深色线条和渐变图形也能清晰辨认；预览只用于参考，不能选择或编辑，也不会写入当前帧。
- 时间轴帧格采用紧凑尺寸，可在同一宽度和高度内查看更多帧与图层。插入实心关键帧时，当前选中的绘制对象实例会按稳定 ID 在目标关键帧继续保持选中，便于连续制作传统元件动画。残影范围手柄位于帧标尺最下方的窄轨道内，只有彩色端点握柄本身可拖动；端点上方仍用于拖动播放头，从而减少预览时误触残影范围。

新绘制对象会添加到当前活动图层。

### Vault

Vault 使用紧凑的“项目素材 + 数量 + 打开”标题栏，下方直接列出当前项目的全部 drawing objects，不再显示单独的来源标签、说明区、列标题或底部操作栏。新建、重命名、复制或删除绘制对象后会按需刷新；双击或点击标题栏中的 `Open` 会进入对应对象编辑器。项目对象可以拖到 `Scene Edit` 舞台创建场景实例，也可以拖到 `Basic Drawing` 舞台创建当前绘制对象的子实例，循环引用会被拒绝。

鼠标在 drawing object 上停留片刻会弹出实际几何预览，预览包含当前帧内容和嵌套 drawing objects，并自动按内容取景。旧版 `Library`、`Stored`、Capture、Note 和 File 入口不再显示，打开素材库时也不会读取持久化 Vault 文件。

## 时间轴和播放

底部图层时间轴支持：

- 左侧点击图层设为当前活动图层。
- 拖拽图层名称可调整图层顺序；右键菜单也提供上移和下移。
- 标题栏中的 `+` 新增图层；在 `Scene Edit` 中会新增场景图层，随后添加的绘制对象实例会进入当前场景图层。
- 左侧眼睛图标或双击图层行切换图层可见性。
- `Solo` / `All` 控制当前活动图层独显或显示全部图层。
- 查看帧尺。
- 拖动播放头切换当前帧。
- 在帧网格点击可选择一个帧单元格；拖拽可框选连续的多轨道、多帧区域，按下鼠标后即使指针移动到图层名称、标尺、滚动条或时间轴控件外，选区仍会持续更新到帧网格中距离指针最近的行列。图层较多时，将指针停留在轨道视口上方或下方会逐行自动滚动，并继续扩展选区到隐藏图层。`Shift` 点击扩展矩形选择，`Ctrl` 点击追加或取消单元格选择。当前末帧之后会保留一屏可滚动的空白网格，这些尚不存在的帧同样可以选择并执行“插入帧”，插入后轨道会自动延长到目标位置。批量命令会作用于所选单元格；未选择时作用于当前轨道和播放头。
- 右键帧网格会打开时间轴菜单，可复制、粘贴、插入或删除帧，以及插入、清除实心/空白关键帧。`Ctrl+C` / `Ctrl+V` 在时间轴获得焦点时复制和粘贴 Cel；粘贴会按照复制区域的轨道和帧偏移写入独立内容。
- 在图层名称栏右键会打开 `Layer` 菜单，用于新建绘制/文件夹/遮罩图层、调整图层顺序和设置图层颜色；在帧网格或帧尺右键会打开 `Frame` 菜单，用于 Cel 复制、粘贴、插入/删除帧及关键帧操作。两个菜单会按右键落点显示，避免混合无关命令。
- 时间轴顶部中央有上下双向拖拽手柄。向上拖动可增大时间轴高度以查看更多轨道，向下拖动可缩小；拖动期间会在每次高度更新时同步当前上下文的最新图层、顺序和选择状态。最小高度会保留图层、帧尺和滚动条的可操作空间。
- 窗口顶部右侧的 `FPS` 输入可随时调整动画帧率，默认 `30.000 FPS`，范围为 `1.000-120.000 FPS`，支持 `23.976`、`29.970`、`59.940` 等三位小数帧率。把指针放在某一位数字上滚动时只调整该位，修改会立即同步到时间轴、播放调度和 Animation 属性页，并与循环及起止帧一起保存到当前工程；打开工程时，起止帧会夹紧到当前时间轴的有效范围。
- 绘制对象时间轴顶部的 `Auto Key` 可开关画布自动关键帧，`Onion`、`Prev` 和 `Next` 控件用于启用当前图层残影并调整前后帧范围。播放动画时残影会自动隐藏以保持流畅，暂停或停止播放后会在当前帧自动恢复。
- 时间轴右侧的 `帧宽` 滑块和数字框可在 `8-32 px` 之间调整时间轴帧格宽度，默认 `14 px`。拖动时帧尺、帧格、选区、播放头、命中区域和横向滚动条会同步缩放，并尽量保持当前播放头的屏幕位置；完成调整后宽度会保存到应用设置。
- `帧高` 提供 Adobe Animate 风格的低、中、高三档：低 `16 px`、中 `21 px`、高 `28 px`，默认使用中等高度。切换时图层行、帧格、关键帧标记、选区、播放头和纵向滚动容量会同步更新，并尽量保持当前活动图层的屏幕位置；选择会保存到应用设置。
- 时间轴标题会在播放头旁显示按当前 FPS 换算的秒制时间，格式固定为三位小数，例如第 13 帧在 `30 FPS` 下显示 `0.433 s`，第 24 帧在 `23.976 FPS` 下显示 `1.001 s`；修改 FPS 或移动播放头后读数会立即更新。
- 查看从关键帧保持到下一个关键帧之前的曝光范围。
- 实心关键帧表示 `Populated`，该轨道内容从此帧开始保持显示。
- 空白关键帧表示 `Blank`，该轨道从此帧开始保持为空白，直到后续实心关键帧恢复内容。
- 新建空绘制图层从第一个空心关键帧开始。关键帧是否实心由 Cel 中是否真的存在对象决定；删除 Cel 的最后一个对象后，标记会自动变为空心。
- 绘制对象时间轴中的每个实心关键帧拥有独立 Cel。新建关键帧时会复制前一个保持中的 Cel；之后在新 Cel 中移动、改色、添加或删除对象，不会修改前一个关键帧。
- 开启 `Auto Key` 后，绘制、移动、变形、粘贴、填充、擦除、删除、调整层叠顺序或材质等画布修改会在提交前，为所有实际受影响的绘制图层在当前播放头创建独立关键帧和 Cel；保持曝光中的旧 Cel 不会被反向改写。已在关键帧上时不会重复复制，无实际变化或取消的手势不会留下关键帧；一次撤销会同时撤销画布修改和自动生成的关键帧。开关状态会保存到应用设置。
- 同一绘制图层中的绘制对象实例也按实心关键帧保存完整状态；移动、旋转、缩放、倾斜、可见性或播放方式的修改只从当前关键帧开始保持，不会反向修改更早的关键帧。复制和粘贴关键帧时会一起复制这些实例状态。
- `F6` 位于空白曝光时仍会得到空心关键帧，不会凭空恢复前一个 Cel 的图形。
- 关闭 `Auto Key` 时，在空白曝光的普通保持帧上直接绘制仍会填充该曝光的源空白关键帧；如果内容必须从当前播放头才开始，请先在当前帧按 `F6` 或 `F7` 建立关键帧。开启 `Auto Key` 时，新内容会归属当前播放头自动建立的 Cel。
- 插入或删除帧时，关键帧标记和 Cel 内对象的所属帧会一起移动；撤销快照也会完整保留对象所属的关键帧。
- 每帧使用当前帧宽设置绘制单元格，帧尺每 5 帧显示一个主要编号；当前帧移动到可视范围外时，时间轴会自动水平滚动跟随。
- 鼠标滚轮在时间轴任意区域默认纵向滚动轨道列表；按住 `Shift` 滚动时改为横向移动帧区域，每格移动 3 帧。到达对应方向的边界时不会自动切换到另一个方向。时间轴下方水平滚动条的左右箭头每次移动 1 帧，点击空白轨道会按当前可见宽度翻页，也可以拖动滑块。
- 当轨道数量超过可见行数时，也可以拖动右侧细纵向滚动条。
- 使用 `Ctrl` 或 `Shift` 形成多帧或多图层选择后，点击轨道行与帧尺之外的时间轴空白背景可取消帧多选，并把图层多选收回到当前活动图层。
- 连续多帧选区使用一个覆盖整个范围的矩形高亮，不再为每个帧格重复绘制边框；使用 `Ctrl` 形成的不连续选区仍分别显示独立的高亮块。
- 帧格采用接近 Adobe Animate 的曝光样式：实心与空心关键帧分别使用填充圆点和空心圆点，关键帧之间以低对比曝光底色、水平保持线和末端封口连接；蓝色矩形表示帧选区，红色播放头独立显示当前帧。

图层时间轴在 `Basic Drawing` 中也会保持可见，便于绘制时直接切换图层和帧。

时间轴沿用 Adobe Animate 的常用快捷键。快捷键作用于当前活动轨道和播放头，或当前多帧选择；正在编辑文本、数字或下拉输入框时不会抢占输入：

- `Enter`：播放或暂停。
- `,` / `.`：上一帧 / 下一帧。
- `Shift+,` / `Shift+.`：跳到播放范围第一帧 / 最后一帧。
- `F5`：延长当前帧所属的曝光，当前关键帧保持原位，后续关键帧向右移动，轨道时长增加；操作成功后播放头会自动移动到这次新增曝光的末帧。
- `Shift+F5`：删除当前帧并将后续帧向左移动；如果被删除的是某个 Cel 的第一格，但该 Cel 还有后续保持帧，其内容会保留并重新落到删除位置。
- `F6`：单帧命令与 Adobe Animate 保持一致：播放头位于普通保持帧时，直接在当前帧插入关键帧且播放头不移动；播放头已经位于实心或空心关键帧时，先前移一帧，再在下一帧插入关键帧。多帧选择保持选择区域。绘制对象轨道会复制当前保持中的 Cel；有内容时显示实心，没有内容时保持空心。场景图层轨道会从此帧恢复该图层中的实例曝光，必要时扩展时间轴。撤销这次插入时，关键帧内容、播放头、帧选区、选区锚点和活动轨道会一起恢复到操作前状态。
- `Shift+F6`：清除当前位置的关键帧标记和该关键帧独有的 Cel 内容，当前位置重新继承前一个关键帧的保持曝光。
- `F7`：单帧命令先将播放头推进一帧，再在新位置插入空白关键帧；多帧选择保持选择区域，并按每条轨道的连续选区处理：前 `n-1` 帧清除独立关键帧并显示为前一 Cel 的延长曝光，只在选区最后一帧创建空白关键帧。不连续选区会分别处理，帧 0 的必需根关键帧保持不变。空白关键帧会清除该帧原有的独立 Cel 内容；之后在该帧绘制会自动创建新的实心 Cel，必要时扩展时间轴。撤销插入会同时恢复空白关键帧、此前的播放头和完整帧选区。
- 时间轴命令完成后会在受影响的帧格显示短暂反馈：复制使用虚线闪框，粘贴使用横向扫入，插入普通帧横向展开，删除帧向中心收缩，实心关键帧产生脉冲，空白关键帧显示扩散圆环，清除关键帧则淡出。动画只重绘相关帧格，不会改变选区、布局或播放头位置。
- 时间轴检测到真实图层集合变化时也会提供行级反馈：新增图层从插入位置向上下展开并淡入；图层删除后会使用删除前保存的名称、颜色和行位置绘制向中心收缩的淡出残影。嵌套实例轨道的增删不会误触发图层动画。

顶部播放按钮用于播放/暂停。`Animation` 工作区可以设置：

- FPS：默认 `30.000`，可设范围为 `1.000-120.000`，支持三位小数并与窗口顶部 FPS 输入双向同步。项目 FPS、循环和起止帧会随工程保存；绘制对象实例的独立播放 FPS 同样支持三位小数。
- 是否循环播放。
- 起始帧。
- 结束帧。

## 压测场景

软件默认不会创建压测数据。

需要压测时，在 `Basic Drawing` 中点击顶部 `Run Stress Scene`。当前按钮会在活动绘制对象中生成：1000 个图层、100000 个绘制对象、100000000 个虚拟矢量基础元素；场景组合上下文中该操作会被禁用。

压测目标是验证大规模场景下的视图渲染和交互响应，不代表完整生产级矢量几何精度。

压测数据生成、LOD 摘要、空间索引、可见对象收集和场景组合准备会按 CPU 核心拆分为确定性批次。每个 worker 只写自己的缓冲区或对象区间，完成后按固定顺序归并，因此多线程调度不会改变对象层级和绘制顺序。

Direct2D 会将带版本号的 LOD 摘要缓存成预乘透明位图。适配舞台时仍统计可见逻辑瓦片，但每个场景每帧只提交一次位图绘制命令；摘要更新或渲染目标重建时缓存会自动失效。

## 渲染后端

舞台渲染使用 Direct2D 硬件 HWND RenderTarget，由 GPU 完成光栅化，并采用即时呈现模式，避免拖拽时在 UI 线程等待垂直同步。

- 软件外壳仍是 WinForms 桌面端。
- 没有使用 WPF。
- 播放调度以批处理方式结算 `300 UPS` 固定逻辑步长；舞台重绘请求仍以 `144 FPS` 为上限，状态栏中的 Render FPS 统计实际完成的舞台帧，而不是重绘请求次数。
- 如果当前机器无法创建 Direct2D 硬件目标，舞台会回退到旧的 GDI 渲染路径，保证软件仍可启动。
- Direct2D 路径继续使用空间索引、瓦片 LOD、绘制预览、选择高亮和贝塞尔控制点。

当前 Direct2D 路径由 CPU 准备复杂矢量拓扑，再交给 GPU 光栅化，主要降低大量矢量对象绘制时的 GDI 压力。后续还可以继续把大批量对象转换为持久 GPU 几何缓存和实例化绘制。

## 视图操作

- 2D 舞台中鼠标滚轮：缩放舞台。
- 2D 舞台中按住鼠标中键并拖拽：平移舞台。该操作是全局视图操作，不受当前工具影响。
- 2D 舞台中按住 Ctrl + 鼠标中键并上下拖拽：缩放舞台。该操作是全局视图操作，不受当前工具影响。
- `Fit Stage`：适配完整舞台。默认项目视图不是完整舞台，而是宽度 `4000 vu` 的工作视图。
- 顶部 `+` / `-`：以舞台中心缩放。

3D Scene Edit 使用 Blender 风格视图操作：

- 鼠标中键拖拽：旋转 3D 视图。
- `Shift+鼠标中键拖拽`：平移 3D 视图。
- `Ctrl+鼠标中键上下拖拽`：推近/拉远 3D 视图。
- 鼠标滚轮：推近/拉远 3D 视图。
- `Ctrl+鼠标滚轮`：调整 3D 视图缩放系数。
- `Numpad 1/3/7`：前视图、右视图、顶视图。
- `Ctrl+Numpad 1/3/7`：后视图、左视图、底视图。
- `Numpad 5`：切换透视/正交投影。
- `Home`：重置 3D 参考视图。
- `Alt+鼠标右键拖拽`：兼容旧操作，仍可平移 3D 视图。

## 当前限制

- 当前舞台已使用 Direct2D 硬件目标和即时 GPU 呈现，但复杂矢量路径还没有完整的持久 GPU 几何缓存。
- 路径级节点编辑还未完整实现，目前是基础形状边界和线条贝塞尔控制点。
- 导入 SVG 默认作为单个整块对象保存和渲染；拆散前不支持内部路径/材质编辑、倾斜或镜像。支持的基础矢量内容可通过舞台右键“拆散”转换为普通填色和线条。
- 高级对象吸附、紧贴和对齐仍在逐步实现。
- 时间轴已经支持独立保持 Cel、实心/空白关键帧、多帧选择、复制/粘贴、插入/删除帧、图层顺序/颜色、按绘制图层启用的洋葱皮、对象所属帧快照和场景实例组合预览；当前还没有补间、关键帧曲线编辑或场景实例变换关键帧。
