# Vector 2D Animation Engine 操作教程

本文档记录当前软件的可用操作。后续每次新增功能或改变交互方式，都需要同步更新本文档，并随代码一起提交 git commit。

## 启动软件

在项目根目录双击：

```text
VectorAnimationEngine.exe
```

当前根目录 EXE 是轻量入口程序，会启动 `native/` 下的桌面应用源码工程。这样日常开发时不用反复发布完整 EXE。

软件默认打开空项目，不会自动生成压测场景。

## 单位体系

当前引擎把矢量单位作为最小绘制原子：

- `1 px = 25 vu`，其中 `vu` 表示 vector unit。
- `1 pt` 线宽固定显示为 `0.5 px`。
- 因此 `1 pt = 12.5 vu`，材质面板中的 `Stroke pt` 会转换为内部矢量单位保存和计算。
- 对象坐标、尺寸、吸附网格、命中测试、框选和移动编辑都以矢量单位为基础。
- 状态栏中的 `Zoom 100%` 表示 `25 vu` 显示为 `1 px`。
- 软件打开项目或生成压测场景后的默认用户可视范围宽度为 `4000 vu`。

后续矢量布尔、路径编辑、吸附、对齐、材质和导出逻辑都需要遵守这个单位体系。

## 开发热重载

开发阶段双击根目录 `VectorAnimationEngine.exe` 会默认启用 `dotnet watch` 热重载。修改 `native/` 下的 C# 代码并保存后，.NET 会尽量把变更应用到正在运行的软件；软件收到热重载通知后会自动重建主窗口，方便快速检查 UI 布局和交互改动。

底部状态栏显示 `Hot Reload On` 时表示当前处于开发热重载模式。需要排查启动问题时，可以使用：

```powershell
.\VectorAnimationEngine.exe --no-hot-reload
```

## 日志和崩溃定位

软件启动后会在项目根目录写入运行日志：

```text
logs/
```

常见文件：

- `launcher.log`：根目录 EXE 启动 native 工程时的启动记录。
- `native-yyyyMMdd-HHmmss-pidN.log`：桌面应用本体的运行日志。

日志会记录启动环境、热重载窗口重建、压测场景生成、Direct2D 渲染失败回退、UI 线程未处理异常和进程级未处理异常。软件崩溃后，优先查看 `logs/` 中最新的 `native-*.log`。

## 主界面区域

- 顶部栏：播放、帧滑块、运行压测场景、适配舞台。
- 左侧工具栏：选择、平移、基础形状、线条、填充，以及打开 Vault 抽屉的 `V` 按钮。
- 中央舞台：绘制、选择、移动和编辑对象。
- Inspector 左侧面板：`Layers` 图层面板。
- 右侧检查器：根据当前工作区显示绘制设置、动画设置、材质设置或层级面板。
- 底部时间轴：查看帧尺、拖动播放头、查看图层曝光条和关键帧占位。
- 最底部状态栏：显示当前渲染帧率、更新频率、动画 FPS 设置和舞台缩放比例。

右侧检查器使用紧凑自适应表格布局，并在内容超过可视区域时提供滚动，避免中文界面、不同 DPI 或较窄窗口下出现文字裁切。主工作台的顶部栏、工具栏、舞台、图层面板和右侧检查器之间使用细边界区分，便于长时间编辑时快速扫描。

## 工作区

顶部工作区标签用于切换不同编辑模式：

- `Basic Drawing`：基础绘制和对象检查。
- `Scene Edit`：场景信息和当前绘制对象编辑上下文。
- `Animation`：播放 FPS、循环、起止帧设置。
- `Materials`：填色、描边、线宽、不透明度。
- `Hierarchy`：场景、图层和对象层级浏览。

`Basic Drawing` 工作区会隐藏底部时间轴，让绘制区域更大。切换到 `Scene Edit`、`Animation`、`Materials` 或 `Hierarchy` 时，底部时间轴会重新显示。

在 `Basic Drawing` 工作区下方会显示绘制对象页签。这里的绘制对象类似 Flash 元件，用于表示可复用的绘制对象编辑上下文：

- `Scene`：主场景编辑上下文。
- `Drawing Object 001`、`Drawing Object 002`：默认可复用绘制对象。
- `+ Object`：新增绘制对象页签。

点击绘制对象页签会切换当前编辑上下文。按住绘制对象页签并拖拽到 Vault，可以把该绘制对象保存为 Vault 条目，便于后续复用和切换。左侧工具栏仍然负责选择矩形、线条、填充等具体绘制工具。

## 绘制工具

左侧工具栏使用 SVG 矢量图标按钮，鼠标悬浮会显示工具名称。当前支持：

- Select：选择、移动、编辑已选对象。
- Pan View：拖动画布视图。
- Rectangle Tool：绘制矩形。
- Ellipse Tool：绘制椭圆。
- Triangle Tool：绘制三角形。
- Polygon Tool：绘制多边形。
- Star Tool：绘制星形。
- Line Tool：绘制线条。
- Fill Tool：填充已有对象颜色。

鼠标悬浮在工具按钮上时，会显示带淡入和滑动动画的工具名称提示。

## 绘制预览

选择任意绘制工具后，在舞台按住鼠标左键并拖拽，会显示半透明绘制预览：

- 形状工具显示填充和描边预览。
- 线条工具显示线段预览和端点。
- 松开鼠标后，预览会转换为真实对象。
- 拖拽距离太短时不会创建对象，避免误触。

## 绘制设置

在 `Basic Drawing` 工作区可以调整绘制设置：

- 默认所有吸附、紧贴、对齐和角度吸附开关都关闭。
- Snapping 图标组：集中放置吸附相关 SVG 图标开关。
- Snap：总吸附开关。
- Grid：网格吸附。
- Objects：对象吸附；当前用于拖动线条端点时吸附到附近线条端点。
- Tight Fit：紧贴占位。
- Align：对齐占位。
- Angle Snap：角度吸附。
- Grid vu：网格大小，单位为矢量单位。
- Aspect Ratio：固定比例绘制。
- Shape：当前绘制形状。

当前吸附功能主要作用于创建和编辑时的点位计算。线条端点编辑支持对象端点吸附；部分高级紧贴和对齐仍是后续扩展占位。

## 选择和编辑对象

切换到 Select 工具后：

- 点击对象可以选中。
- 在空白区域按住左键并拖拽，可以使用框选选择多个对象。
- 拖拽已选对象主体可以移动。
- 框选多个对象后，拖拽其中任意已选对象可以整体移动这一组选中对象。
- 选中对象后会显示高亮轮廓。
- 多选时会显示多对象高亮轮廓，主选中对象继续显示可编辑手柄。
- 选中填色形状后，会显示边界角点手柄。
- 拖动边界角点可以调整对象边界尺寸。
- 点击填色形状的描边边界时，会选中边界线段；被选中的边界段会单独高亮。
- 拖动被选中的线条段、边界段或被穿过线切出的矩形填色区域时，该虚拟拓扑部分会先实体化为独立对象，然后跟随鼠标移动。
- 选中线条后，会显示起点、终点和贝塞尔控制点。
- 拖动线条起点或终点可以调整线段端点；如果多个线段端点已经连接在同一位置，这些连接端点会一起移动以保持连接。
- 开启 `Snap` 和 `Objects` 后，拖动线条端点靠近其他线条端点时会自动吸附。
- 拖动贝塞尔控制点可以把线条调整为曲线。
- 按 Delete：删除当前选中的一个或多个绘制对象。
- `Ctrl+Z`：撤销最近一次场景编辑，包括绘制、删除、移动、端点/控制点调整、填充、材质修改、粘贴和拓扑 part 实体化。
- `Ctrl+C`：复制当前选中的一个或多个对象。
- `Ctrl+V`：粘贴复制的对象，并在舞台上偏移一小段距离后选中新对象。

选择命中支持填色、自由线条和填色对象的边界描边。线条按贝塞尔曲线距离判断，填色对象按对象边界判断。

当焦点位于文本输入框或数值输入控件中时，`Ctrl+Z`、`Ctrl+C`、`Ctrl+V` 会优先保留给该输入控件使用。

## 绘制元素和拓扑规则

当前引擎开始把绘制对象内部拆成绘制元素：

- 填色是绘制元素。
- 线条是绘制元素。
- 填色对象的边界描边也是绘制元素；例如默认矩形的四条边可以分别选中。
- 同一个图层中，同一个 `1 vu` 绘制单位区域只允许一个填色单位有效；如果多个填色重叠，选择命中归属于该图层中更上层的填色单位。
- 线条和填色边界相交或相切时，线条会按交点切分为多个可命中的线段部分，填色边界描边也会被反向切分。
- 线条和线条相交时，也会按交点建立拆分关系；选择时会根据鼠标所在的线段部分显示 `Stroke part N`。
- 线条拓扑统一按二次贝塞尔曲线处理，曲线和曲线、直线和曲线、直线和直线使用同一套拆分逻辑；直线是控制点位于中点的特殊曲线。
- 线条拆分点会量化到矢量单位，且不会继续切出小于 `1 vu` 的线段部分。
- 填色如果被线条明确穿过边界，则选择时会根据切分侧显示不同的 `Fill part N`。
- 如果线条没有完整穿过填色边界，填色仍然按一个整体选择。
- 典型矩形切分：一条线从矩形外部穿过矩形并从另一侧穿出时，矩形填色会形成两个可命中的 `Fill part`，矩形边界描边会从默认四边变为六段，穿过矩形的新线条会被矩形边界反向切成三段。
- 拆分 part 第一次被拖动时会实体化：`Stroke part` 会拆成独立线对象，`BoundaryStroke part` 会把形状描边拆成独立线段，矩形被一条穿过线切开的 `Fill part` 会变成两个可独立移动的 Path 填色对象。

当前拓扑解算使用基础形状边界和自适应采样的贝塞尔曲线，覆盖现有矩形、椭圆、三角形、多边形、星形、Path 填色和线条。矩形填色被单条穿过线切分后的移动已经可用；后续复杂路径、多条切线、洞、多重交叠和完整面片重建会继续扩展。

## 填充颜色和材质

在 `Materials` 工作区可以调整：

- Fill：填色。
- Stroke：描边颜色。新绘制对象会保存自己的描边颜色。
- Stroke pt：描边宽度，单位为点。`1 pt` 固定等于 `0.5 px`，并按 `1 px = 25 vu` 转换为内部矢量单位。
- Opacity：透明度。

使用 Fill Tool 点击已有对象，可以把当前材质颜色应用到该对象。

如果已选中对象，在材质面板调整参数会直接影响当前对象。

`Basic Drawing` 工作区右侧检查器中的 `Active color` 和 `Stroke pt` 会同步到当前材质。调整 `Stroke pt` 后，后续绘制的形状会使用新的描边粗细；如果当前已有对象被选中，也会立即更新该对象描边。

## 图层和 Vault

Inspector 左侧的辅助面板显示图层：

- `Layers`：管理当前场景图层。

Vault 位于窗口左侧边缘的抽屉中，点击左侧工具栏上的 `V` 按钮可以打开或关闭。Vault 抽屉用于浏览内置库资产，并把任意内容存进 Vault。

### Layers

`Layers` 页显示当前场景图层：

- 点击图层可设置为当前活动图层。
- `Solo` 只显示当前活动图层。
- `All` 显示全部图层。
- 双击图层可切换图层可见性。

新绘制对象会添加到当前活动图层。

### Library

Vault 抽屉上半部分是 Library。当前提供基础预设：

- Basic Shapes。
- Material Swatches。
- Animation Timing。
- Stress Scene Setup。

选中库条目后点击 `Add to Vault`，可以把库预设保存到 Vault。

### Vault

Vault 抽屉下半部分是 Vault。Vault 是通用资产容器，用于保存任何后续可复用或需要记录的内容。

当前支持：

- 从 `Basic Drawing` 的绘制对象页签拖拽到 Vault：保存可复用绘制对象条目。
- `Capture`：把舞台上当前选中对象保存为对象快照。
- `Note`：保存任意文字笔记。
- `File`：保存任意外部文件路径引用。
- `Remove`：删除当前选中的 Vault 条目。
- `Open`：打开文件引用，或查看普通 Vault 条目的内容。

Vault 数据持久化在：

```text
data/vault.json
```

当前 Vault 保存的是通用元数据和引用，不会复制外部文件本体。

## 时间轴和播放

底部时间轴支持：

- 查看帧尺。
- 拖动播放头切换当前帧。
- 查看图层曝光条。
- 查看关键帧占位。

注意：`Basic Drawing` 工作区默认隐藏底部时间轴，以优先保留绘制空间。

顶部播放按钮用于播放/暂停。`Animation` 工作区可以设置：

- FPS。
- 是否循环播放。
- 起始帧。
- 结束帧。

## 压测场景

软件默认不会创建压测数据。

需要压测时，点击顶部 `Run Stress Scene`。当前按钮会生成默认大场景：1000 个图层、100000 个绘制对象、100000000 个虚拟矢量基础元素。

压测目标是验证大规模场景下的视图渲染和交互响应，不代表完整生产级矢量几何精度。

## 渲染后端

舞台渲染当前优先使用 Direct2D HWND RenderTarget。

- 软件外壳仍是 WinForms 桌面端。
- 没有使用 WPF。
- 主循环目标更新频率为 `300 UPS`，舞台重绘请求目标频率为 `144 FPS`。
- 如果当前机器 Direct2D 初始化失败，舞台会回退到旧的 GDI 渲染路径，保证软件仍可启动。
- Direct2D 路径继续使用空间索引、瓦片 LOD、绘制预览、选择高亮和贝塞尔控制点。

当前 Direct2D 优化主要降低大量矢量对象绘制时的 CPU/GDI 压力。后续还可以继续把大批量对象转换为 GPU 侧几何缓存和实例化绘制。

## 视图操作

- 鼠标滚轮：缩放舞台。
- 按住鼠标中键并拖拽：平移舞台。该操作是全局视图操作，不受当前工具影响。
- 按住 Ctrl + 鼠标中键并上下拖拽：缩放舞台。该操作是全局视图操作，不受当前工具影响。
- Pan View 工具拖拽：平移视图。
- `Fit Stage`：适配完整舞台。默认项目视图不是完整舞台，而是宽度 `4000 vu` 的工作视图。
- 顶部 `+` / `-`：以舞台中心缩放。

## 当前限制

- 当前舞台已优先使用 Direct2D，但复杂矢量路径还没有完整 GPU 几何缓存。
- 路径级节点编辑还未完整实现，目前是基础形状边界和线条贝塞尔控制点。
- 高级对象吸附、紧贴和对齐仍在逐步实现。
- 时间轴已有工业软件方向的布局基础，但关键帧数据模型还需要继续扩展。

## 开发与版本记录约定

- 每次新增功能、修复 bug 或改变操作方式，都需要更新本文档。

- commit message 应简短说明本次改变，例如 `Add drawing preview and tool tips`。
- 提交前至少运行一次相关构建验证。
