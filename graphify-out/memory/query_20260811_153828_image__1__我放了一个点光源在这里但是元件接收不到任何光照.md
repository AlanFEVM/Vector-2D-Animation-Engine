## Answer

Expanded from original query via vocab: [light, point, range, position, surface, plane, normal, local, reference, render, scene, spatial]. The finite-light path rejected a zero-thickness receiver when the point light was on the negative side of its stored plane normal. The fix orients an effective receiver plane toward each finite-light sample only for zero-thickness FrontFill/FrontStroke surfaces, reuses that plane for footprint, shading, and occlusion, and preserves one-sided behavior for extruded surfaces.
