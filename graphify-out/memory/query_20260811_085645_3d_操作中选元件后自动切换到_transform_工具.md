# Q: 3D 操作中选元件后自动切换到 transform 工具。

## Answer

Expanded from original query via graph vocabulary: [selection, selected, scene, instance, spatial, transform, tool, activate, pointer]. The 3D Stage selection path is MainForm.TryBeginProjectedScenePointer; after a successful projected instance hit it calls SetSceneInstanceSelection, then should call ActivateTool(ToolMode.Transform3D) only for the 3D Select tool. Keeping this out of SetSceneInstanceSelection avoids affecting timeline, paste, undo, and keyboard-session selection restoration.
