# Q: 3D场景下渲染径向渐变不正确

## Answer

Expanded from original query via graph vocab: [radial, gradient, reference, projected, projection, direct, gdi, fill]. The projective optical-surface path reused GDI PathGradientBrush semantics, where ColorBlend position 0 is the boundary and position 1 is the center, opposite to the engine radial-gradient contract; the brush also leaves pixels outside its ellipse untouched. The fix reverses radial ColorBlend positions for the projective source-space brush and fills the complete source contour with the final stop before mapping each clipped projective triangle.
