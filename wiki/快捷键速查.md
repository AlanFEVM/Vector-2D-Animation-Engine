# 快捷键速查 · Shortcut Cheat Sheet

同一按键按当前焦点执行对应上下文命令。舞台快捷键不会抢占文本框、数值框、下拉框或时间轴输入。

## 全局与舞台固定命令

| 按键 | 命令 |
| --- | --- |
| `F1` / `F2` | 显示/隐藏检查器 / 时间轴 |
| `Ctrl+1` / `Ctrl+2` / `Ctrl+3` | 切换基础绘制 / 场景与动画 / 镜头与导演（键盘上方数字键） |
| `Ctrl+4`–`Ctrl+9` | 按标签顺序预留给后续工作流模块；空槽不执行，且均不能分配给自定义工具快捷键 |
| `Ctrl+N` / `Ctrl+O` | 新建 / 打开工程 |
| `Ctrl+S` / `Ctrl+Shift+S` | 保存 / 另存工程 |
| `Ctrl+Z` | 撤销当前编辑 |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | 剪切 / 复制 / 粘贴舞台多选（支持本地图形+实例混合、场景实例） |
| `F8` | Basic Drawing：选区转元件；Scene & Animation 3D：连续实例组合为 3D 元件 |
| `Ctrl+Up` / `Ctrl+Down` | 所选本地图形/嵌套实例在当前图层/Cel 内前移/后移一层（3D 不执行层级排序） |
| `←` / `→`、`↑` / `↓` | Scene & Animation 3D：横移或沿镜头视线前进/后退（`Shift` 4 倍速） |
| `G` / `R` / `S`，再 `X` / `Y` / `Z` | Scene & Animation 3D：沿指定轴移动/旋转/缩放（`G`/`R`/`S` 在此为 3D 变换，非工具键） |
| `F` | Scene & Animation 3D：平滑聚焦全部选中实例 |
| `Delete` | 删除舞台全部选择（含场景实例、Basic 混合选择） |

## 时间轴快捷键

| 按键 | 命令 |
| --- | --- |
| `Enter` | 播放/暂停 |
| `,` / `.` | 上一帧 / 下一帧 |
| `Shift+,` / `Shift+.` | 播放范围首帧 / 末帧 |
| `F5` / `Shift+F5` | 延长曝光 / 删除当前帧 |
| `F6` / `Shift+F6` | 插入并复制关键帧 / 清除关键帧 |
| `F7` | 插入空白关键帧 |
| 时间轴 `Ctrl+A` | 选择当前可见图层 |
| 时间轴 `Ctrl+C` / `Ctrl+V` | 复制 / 粘贴 Cel |

## 工具快捷键方案（传统 Flash 键位）

| 键 | 工具 | 键 | 工具 |
| --- | --- | --- | --- |
| `V` | Select | `Q` | Free Transform |
| `H` | Hand | `R` | Rectangle |
| `O` | Ellipse | `N` | Line |
| `P` | Pen | `Y` | Pencil |
| `T` | Text | `B` | Brush |
| `K` | Fill | `S` | Ink Bottle |
| `I` | Eyedropper | `G` | Gradient |
| `E` | Eraser |  |  |

可切换到 `Number Keys` 方案，或复制内建方案创建自定义方案。文件/编辑/时间轴/视图导航等固定快捷键不可被工具绑定覆盖。`Tab` / `Shift+Tab` 在当前工具组内前后切换；`[` / `]` 调铅笔/笔刷/橡皮擦宽度。

> `Ctrl+A` 在舞台 = 全选当前帧可见未锁内容；在时间轴 = 选当前可见图层；在文本/搜索/数值编辑器 = 由编辑器处理。
