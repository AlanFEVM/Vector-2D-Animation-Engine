# 渐变 · Gradient

**渐变（Gradient）**给填色或线条应用连续的颜色过渡。它是材质的一种形态，可以被形状补间、被 [吸管](吸管.md) 完整吸取、也会随实例继承。

## 渐变类型

| 类型 | 说明 |
| --- | --- |
| `Linear` | 线性渐变，颜色沿一条直线轨迹过渡 |
| `Radial` | 径向渐变，颜色由中心向外扩散 |
| `ShapeRadial` | 形状径向渐变，按源对象整体轮廓做映射 |
| 线性轨迹渐变 | 在自定义线性轨迹上采样渐变 |

## 怎么用

- 在右侧着色面板把目标切到渐变材质，选类型后用渐变工具在舞台上拖出渐变轴。
- 拖动轴上的色标可改位置与颜色；可增删色标。
- 渐变可作用于**填色**或**线条**。

## 细节与规则

- **碎片继承**：渐变材质可完整继承到随机破碎后的每个碎片——任意数量色标、位置、颜色、Alpha 均保留。
- `ShapeRadial` 默认继续用**源对象整体轮廓**映射，碎片之间不会各自从中心重新开始着色。
- **参与形状补间**：纯色 ↔ 渐变可互转；不同数量的渐变色标按色标位置采样后插值；渐变类型不同时，空间类型在补间中点切换，颜色保持连续（见 [形状补间](形状补间.md)）。
- 渐变可被 [吸管](吸管.md) 整体吸取。

## 需要注意

- **文本特例**：文本不支持渐变；对渐变对象直接改「纯色」会把它切回纯色材质（见 [文字](文字.md)）。
- `ShapeRadial` 的观感依赖源对象轮廓，换到形状完全不同的对象上不会得到等价效果。
