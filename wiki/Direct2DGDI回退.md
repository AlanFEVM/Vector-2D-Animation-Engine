# Direct2D / GDI 回退 · Render Fallback

引擎的 2D 渲染有**三级路径**：Direct3D11 + Direct2D 硬件光学、Direct2D 软件光学、GDI 回退。系统自动在可用时选最优路径。

## 路径层级

- **GPU 光学通道（首选）**：硬件支持时优先创建 Direct3D11 与 Direct2D 共用的显式高性能显卡设备，主画布直接提交交换链；GPU 光学通道不可用时自动回退到经过验证的 Direct2D 光学路径。
- **Direct2D 路径**：全 `Normal` 混合的 2D 绘制把稳定底图保留在 Direct2D GPU 资源中；笔刷预览、首移预览、选区、贝塞尔控制柄、工具光标作为实时覆盖层更新。
- **GDI 回退**：Direct2D 创建失败时自动回退到 GDI，功能仍可用但性能可能下降；GDI 回退保留相同的线性光照公式与预乘透明度语义、相同的边界行为。

## 关键规则（回退一致性）

- 硬件光学、Direct2D 与 GDI 回退**保持相同的线性颜色、局部灯光、阴影覆盖与材质 Alpha**。
- 非 `Normal` 混合模式使用精确软件合成；全部恢复 `Normal` 后使用 Direct2D 硬件路径。
- 超大/高倍率表面按整帧统一级别同比降低光学栅格分辨率，继续逐像素光照；最低分辨率仍无法建立时显示含原透明度的未受光矢量材质，不退回污染色相的彩色叠层。
- 无描边渐变填色在透视视图用固定复杂度材质域 + 精确屏幕轮廓渲染；Direct2D 不可用时的 GDI 回退保持相同边界行为。

## 性能与缓存

- Reference 3D 播放启用有界工作区帧缓存：已绘制组合帧保留为 GPU 位图，循环命中时只提交整帧位图再绘覆盖层；缓存不跨窗口/尺寸/相机/灯光/工程编辑复用，达内存上限按最早使用淘汰。
- 停止播放且舞台空闲时按后续顺序逐帧预渲染邻近帧；复杂帧每次只预取一帧，慢帧完成后短暂让出 UI。
- 密集 Normal 场景（>100 绘制项）在线程池并行准备渲染计划并并行栅格化独立瓦片；最终仍由单个 Direct2D 目标按原始深度顺序提交。
- 精确布尔拓扑、填色边界和最终贝塞尔几何仍由 CPU 在提交阶段计算；GPU 负责缓存/变换/栅格化/交互反馈，预览提速不降最终精度。

## 诊断

- 查看 `logs/native-*.log` 中的 Direct2D、GDI fallback 或未处理异常信息。
- `VECTOR_DISABLE_GPU_FILTERS=1` 仅禁用滤镜 GPU 加速（不影响主渲染路径）。
