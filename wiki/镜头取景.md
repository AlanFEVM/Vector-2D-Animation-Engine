# 镜头取景

「镜头取景」描述每个相机最终拍到的画面范围，由宽高比和取景框尺寸决定。它属于相机属性，是镜头与导演工作区里最核心的设置之一。

## 宽高比

在相机属性的「宽高比」中可选择一个固定比例，或使用默认的「跟随场景」：

- 可选：16:9、9:16、4:3、3:2、1:1、4:5、21:9。
- 每个镜头独立保存自己的比例；切换比例不会修改场景尺寸。
- 比例在目标关键帧处切换，位置和镜头参数继续按原有补间规则变化。
- 「重置相机」会同时恢复为「跟随场景」。

## 取景框尺寸

- 取景框宽度最小 **1920 vu**、高度最小 **1080 vu**。
- 缩到下限时保持所选宽高比：16:9 可达到 1920 × 1080 vu；9:16 因要同时满足两个下限，最小范围约为 1920 × 3413.33 vu。
- 该限制适用于正交、透视和旧版二维取景框；正交范围输入使用 `vu`。
- 旧工程中低于下限的正交范围，读取时会自动提升到下限，关键帧保留。

## 取景预览

镜头与导演工作区里，当前相机的取景会显示为舞台左下角的浮动监视器：它按相机的真实 3D 位置、三轴旋转、投影模式和焦距/正交尺寸渲染，是真正的相机视图。Z 轴推拉会改变取景覆盖范围。可拖动监视器右下角调整大小，尺寸会一直保持。

## 相机参数

| 参数 | 说明 |
| --- | --- |
| 位置 X/Y/Z | 相机在世界中的位置 |
| 旋转 X/Y/Z | 三轴旋转角度 |
| 焦距 Focal length | 透视相机的焦距，可做关键帧与补间实现变焦 |
| 正交尺寸 Ortho size | 正交相机的可视尺寸，可做关键帧与补间 |
| 重置相机 | 恢复默认 3D 取景 |

## 需要注意

- 这里的 `vu` 是场景单位，不是最终导出图像的像素分辨率（见 [单位模型](单位模型.md)）。
- 相机轨道只支持经典补间（见 [经典补间](经典补间.md)）。
