# 时间轴

时间轴是底部的**帧与图层管理面板**（按 `F2` 显示 / 隐藏）。所有与时间有关的概念——曝光、关键帧、胶片格、补间——都通过它来操作。

## 它的结构

| 区域 | 说明 |
| --- | --- |
| 时间标尺 | 帧号刻度 |
| 播放头 | 红色竖线，表示当前所在帧，详见 [播放头](播放头.md) |
| 图层行 | 每个绘制图层 / 灯光轨道一行，左侧是总控（眼睛 / 锁 / 颜色） |
| 帧格 | 一个单元格 = 某图层某帧的胶片格 |
| 补间色带 | 蓝色代表经典补间，绿色代表形状补间 |
| 灯光轨道 | 场景灯光每盏一条 |

## 基本操作

- **定位播放头**：点击任意帧格。
- **选择**：点帧格选单个；拖动框选多图层多帧（`Shift` 扩展，`Ctrl` 追加 / 取消）。
- **右键帧格**：复制 / 粘贴胶片格、插入 / 删除帧与关键帧、反转帧顺序。
- **拖拽变换**：选中两帧以上可整体平移或拉伸选区。
- **多选图层**：`Ctrl+单击` / `Shift+单击`；时间轴聚焦时 `Ctrl+A` 选当前可见图层。

## 相关开关

- `Auto Key`（自动关键帧）：保持帧上的修改是否自动建立关键帧（见 [自动关键帧](自动关键帧.md)）。
- `Onion` / `Motion`：洋葱皮与运动轨参考（见 [洋葱皮](洋葱皮.md)）。

## 大工程下的播放优化

图层很多的工程播放时，时间轴只重绘帧摘要、标尺列、播放头和当前可见帧格；播放头到达可见范围边缘后视窗按区段向前跟随，不每帧重绘整个面板，也不向消息队列堆叠多余的刷新请求。
