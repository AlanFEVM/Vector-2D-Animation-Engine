# 图片导入 · Import Image

`Import Image...` 或直接拖入图片，会先弹出**导入设置对话框**（参考 Unity 方式），确认后把图片作为一个**整体位图对象**放进工程。

## 导入设置

| 设置 | 说明 |
| --- | --- |
| `Filter Mode` | `Point`（像素风）/ `Bilinear` / `Trilinear` |
| `Mipmaps` | 是否生成多级贴图；`Generate Mipmaps For Alpha` 单独控制透明通道 |
| `Pixels Per Unit` | 每单位像素数（PPI），决定放置大小，默认 `100` |
| `Non-Power-Of-Two Scale` | 是否把存储尺寸向下吸附到 2 的幂 |
| `Max Size` | 存储上限，默认 `8192`，只缩小不放大 |
| `Compression` | `Lossless (PNG)` / `JPEG`（可调质量）/ `Raw` |
| `Read/Write Enabled` | 允许后续重新编码 |
| `Pivot` | 归一化轴心（0–1），默认居中 0.5 |
| `Alpha Source` | `From input` 保留透明；`None` 丢弃透明并还原非预乘值 |

## 导入后的位图对象

- 图片作为**整体位图对象**放置：可整体选择、移动、缩放、旋转。
- 不支持 Break Apart（无法打散为矢量路径），需要矢量化请用 [SVG导入](SVG导入.md)。

## 重新编辑与重定位

- 右键素材 `Import Settings...` 改 `Max Size` / `NPOT` / `Compression` / `Alpha Source`，会重新生成托管文件并同步更新所有该图片的放置尺寸，`Ctrl+Z` 可撤销。
- 源文件移动或改名后，素材行标记为缺失；右键 `重新定位...` 指向新文件，ID 和放置内容不变。
- 删除图片素材会同时移除工程各处使用该图片的位图对象（一次撤销事务）。

## 需要注意

- 小于源分辨率绘制时会改用预生成缩小副本采样，以消除旋转锯齿。
- 图片素材按 SHA-256 校验托管副本，源文件丢失也能打开，见 [保存工程](保存工程.md)。
- `Import Image...` 仅在可绘制上下文（Basic Drawing 或 Scene Mask 编辑面）可用。
