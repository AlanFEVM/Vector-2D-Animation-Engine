# 图层文件夹 · Layer Folder

**图层文件夹（Folder）**是 [图层](图层.md) 的容器，用来把相关图层收纳在一起，形成可整体操作的层级结构。它本身不是遮罩，也不改变绘制层级。

## 怎么用

- 在时间轴图层区域把图层拖进文件夹行内即可归入。
- 拖动排序时，把图层拖到 Folder 的**中部**表示放入该文件夹；拖到上/下边缘表示排在外层。
- 单击文件夹可**折叠/展开**（折叠只改时间轴显示，不影响舞台）。

## 属性传递

文件夹是一个整体开关容器，会把状态传递给子层：

- **隐藏文件夹** → 隐藏其中所有图层。
- **锁定文件夹** → 锁定其中所有图层。
- **Outline 文件夹** → 其中所有图层进入轮廓显示。

（分别见 [图层可见性](图层可见性.md)、[图层锁定](图层锁定.md)、[轮廓模式](轮廓模式.md)。）

## 细节与规则

- 拖动排序带动画：动画**只用于预览**，松手才提交一次可撤销的结构修改；若关闭系统动画则立即定位。
- 把已被 [遮罩](遮罩.md) 的内容层拖到普通位置或 Folder，会**自动把它移出**原遮罩层。
- 拖动遮罩文件夹行会搬动整个遮罩组。

## 需要注意

- 折叠状态只是时间轴显示状态，不是隐藏。
- Folder 是**图层容器**，用于组织；裁切内容请用 [遮罩](遮罩.md)，两者不要混用。
