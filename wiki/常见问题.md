# 常见问题 · FAQ

## 无法绘制

依次检查：
1. 是否位于 `Basic Drawing`。
2. 当前是否为普通绘制图层，而非 Folder / Mask 的错误目标。
3. 图层是否可见、未锁定。
4. 当前帧是否允许写入；需要新 Cel 时先按 `F6` 或 `F7`。
5. 是否正在播放动画、编辑文本或操作输入框。

## 选择不到对象

- 检查图层和父文件夹是否锁定。
- 对象是否位于嵌套实例中；本地几何优先，双击实例进入源对象。
- 未拆散 SVG 只能整体选择。
- Outline 不禁止选择，但 Mask 和可见性影响实际显示内容。

## 混合模式看不到预期效果

- 混合需要下方存在可见像素——确认图层顺序和可见性。
- 检查 Folder / Scene Layer 是否作为整体隔离混合。
- 检查 Mask 是否先裁掉了内容。
- 临时切回 `Normal` 可区分材质问题与混合问题。详见 [27种混合模式](27种混合模式.md)。

## Fill 或 Stroke 颜色模块不显示

- 用 `F1` 展开检查器。
- 返回 `Basic Drawing`，选绘制工具或可编辑对象。
- 在基础着色面板顶部点 `Fill` 或 `Stroke` 目标。
- 滚动检查器，确认图层混合面板下方的基础着色区域已展开。

## 播放时内容被提前修改

通常是保持曝光机制导致：关闭 Auto Key 时在普通保持帧编辑会改来源 Cel。需要从当前帧开始变化时，先建关键帧或开启 Auto Key。详见 [自动关键帧](自动关键帧.md)。

## 找不到导出/导入元件命令

- 导出命令要求存在可导出的当前元件：Vault 右键元件，或舞台右键菜单导出项（作用于当前元件）。舞台右键没导出项，通常说明当前没有活动可导出元件。
- Vault 选 `外部 SVG` 只给链接相关命令；选 `图片` 给 Place/Import Settings/重新定位/删除，不给元件导出、也不能 Break Apart。
- `Import Symbol File...` 在舞台右键菜单且始终可用；看不到请在舞台画布右键，而非时间轴/Vault/检查器。
- 误把 `.V2DSymbol` 当 SVG 打开会失败：它是带格式版本的压缩包，请用导入命令而非 `Import SVG...`。

## 性能或渲染异常

- 渲染路径、缓存策略与已知性能边界见 [规模目标](规模目标.md)；Direct2D 失败自动回退 GDI，功能可用但性能下降。
- 排查日志：查看 `logs/native-*.log` 的 Direct2D、GDI fallback 或未处理异常，详见 [Direct2DGDI回退](Direct2DGDI回退.md)。

## 崩溃诊断报告

未处理错误时自动在 `logs/crashes/` 写出 `crash-<日期>-<时间>-pid<进程号>.txt`，含崩溃来源、运行环境、已加载模块、完整异常链、最近约 120 条用户操作记录、最后 200 条日志行。可用 `V2D_LOG_FIRST_CHANCE_EXCEPTIONS=1` 启动额外记录首次 Chance 异常（日志量大，仅排查时临时开）。报告以纯文本写出，可直接附在反馈中；若未生成，`logs/native-*.log` 仍保留 fatal 记录与报告路径。
