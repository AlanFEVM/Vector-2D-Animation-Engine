# 场景

场景是「场景与动画」工作区里的**装配单位**：把元件作为实例摆进场景、做关键帧动画，都在场景里完成。一个工程可以包含多个场景，可在顶部新建、重命名、切换、删除。

## 每个场景自带什么

| 内容 | 说明 |
| --- | --- |
| 维度 | 2D 或 3D，决定投影方式（见 [投影](投影.md)） |
| 镜头取景 | 相机的取景范围与宽高比（见 [相机](相机.md)） |
| 播放设置 | 帧率、循环方式、播放范围 |
| 场景图层 | 实例、遮罩关系、灯光轨道、相机轨道 |
| [洋葱皮](洋葱皮.md) 设置 | 前后帧参考的开关与数量，按场景独立保存 |

## 场景图层

- **普通内容层**：放场景实例。要对该层做 [经典补间](经典补间.md)，层里必须恰好包含一个场景实例，且起止帧都是有内容的关键帧。
- **遮罩**：与绘制图层相同的遮罩语义——先裁切，再混合。
- **灯光轨道**：每盏灯一条轨道，可用 `F5`/`F6`/`F7` 与补间。
- **相机轨道**：只支持经典补间。

## 场景实例 与 嵌套实例 的区别

- **场景实例**：元件拖到场景里产生，存在于场景图层。
- **嵌套实例**：元件内部引用其他元件，存在于绘制图层（见 [嵌套实例](嵌套实例.md)）。
- 两者都只保存「引用 + 变换 + 播放 / 外观状态」；改源元件，所有引用自动更新。

## 与工作区的关系

「镜头与导演」（`Ctrl+3`）与「场景与动画」**共享同一个场景、舞台和连续时间轴**：切换场景、2D/3D、投影和播放设置行为一致，右侧会换成相机管理面板。场景数据随工程保存，打开时经过校验。
