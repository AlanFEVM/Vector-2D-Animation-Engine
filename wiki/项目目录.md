# 项目目录 · Project Structure

工程采用**目录结构**而非单个压缩包。首次保存请选择或新建专用文件夹。

```text
Project Folder/
  Project Name.v2dProject
  .Vault/
    Images/
  .TimeLine/
```

## 各文件职责

- `.v2dProject`：保存工程索引、播放设置和校验信息；元件吸附点作为元件级静态数据也存这里（不写入图层/时间轴）。
- `.Vault`：保存可逆 SVG 绘制资产；普通 SVG 预览保持可用，内部可编辑场景数据用 Brotli 无损压缩，不降低几何精度或画质。图片素材复制到 `.Vault/Images` 并按下内容 SHA-256 校验托管副本。
- `.TimeLine`：用 `.json.br` 文件无损压缩保存图层、关键帧、Cel、场景和实例状态，打开时自动解压。

## 格式版本

- 新保存工程采用**格式版本 5**；版本 1–4 工程和旧版未压缩 SVG 数据仍可打开，再次保存自动转压缩格式（需用支持的新版编辑器打开）。
- 版本 5 新增图片素材库，旧格式不允许含图片素材。
- 外部 SVG 只在 `.v2dProject` 保存稳定 ID、绝对/工程相对源路径和最后已知 SHA-256；源文件留在原位置，不复制进 `.Vault`。

## 注意事项

- 不要手工移动、改名或单独替换 `.Vault`、`.TimeLine` 中的文件。
- 不要把两个工程保存到同一个受管理目录；软件会拒绝覆盖不属于当前工程的数据。
- 新建/打开/关闭前出现保存提示时，`Cancel` 保留当前编辑状态。

> 保存与打开的校验逻辑见 [保存打开校验](保存打开校验.md)。
