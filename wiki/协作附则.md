# 协作附则 · Collaboration Notes

本附则用于多人 / 多 Agent 在本仓库协作时的统一规则，避免互相覆盖与产生脏提交。

## 工作树与提交

- 动手前先 `git status --short --branch` 记录已修改/未跟踪文件；未知改动视为他人所有，不回退、覆盖、暂存或归功于本任务。
- **未经明确授权不执行**暂存、提交、分支切换、合并、变基或推送。
- 只有存在决定性信息缺失、需他人修改或需新增授权时才询问。

## 文件所有权

- 每个文件同一时间只有一个写入者。`Benchmark*`、`MainForm*`、`VectorScene*`、`StageControl*`、`Direct2DStageRenderer*` 等核心文件，以及项目文件、公共文档、发布源/脚本/产物，由集成负责人独占。
- 子 Agent 编辑前与交接前刷新 `git status --short`；发现范围重叠先报告并停止该文件写入，不得撤销他人工作。

## 验证

- 产品/launcher/发布修改使用最小充分验证套件；现有回归位于 `native/App/Benchmark*.cs`，不要假设存在独立测试工程或 CI。
- 修复优先验证可观察失败行为及受影响契约；不无理由重复全套验证；纯说明文档变更无需产品构建。

## 内容与文档

- 文档与代码不一致时核对实现和测试，明确差异，不把规模目标或基准夹具当成已达成的性能。
- 用户可见功能/交互变化同步更新 `docs/USER_GUIDE.md`；仅 Agent 指南调整无需改产品说明。
- `bin/`、`obj/`、运行时、验证输出、截图、发布产物、任务无关 graphify 缓存不得混入提交，除非用户明确要求。

## 发布边界

- 根目录 `VectorAnimationEngine.exe` 只用于本地开发（由 `scripts\publish-development-launcher.ps1` 生成，带热重载）。
- 正式发布用 `scripts\publish-single-exe.ps1`，产物只放 `artifacts\release` 或明确指定的空目录；须是可替换 EXE，下次启动由 bootstrap 原子刷新外部 `.V2DEngine`。
- `.Runtime` 保持外部持久化；缺失/无效时由 bootstrap 获取兼容的 .NET 8 Core 与 Windows Desktop x64 runtime。

> 本仓库的完整 Agent 协作工作流见根目录 `AGENTS.md` 与 `.agents/` 下的技能说明。
