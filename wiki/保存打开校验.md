# 保存 / 打开校验（工程文件操作总览）

主菜单提供工程文件操作，保存与打开都经过**事务 + 校验**保护。每个环节都有独立词条：

| 环节 | 作用 | 独立词条 |
| --- | --- | --- |
| 保存 | 先写临时内容并校验，再替换原工程 | [保存工程](保存工程.md) |
| 打开 | 先校验路径与 SHA-256，再解压校验 ID/引用/时间轴 | [打开校验](打开校验.md) |
| 图片导入 | 导入设置对话框 + 整体位图对象 | [图片导入](图片导入.md) |
| SVG 导入 | 矢量图导入并可打散 | [SVG导入](SVG导入.md) |

## 菜单与快捷键

| 菜单项 | 快捷键 / 说明 |
| --- | --- |
| `New Project` | `Ctrl+N` |
| `Open Project...` | `Ctrl+O` |
| `Import SVG...` | 仅可绘制上下文（Basic Drawing 或 Scene Mask 编辑面）可用 |
| `Import Image...` | 同上；导入后作为整体位图对象放置 |
| `Save Project` | `Ctrl+S` |
| `Save Project As...` | `Ctrl+Shift+S` |
| `Settings...` | 语言、主题、快捷键与 Codex/MCP 接口 |
| `Release Notes...` | 查看当前版本更新说明 |

## 共同原则

- 保存和打开都**先校验、后替换**，任何一步失败都不会留下半成品工程。
- 工程采用**目录结构**而非单压缩包，见 [项目目录](项目目录.md)。
