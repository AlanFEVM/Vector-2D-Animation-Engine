# SVG 导入 · Import SVG

支持把 `.svg` 文件导入为可编辑/可放置的对象，以及把元件导出为 SVG 或 `.V2DSymbol`。

## 导入 SVG

- 主菜单 `Import SVG...`，或把单个 `.svg` 拖到 `Basic Drawing` 舞台。结果先作为**整体对象**，可选择/移动/变形/复制/保存。
- 保留不含扩展名的 SVG 文件名；若当前元件完全无内容，自动改用该文件名。
- `Break Apart` 转内部内容：基础路径/形状/文字优先转普通矢量；实色描边按原始宽度/端帽/连接/miter limit 展开为可编辑轮廓 Path（小于 1 的细描边不放大）；`nonzero` 填充和 `<text><tspan>` 转等价轮廓；图片/滤镜/复杂裁切/混合按最终外观有限精度轮廓化。
- 每个 SVG 拆分图层放入独立 Folder（用导入时文件名）；旧工程无元数据用 `SVG`。互不重叠的显式图层/分组/连续绘制区段合并到同一 Drawing Layer，重叠时只保留最少层数。
- 新图层继承源图层颜色和显示属性；对象原填色/描边/透明度不被图层颜色重写。拆散为一次撤销事务。

机制：未拆散 SVG 保留整体外观但不开放内部材质和节点；复杂效果轮廓化后高倍缩放可能出现轻微像素边缘或颜色分级。

## 导出单个元件为 SVG

Vault 元件右键 `Export SVG...`，或舞台右键 `Export Symbol as SVG...`（导出当前元件）：

- 只含当前帧实际可见内容：隐藏图层/父文件夹隐藏图层/文件夹和遮罩图层本身不写入；被遮罩绘制层生成对应 SVG `mask` 裁切输出。
- 画布按实际图元范围收紧，显式像素按 `25 vu = 1 px` 换算。图层顺序按舞台绘制顺序；图层混合映射为等效 CSS `mix-blend-mode`。
- 导出的是普通 SVG，**不含 `.Vault` 可逆元数据**，不能替代工程存储，也不能再次导入还原为可编辑元件。

## .V2DSymbol（可再次导入的元件包）

- Vault 元件右键 `Export Symbol File...` 或舞台右键 `Export Symbol File...`；`Import Symbol File...` 在舞台右键导入当前工程。
- 也可从资源管理器把 `.V2DSymbol`（扩展名不区分大小写）拖入资产列表区导入；多文件顺序独立导入，失败不影响其他，最后成功导入的根元件被选中。
- `.V2DSymbol` 是自包含可逆元件包：Brotli 无损压缩 UTF-8 JSON，几何/图层/Cel 曝光/关键帧/实例状态无损保存，导入后继续可作可编辑元件。
- 写入完整依赖闭包（嵌套引用全打包）；标签按名称合并（同名保留工程原色，新标签用文件色）；路径按记录重建目录链；导入一律分配新 ID，重复导入得独立副本，重名自动追加序号。
- 导入前完整校验：不支持版本、重复/悬空引用、递归嵌套、非法目录路径、越界元数据都被拒绝，工程不被修改；写入中途失败会移除已创建元件。

> 图片导入（PNG/JPEG…）的导入设置见 [图片导入](图片导入.md)；更多工程文件操作见 [保存打开校验](保存打开校验.md)。
