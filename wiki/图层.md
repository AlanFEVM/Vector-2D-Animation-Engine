# 图层

图层是动画里用来分层管理内容的透明薄片。你可以把不同元素放在不同图层上，分别控制它们的显示顺序、可见性、不透明度和混合方式，彼此互不干扰。

## 它解决什么问题

- 把背景、角色、前景分开，避免互相遮挡或误改。
- 每个图层可以单独设置可见、锁定、不透明度和混合方式。
- 动画补间是作用在图层上的，而不是单个图形上。

## 图层的几种类型

| 类型 | 用途 |
| --- | --- |
| 绘制图层 | 存放矢量图形、元件实例 |
| 场景图层 | 存放场景实例，用于做场景级补间 |
| 遮罩图层 | 用它裁剪下方图层的显示区域 |
| 灯光轨道 | 控制场景里灯光的动画 |
| 相机轨道 | 控制镜头运动（只支持 [经典补间](经典补间.md)） |

## 常用操作

- **调整顺序**：在图层面板里上下拖动；越靠下越早绘制，越靠上越盖在上面。
- **可见 / 锁定**：点眼睛图标隐藏，点锁图标防止误编辑。
- **颜色标识**：给图层标一种颜色，方便在舞台和时间轴里区分。
- **不透明度**：调低让整层变透明。
- **混合模式**：选择 27 种混合方式之一（见 [27 种混合模式](27种混合模式.md)）。
- **组织**：用 [图层文件夹](图层文件夹.md) 把相关图层收纳成层级结构，或用 [图层分组](图层分组.md) 按用途筛选显示。

## 需要注意

- 场景图层要做「经典补间」时，该层必须**恰好只有一个场景实例**，且起止帧都有内容；如果一个层里有多个实例，先把它们分到不同图层。
- 遮罩关系：上方的遮罩层会裁剪下方紧跟的被遮罩层（见 [文件夹／遮罩／可见性／锁定](文件夹遮罩可见性锁定.md)）。
