# 保存工程 · Save Project

保存工程使用**事务 + 校验**保护，防止写出损坏的工程文件。

## 入口

| 菜单项 | 快捷键 |
| --- | --- |
| `Save Project` | `Ctrl+S` |
| `Save Project As...` | `Ctrl+Shift+S` |

## 保存机制

- 保存时**先写入临时内容并完整校验，再替换原工程**；中断后可通过事务日志恢复。
- 工程采用**目录结构**而非单压缩包（见 [项目目录](项目目录.md)）。

## 素材托管

- 图片素材字节被复制到 `.Vault/Images`，并按 **SHA-256** 校验托管副本。
- **源文件丢失不阻止打开**：托管副本已足够还原画面。
- 外部 SVG 只在 `.v2dProject` 中保存稳定 ID、源路径和最后已知 SHA-256，不复制内容。

## 需要注意

- `Save As` 会改变工程的存储位置；已有工程的相对引用随目录一起迁移。
- 打开工程会先做校验，见 [打开校验](打开校验.md)。
