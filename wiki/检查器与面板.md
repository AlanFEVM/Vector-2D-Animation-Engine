# 检查器与面板 · Inspector & Panels

界面右侧和底部有多块功能面板，内容**随当前选区与上下文变化**。

## 右侧检查器（F1）

`F1` 显示/隐藏检查器。常见内容按上下文出现：

| 选中对象 | 检查器显示 |
| --- | --- |
| 绘制图层 | 图层混合模式（27 种）、图层颜色/不透明度 |
| 补间色带 | `Tween Curve` 缓动曲线编辑器 |
| 绘制工具或可编辑对象 | 基础着色面板（`Fill` / `Stroke` 目标切换） |
| 相机补间（镜头工作区） | 镜头检查器 + 相机曲线 |

找不到 Fill/Stroke 颜色模块时：用 `F1` 展开检查器 → 回 `Basic Drawing` 选绘制工具或可编辑对象 → 在基础着色面板顶部点 `Fill` 或 `Stroke` → 滚动检查器确认图层混合面板下方区域已展开。

## 时间轴（F2）

`F2` 显示/隐藏底部时间轴，详见 [时间轴](时间轴.md)。

## 输入框行为

- 数值输入框支持方向键微调（配合 `Shift` 步进更大）。
- `Ctrl+A` 在输入框内由编辑器处理（全选文本），不触发舞台全选。
- 连续拖动滑块/手柄时界面即时预览，但**只在抬手或完成输入后**统一写入模型与撤销记录（如曲线锚点、灯光补间端点）。

## 状态栏

顶部/底部状态栏显示 `Zoom` 等当前工作区状态；Zoom 与相机体系详见 [舞台](舞台.md) 与 [单位模型](单位模型.md)。
