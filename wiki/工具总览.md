# 工具总览 · Tools

左侧悬浮工具栏按「工具组」组织，按钮右下角有分组标记，悬停后可在右侧弹出区选子工具。`Tab` / `Shift+Tab` 在当前工具组内前后切换。

## 绘制工具（Basic Drawing 可用）

| 工具 | 作用 |
| --- | --- |
| `Shape` | 矩形 / 椭圆 / 三角 / 多边形 / 星形；拖动时 `Shift` 等比、`Ctrl` 从中心绘制 |
| `Line` | 独立线段；拖动用当前 Stroke，`Shift` 按角度步长约束 |
| `Pen` | 连续建立直线或三次贝塞尔路径；拖新锚点建方向柄，单击首锚点闭合 |
| `Simple Pen` | 逐段绘制简化曲线 |
| `Pencil` | 生成开放描边（Stroke 材质）；`Smoothing` 0–100% 越高越平滑、段数越少 |
| `Brush` | 生成闭合填色轮廓（Fill 材质） |
| `Pressure Brush` | 用数位笔压力；鼠标按速度与停留时间模拟压力 |
| `Mixing Brush` | 以当前 Fill 载色，沿笔迹拾取已有填色；光学/颜料混色 |
| `Text` | 单击建文本，`Ctrl+Enter` 提交，`Esc` 取消 |
| `Fill` | 修改填色；点击由描边与已有填色边缘围成的空白区可创建填色 |
| `Ink Bottle` | 给填色边界应用当前 Stroke 颜色与线宽 |
| `Eyedropper` | 吸取填色/描边/渐变 |
| `Gradient` | 给填色或线条应用并调整渐变 |
| `Snap Point Tool` | 为当前元件配置可复用吸附点；左键加、右键删、可拖动 |
| `Eraser` | 可分别擦 Stroke / Fill / 同时；中段擦除会把顶点色网格拆成可独立选择的连通区域 |

## 选择与变形工具

| 工具 | 作用 |
| --- | --- |
| `Select` | 选择与移动；同组含 `Polygon Lasso` / `Freehand Lasso` |
| `Free Transform` | 缩放、旋转、倾斜 |
| `Distort` | 可编辑三次贝塞尔包络扭曲 |
| `Hand` | 临时平移视图（`Space` 也可临时手形） |

## 通用操作提示

- `[` / `]` 调整铅笔、笔刷或橡皮擦宽度。
- 笔刷激活时按住 `Shift` 可在指针周围选最近使用的颜色。
- 拖动期间显示半透明预览，通常松开鼠标才正式写入；`Esc` 取消未提交操作。
- 调整混色笔刷参数后可直接落笔；开始笔触时舞台重新接管键盘焦点，松手后可立即 `Ctrl+Z` 撤销该笔区域。

## 快捷键方案

传统 Flash 键位（`V` Select、`B` Brush、`P` Pen、`Y` Pencil、`T` Text、`K` Fill、`S` Ink Bottle、`I` Eyedropper、`G` Gradient、`E` Eraser、`Q` Free Transform、`R` Rectangle、`O` Ellipse、`N` Line、`H` Hand）。可切换到 `Number Keys` 方案或复制内建方案做自定义。详见 [快捷键速查](快捷键速查.md)。
