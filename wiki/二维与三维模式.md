# 二维与三维模式

「二维与三维模式」是同一个场景的两种观察与编辑维度。切换 2D/3D 不会创建另一份场景，只是改变观察视图和可用工具。

## 它们的关系

- 舞台顶部右侧的 `2D` / `3D` 按钮切换同一场景的观察视图；其左侧始终显示 `正交` / `透视` 投影的快捷切换。
- 新场景首次进入 3D 时默认使用透视投影；所有 2D 参考视图仍按正交方式显示。
- 新场景实例位于 `Z = 0` 的基准 2D 平面上，初始 `Scale Z = 0`，因此默认没有厚度。
- 2D 前视图始终使用正交空间投影，并按实例在当前帧求值后的 Z 深度从远到近绘制和命中；Z 轴 [经典补间](经典补间.md) 经过 `Z = 0` 时不会丢失深度排序。

## 2D 与 3D 下的工具

- 2D 前视图提供：选择、自由变换、扭曲和素材库。
- 2D 侧向或顶/底参考视图只保留选择与素材库。
- 3D 视图提供：选择和 3D 变换、素材库。
- 形状、线条、笔刷、文字、填充、取色、渐变与擦除等绘制工具在 3D 与参考视图中隐藏，相关快捷键也不激活。

## 与灯光的关系

- 场景第一次切换到 3D 时，会自动建立一盏白色直线光和一盏强度 50% 的白色环境光（见 [灯光](灯光.md)）。
- 全部光源删除、禁用或强度为零时，2D 与 3D 视图都保留对象原色，不会仅因切换维度而变黑。

## 镜头与导演

- 镜头与导演工作区在一个场景里管理多组独立的 3D 相机（见 [相机](相机.md)）。
- 场景始终只有一条连续时间轴；相机不拥有场景内容图层，旧工程里的镜头图层归属只作为兼容数据读取后清空。
