# 播放头 · Playhead

播放头是 [时间轴](时间轴.md) 上的一条**红色竖线**，用来标记「当前停在哪一帧」。因为 [舞台](舞台.md) 始终显示播放头所在的那一帧，所以它的位置就等于你此刻看到的画面时间点。

## 长什么样

- 红色竖线贯穿时间标尺和所有图层行的帧格，顶端有一个醒目的**红色标记头**。
- 标记头旁边会显示当前帧号，方便随时确认位置。

## 怎么操作

| 操作 | 效果 |
| --- | --- |
| 点击任意帧格 | 播放头跳到那一帧 |
| 拖动标尺 / 标记头 | 逐帧擦洗预览（scrub），画面跟着连续变化 |
| 按空格播放 | 播放头按 [帧率](帧率.md) 向前推进 |
| `Home` / `End` | 跳到时间轴起点 / 末尾（具体键位见 [快捷键速查](快捷键速查.md)） |

此外，拖动 [帧摘要](帧摘要与区段跟随.md) 对应位置也能让播放头同步移动。

## 播放时它会怎样

- 播放头按 [帧率](帧率.md) 每秒走固定帧数，走到 [播放范围](循环与播放范围.md) 末尾后，按设定的循环方式回绕或往返。
- 图层很多的工程在播放时，时间轴只会重绘帧摘要、标尺和播放头附近的帧格；当播放头到达可见范围的边缘，时间轴视窗会**按区段向前跟随**，而不是每帧重绘整个面板，以避免卡顿。

## 和曝光的关系

播放头所在的那一帧，决定了每个图层「当前显示哪一格」：若图层在该帧有 [曝光](曝光.md)，就显示对应的 [胶片格](胶片格.md)；没有曝光则显示空白帧。所以只要把播放头移到任意位置，就能立刻检查那一帧各图层的实际叠加效果。

## 注意

- 播放头的位置是**编辑时的临时状态**，不随工程保存；重新打开工程默认从第 1 帧开始。
- 拖动播放头做擦洗预览，不会产生 [关键帧](关键帧.md)，也不会写入 [撤销](撤销模型.md) 记录——它只改变「看哪一帧」，不改变任何内容。
