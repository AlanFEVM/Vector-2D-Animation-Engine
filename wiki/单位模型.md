# 单位模型 · Unit Model

引擎内部使用**矢量单位（vu, vector unit）**，所有几何以矢量存储，放大不降清晰度。

## 换算关系

- `1 px = 25 vu`（像素到矢量单位）。
- 线宽以 `pt` 输入：`1 pt = 0.5 px = 12.5 vu`。
- 舞台缩放**不会改变线宽的工程尺寸**（pt 是物理线宽，独立于视图缩放）。

## 视图缩放与 Zoom

- 顶部/底部状态栏 `Zoom` 百分比始终显示**当前工作区**的缩放，与画面一致；三个工作区缩放相互独立：
  - `Basic Drawing` 与 2D Front 场景视图：绘制相机倍率。
  - 3D 场景视图、侧向/顶底参考视图、镜头工作区：参考相机倍率。
- 绘制相机倍率范围约 `2%–6400%`；参考相机倍率 `25%–800%`。
- 3D 视图滚轮推拉改变的是摄像机距离（观察距离），**不计入 Zoom 百分比**。

## 镜头取景范围

- 镜头取景框宽最小 `1920 vu`、高最小 `1080 vu`；缩小到下限时保持所选宽高比（如 9:16 最小约 1920 × 3413.33 vu）。
- 该限制适用于正交/透视/旧版 2D 取景框；正交范围输入用 vu。
- 旧工程低于下限的正交范围读取时提升到下限，关键帧保留。
- **vu 是场景单位，不是导出图像的像素分辨率。**

## 像素与导出

- 导出 SVG 时显式像素按 `25 vu = 1 px` 换算；画布按实际图元范围收紧，重新导入不会把整个工作区透明空白算进边界。
- 图片导入 PPI 默认 `100`，决定放置到舞台后的实际大小（见 [图片导入](图片导入.md)）。
