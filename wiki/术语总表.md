# 术语总表 · Glossary

本表汇总引擎核心术语，便于跨词条对照。

## 工作区与资产

- **Basic Drawing（基础绘制）**：画元件/图层/Cel 的工作区，`Ctrl+1`。
- **Scene & Animation（场景与动画）**：装配实例、做关键帧动画的工作区，`Ctrl+2`。
- **Shots & Directing（镜头与导演）**：管理多组 3D 相机与相机轨道的工作区，`Ctrl+3`。
- **Symbol / 符号 / 元件**：可复用的绘制资产（图层 + Cel 曝光 + 关键帧 + 内部实例）。
- **Instance / 实例**：对元件的引用 + 变换 + 播放/外观状态；多个实例可引用同一源。
- **Nested Instance / 嵌套实例**：元件内部再引用其他元件。
- **Vault / 素材库**：项目素材列表（基础元件 / 3D 元件 / 外部 SVG / 图片）。

## 时间与图层

- **Cel / 胶片格**：某图层在某关键帧的独立内容。
- **Exposure / 曝光**：从一个关键帧保持到下一个关键帧之前的区间。
- **Keyframe / 关键帧**：实心=有内容，空心=空。
- **Playhead / 播放头**：红色竖线，表示当前帧。
- **Layer / 图层**：内容层级单元，图层 0 在最上方。
- **Folder / 文件夹**：收纳图层。
- **Mask / 遮罩**：用封闭填色裁切内容层；先裁切再混合。
- **Blend Mode / 混合模式**：当前层与下方内容的 27 种合成方式之一（非 Normal 走软件合成）。
- **Outline / 轮廓**：编辑辅助，用图层色轮廓显示内容，不改材质。

## 几何与材质

- **vu / 矢量单位**：内部单位，`1 px = 25 vu`，`1 pt = 12.5 vu`。
- **Fill / 填色**：对象内部材质。
- **Stroke / 描边**：Line/Pencil/边界的颜色与线宽（pt）。
- **Bézier / 贝塞尔**：三次贝塞尔节点，矢量几何基础。
- **整体对象**：位图/未拆散 SVG/文本/未拆散 Mixing Brush，无顶点几何，只能整体变换。

## 动画

- **Classic Tween / 经典补间**：蓝色色带，逐帧插值变换与外观（单对象或单实例）。
- **Shape Tween / 形状补间**：绿色色带，自动形变矢量内容（对象数可不同）。
- **Easing / 缓动曲线**：补间随时间的进度控制。
- **Auto Key / 自动关键帧**：保持帧上修改时自动建关键帧的开关。
- **Onion Skin / 洋葱皮**：前后帧半透明参考，不改工程。
- **Motion / 运动轨**：叠加实例运动轨迹的参考辅助。

## 持久化

- **.v2dProject**：工程索引/播放设置/校验信息。
- **.Vault**：可逆 SVG 资产与图片托管目录。
- **.TimeLine**：`.json.br` 无损压缩的图层/关键帧/Cel/场景/实例状态。
- **.V2DSymbol**：自包含可逆元件包（Brotli 压缩 JSON）。
- **Format v5**：当前格式版本，新增图片素材库。
