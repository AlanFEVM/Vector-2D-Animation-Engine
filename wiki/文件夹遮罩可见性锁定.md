# 文件夹 / 遮罩 / 可见性 / 锁定（图层组织属性总览）

时间轴左侧管理 [图层](图层.md) 的**组织与显示属性**。这些概念各自独立成篇：

| 属性 | 作用 | 独立词条 |
| --- | --- | --- |
| 可见性（眼睛） | 控制图层在舞台上是否显示 | [图层可见性](图层可见性.md) |
| 锁定（锁） | 控制图层是否被保护不可编辑 | [图层锁定](图层锁定.md) |
| 文件夹（Folder） | 图层容器，组织层级 | [图层文件夹](图层文件夹.md) |
| 遮罩（Mask） | 用封闭填色裁切下方内容 | [遮罩](遮罩.md) |
| 列头总控 | 一次性切换全部图层属性 | [图层总控](图层总控.md) |
| 多选图层 | 批量修改选中图层的属性 | [图层多选](图层多选.md) |

## 相关的编辑辅助属性

图层的编辑识别属性（不进最终材质）另有独立词条：

- 图层颜色标识——见 [图层颜色标识](图层颜色标识.md)
- 轮廓模式 Outline——见 [轮廓模式](轮廓模式.md)
- 图层不透明度——见 [图层不透明度](图层不透明度.md)

## 相关的组织手段

- 分组（TabGroup）——见 [图层分组](图层分组.md)
- 遮罩的种类差异（Folder / 遮罩层 / 2D 场景遮罩）——见 [遮罩类型](遮罩类型.md)

## 需要注意

- 隐藏、锁定、Outline 文件夹的状态都会**传递给其子层**。
- Folder 是组织容器，Mask 是几何裁切，两者不要混用。
